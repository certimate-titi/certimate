# 資料處理協議（Data Processing Agreement, DPA）— B2B 教育機構模板（草案 v0.1）

> **聲明**：本草案非律師意見，僅供 EDU console 簽約流程參考。**機構正式簽署前須經雙方法律顧問覆核**。
> 模板版本：2026-05-08

## 締約方

- **資料控制者（Controller）**：______________（以下稱「機構」），代表人 ______________，地址 ______________
- **資料處理者（Processor）**：CertiMate / TiTi 服務營運主體（以下稱「平台」）

## 第 1 條 適用範圍

本協議為機構與平台間《服務主協議》之附件，規範機構於使用平台 EDU / INSTITUTION 方案期間，平台代為處理之**學生個人資料**（以下稱「機構資料」）之處理條件。本協議遵循《個人資料保護法》及其施行細則。

## 第 2 條 處理目的、類別、期間

| 項目 | 內容 |
|------|------|
| 處理目的 | 提供學生備考輔導、學習數據分析、教師端管理 |
| 資料類別 | 學生姓名、學號、機構電子郵件、答題紀錄、學習進度、上傳作業 |
| 資料主體 | 機構在學學生、教師 |
| 處理期間 | 服務契約存續期間 + 終止後 30 日匯出窗口 |
| 處理地區 | GCP asia-east1（台灣）；AI 推論限定 zero-retention 之 LLM endpoints |

## 第 3 條 平台之義務

3.1 **依指示處理**：平台僅依機構之書面指示處理機構資料，不得逾越本協議目的。
3.2 **保密義務**：平台員工及承包商均簽署 NDA，違反者依約懲處。
3.3 **安全措施**：實施符合產業標準之技術與組織措施，包括：
   - 傳輸加密（TLS 1.2+）、靜態加密（AES-256）
   - Row-Level Security 隔離 `tenant_id`，機構間資料不可互讀
   - 存取日誌保留 12 個月
   - 每年至少一次滲透測試
3.4 **次處理者**：平台得委託下列次處理者，並對其行為負責：

| 次處理者 | 用途 | 地區 |
|----------|------|------|
| Google Cloud Platform | 雲端基礎設施 | 台灣 / 美國 |
| Google Gemini API | AI 解析（已關閉 data retention） | 美國 |
| Anthropic Claude API | AI 解析（zero-retention 設定） | 美國 |
| OpenAI API | AI 解析（zero-retention 設定） | 美國 |
| ECPay 綠界 | 金流（如機構自付） | 台灣 |
| Firebase | 身分驗證 | 台灣 / 美國 |

新增次處理者前，平台應提前 30 日通知機構，機構得於 14 日內以書面異議。

## 第 4 條 學生資料禁止用於模型訓練（核心條款）

4.1 平台**保證不將機構資料用於任何 AI 模型之訓練、fine-tuning 或評估資料集**。
4.2 平台應於各 LLM 供應商 API 設定中啟用 `disable_training` / `zero_retention` 旗標，並提供設定截圖供機構稽核。
4.3 違反本條者，每筆違規資料賠償新台幣 ______ 元，且機構得立即終止契約。

## 第 5 條 資料主體權利協助

5.1 學生或家長行使 PDPA 權利（查詢、更正、刪除、停止處理）時，平台應於收到機構轉介後 **10 個工作日內**協助完成。
5.2 平台提供機構管理員介面以批次匯出 / 刪除特定學生資料。

## 第 6 條 資料外洩通知

平台察覺機構資料疑似外洩後，應於 **48 小時內**以書面通知機構，內容包括：外洩範圍、可能風險、已採取之應對措施。雙方共同決定是否通報主管機關。

## 第 7 條 稽核權

機構得每年一次以書面要求平台提供：
- ISO 27001 / SOC 2 報告（若已取得）
- RLS 政策設定快照
- 次處理者清單與其 DPA 摘要
平台保留商業敏感資訊之合理遮蔽權。

## 第 8 條 契約終止

8.1 契約終止後 30 日內，平台應依機構選擇：(a) 將機構資料以結構化格式（CSV / JSON）匯出交付，或 (b) 永久刪除（含備份）。
8.2 平台應於完成後出具**資料銷毀證明**。

## 第 9 條 損害賠償與責任上限

平台對機構之累積責任以**前 12 個月服務費總額**為上限，但因故意或重大過失致個資外洩者不在此限。

## 第 10 條 準據法

本協議依中華民國法律，合意以台灣台北地方法院為第一審管轄法院。
