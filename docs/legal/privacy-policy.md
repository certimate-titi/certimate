# CertiMate (TiTi) 隱私權政策（草案 v0.1）

> **聲明**：本草案非律師意見，僅供產品團隊與法律顧問討論。**上線前需專業律師覆核**，並依《個人資料保護法》（PDPA）向主管機關備查（如有要求）。
> 最後更新：2026-05-08

## 1. 蒐集者

蒐集機構：本公司（CertiMate / TiTi 服務營運主體）。
法源依據：《個人資料保護法》第 8 條告知義務。

## 2. 蒐集目的

- **152** 廣告或商業行為管理
- **069** 契約、類似契約或其他法律關係事務
- **090** 消費者、客戶管理與服務
- **148** 網路購物及其他電子商務服務
- **109** 教育或訓練行政

## 3. 蒐集個資類別

| 類別 | 範例 | 來源 |
|------|------|------|
| C001 識別個人 | 姓名、電子郵件、Google SSO ID | 註冊 / Firebase Auth |
| C002 識別財務 | 訂閱方案、ECPay 交易序號（**不存信用卡卡號**） | 綠界金流 |
| C003 政府識別 | 學校 / 機構名稱（B2B 簽約用） | EDU console |
| C011 個人描述 | 備考目標證照、學習進度 | 用戶自填 |
| C132 未分類資料 | 上傳之 PDF、答題紀錄、AI 對話 | 服務使用過程 |

**未成年用戶**：13–18 歲須法代同意；13 歲以下不開放註冊。

## 4. 利用期間、地區、對象、方式

- **期間**：帳號存續期間 + 終止後 **90 日**保留期（供誤刪復原）→ 永久刪除（含資料庫硬刪 + GCS 物件刪除）。
- **地區**：主要儲存於 GCP `asia-east1`（台灣彰濱）。AI 推論可能傳輸至 Google US（Gemini）、Anthropic US（Claude）、OpenAI US；傳輸前已**去識別化**並依各供應商之 DPA 處理。
- **對象**：本公司及承包之雲端供應商（Google Cloud、Anthropic、OpenAI、Voyage、ECPay、Firebase）。**不販售個資予第三方**。
- **方式**：自動化系統處理 + 人工有限度檢視（僅故障排除）。

## 5. 用戶權利（PDPA §3）

您得隨時行使下列權利：

1. 查詢、請求閱覽
2. 請求製給複本
3. 請求補充或更正
4. 請求停止蒐集、處理或利用
5. 請求刪除

行使方式：登入後於「帳號設定 → 我的資料」自助下載 / 刪除，或來信 privacy@certimate.example。本公司於 **15 日內**回覆（必要時延長 15 日）。

## 6. Cookie 政策

- **必要 Cookie**：JWT（`certimate_jwt_token`）、Session、CSRF — 不可關閉
- **功能 Cookie**：使用者偏好（深色模式、語言）— 可關閉
- **分析 Cookie**：GA4（去識別化）、Sentry 錯誤監控 — 可於 Cookie Banner 拒絕

## 7. AI 訓練資料聲明

- 您的上傳內容、答題紀錄、AI 對話 **不會用於訓練**第三方 LLM（已於 Gemini / Anthropic / OpenAI 之 API 設定關閉 data retention for training）。
- 平台得使用**去識別化、聚合化**統計改善 prompt 與檢索品質。
- B2B 機構之學生資料另依 DPA 條款處理（學生資料禁用於任何模型訓練）。

## 8. 資料安全

- 傳輸：全程 HTTPS / TLS 1.2+
- 儲存：PostgreSQL 含 RLS（tenant_id 隔離）+ pgvector；敏感金鑰經 GCP Secret Manager
- 存取：最小權限原則 + 雙因素驗證（內部）
- 事故通報：發生個資外洩將於 **72 小時內**通知主管機關及受影響用戶

## 9. 不提供之後果

若您拒絕提供必要個資（如電子郵件），將無法完成註冊或使用核心功能。

## 10. 政策更新

本政策修訂將於網站公告並於登入時提示；重大變更（如新增蒐集目的）需重新取得同意。
