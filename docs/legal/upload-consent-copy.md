## B. YouTube / 影片講座解析 — Fair Use 聲明文案

### B1. 連結輸入框上方說明（藍色 info banner）

```
ⓘ 影片解析說明

CertiMate 僅擷取影片字幕 / 自動轉錄文字進行 AI 摘要與題目生成，
不會下載、轉檔或重製影片內容。此功能基於以下原則：

• 學習目的：用於您個人備考之非營利學習
• 引用比例：僅生成摘要與衍生題目，不重現原影片
• 來源標示：所有解析結果保留原始 YouTube 連結
• 權利人請求：講者 / 創作者得來信 takedown@certimate.example
  要求移除特定影片之解析結果，我們將於 7 日內處理

此用途屬《著作權法》第 65 條合理使用之衡量範圍，但仍可能
存在法律爭議；您使用此功能即表示理解並承擔相關風險。
```

## C. 通用注意事項（給工程師）

1. **記錄同意**：勾選 A1 時須寫入 `user_consent_logs` 表，欄位含 `user_id` / `consent_type` / `version` / `ip` / `user_agent` / `consented_at`，作為事後舉證。
2. **版本化**：本文案任何文字變動須遞增 `version`（如 v0.1 → v0.2），舊用戶於新版本上線時重新勾選。
3. **未成年判斷**：若帳號 `birth_year` 顯示未滿 18，須額外顯示「請確認您的法定代理人已知悉並同意」之第二勾選框。
4. **Takedown 流程**：`takedown@certimate.example` 信箱須有人值班，建議納入 SLA 7 日內回覆。
5. **A/B 測試禁區**：法律同意文案**不得**作為 A/B 測試變因；如需調整必經法務再審。
