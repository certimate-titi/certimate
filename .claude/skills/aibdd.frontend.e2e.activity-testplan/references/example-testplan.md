# 範例：名單激活 — 驗收測試計畫

以下範例展示從「名單激活.activity」推導出的完整測試計畫。

## 輸入：名單激活.activity

```
[ACTIVITY] 名單激活
[ACTOR] 管理者 -> {specs/actors/管理者.md}
[ACTOR] 系統 -> {specs/actors/系統.md}

[STEP:1] @管理者 {specs/features/journey/設定階段自動化.feature}
[STEP:2] @管理者 {specs/features/journey/設定階段SOP.feature}
[STEP:3] @管理者 {specs/features/journey/激活名單.feature}
[DECISION:3a] 該階段是否有 Automation
  [BRANCH:3a:有] @系統 {specs/features/journey/執行階段自動化.feature}
  [BRANCH:3a:無] {specs/ui/無自動化提示.md}
[MERGE:3a]

[DECISION:3b] 該階段是否綁定 SOP
  [BRANCH:3b:有] @系統 {specs/features/journey/派發SOP任務.feature}
  [BRANCH:3b:無] {specs/ui/無SOP提示.md}
[MERGE:3b]

[STEP:4] @管理者 {specs/features/journey/推進名單階段.feature}
[STEP:5] @管理者 {specs/features/journey/查詢名單激活狀態.feature}
[END]
```

## 路徑分析

- DECISION:3a（2 分支：有/無 Automation）
- DECISION:3b（2 分支：有/無 SOP）
- 兩個 DECISION 為串聯（非嵌套），取笛卡爾積 = 2 × 2 = **4 條路線**

## 產出：名單激活.testplan.md

---

```markdown
# 名單激活 — 驗收測試計畫

> 來源：specs/activities/名單激活.activity

> 測試路線數：4

| 3 | 名單激活 — 無自動化 + 有SOP | 3a:無, 3b:有 | 7 |
| 4 | 名單激活 — 無自動化 + 無SOP | 3a:無, 3b:無 | 7 |

## 情境 1：名單激活 — 有自動化 + 有SOP

**路線描述**：管理者設定自動化與SOP後激活名單，系統執行自動化並派發SOP任務，管理者推進階段並查詢狀態。

| # | 操作描述 | 預期結果 |
|---|---------|---------|
| 1 | 進入「Journey 設定」頁面，在階段自動化區塊選擇觸發條件與自動化動作，點擊『儲存』 | - 顯示成功訊息「自動化設定已儲存」<br>- 該階段卡片上出現「自動化」標籤圖示 |
| 2 | 切換到「SOP 設定」分頁，選擇一個 SOP 範本綁定至該階段，點擊『儲存』 | - 顯示成功訊息「SOP 已綁定」<br>- 該階段卡片上出現「SOP」標籤圖示 |
| 3 | 回到名單頁面，選取目標名單，點擊『激活』按鈕 | - 彈出確認對話框「確定要激活此名單？」<br>- 點擊『確定』後名單狀態變為「進行中」 |
| 4 | （系統自動觸發）等待頁面更新 | - 名單詳情頁出現「自動化執行中」狀態提示<br>- 活動紀錄區塊顯示自動化執行的日誌項目 |
| 5 | （系統自動觸發）等待 SOP 任務派發完成 | - 名單詳情頁的「待辦任務」區塊出現新的 SOP 任務項目<br>- 任務狀態顯示為「待處理」 |
| 6 | 點擊名單的『推進階段』按鈕，選擇目標階段後確認 | - 名單階段標籤更新為新階段名稱<br>- 階段進度條前進一格 |
| 7 | 點擊『查詢狀態』或進入名單詳情頁 | - 頁面顯示完整的激活歷程時間軸<br>- 可見自動化執行紀錄與 SOP 任務紀錄<br>- 當前階段正確顯示 |
```

## 推導過程說明

### 節點序列
```
STEP:1（設定階段自動化）
STEP:2（設定階段SOP）
STEP:3（激活名單）
DECISION:3a（有/無 Automation）→ 2 分支
MERGE:3a
DECISION:3b（有/無 SOP）→ 2 分支
MERGE:3b
STEP:4（推進名單階段）
STEP:5（查詢名單激活狀態）
```

### 路線展開
```
DECISION:3a × DECISION:3b = 2 × 2 = 4 條路線

路線 1：STEP1 → STEP2 → STEP3 → BRANCH:3a:有 → BRANCH:3b:有 → STEP4 → STEP5
路線 2：STEP1 → STEP2 → STEP3 → BRANCH:3a:有 → BRANCH:3b:無 → STEP4 → STEP5
路線 3：STEP1 → STEP2 → STEP3 → BRANCH:3a:無 → BRANCH:3b:有 → STEP4 → STEP5
路線 4：STEP1 → STEP2 → STEP3 → BRANCH:3a:無 → BRANCH:3b:無 → STEP4 → STEP5
```

### 情境命名
- 路線 1：「有自動化 + 有SOP」— 兩個分支都走「有」
- 路線 2：「有自動化 + 無SOP」— 第一個走「有」，第二個走「無」
- 路線 3：「無自動化 + 有SOP」— 第一個走「無」，第二個走「有」
- 路線 4：「無自動化 + 無SOP」— 兩個分支都走「無」
