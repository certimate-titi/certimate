# QA 稽核檢查清單模板

此模板供 AI QA Architect 在執行稽核時逐項勾選使用。

---

## 前置檢查

- [ ] 確認稽核範圍（Feature 編號 / 頁面路徑）
- [ ] 確認 `.feature` 檔案已定位並讀取
- [ ] 確認 UI 可存取（截圖 / URL / dev server）
- [ ] 確認使用者角色與測試帳號

## Top-Down 檢查項

### Scenario 層級
- [ ] 每個 Scenario 都有對應的 UI 流程
- [ ] Happy path 完整覆蓋
- [ ] Error path 完整覆蓋（錯誤輸入、權限不足、網路失敗）
- [ ] 邊界條件覆蓋（空值、最大長度、特殊字元）
- [ ] 並發/競態條件（若適用）

### Step 層級
- [ ] Given 步驟的前置資料可在 UI 建立
- [ ] When 步驟有對應的 UI 操作元件
- [ ] Then 步驟的預期結果在 UI 可觀察
- [ ] Background 步驟的共用前置條件正確

### Feature 層級
- [ ] Feature 描述與實際功能一致
- [ ] Rule 分組邏輯合理
- [ ] Scenario Outline 的 Examples 涵蓋關鍵組合
- [ ] `@ignore` 標籤的 Scenario 有明確原因

## Bottom-Up 檢查項

### 互動元件
- [ ] 所有按鈕都有對應 Scenario
- [ ] 所有表單欄位都有驗證 Scenario
- [ ] 所有導航連結都有覆蓋
- [ ] 下拉選單/Modal/Toast 等動態元件已檢查
- [ ] 鍵盤快捷鍵（若有）已檢查

### 狀態變化
- [ ] Loading 狀態有正確顯示
- [ ] Empty state（空資料）有適當提示
- [ ] Error state 有明確錯誤訊息
- [ ] Success state 有適當回饋

## UX 摩擦力檢查項

### 可發現性
- [ ] 主要 CTA（Call-to-Action）明顯可見
- [ ] 功能入口不超過 3 次點擊可達
- [ ] 麵包屑/導航清楚標示當前位置

### 可理解性
- [ ] 按鈕文字使用動詞（「建立」而非「新增」）
- [ ] 表單標籤清晰無歧義
- [ ] 錯誤訊息說明原因 + 解決方法
- [ ] 專業術語有 tooltip 說明

### 操作效率
- [ ] 必填欄位數量合理
- [ ] 有預設值減少輸入
- [ ] 支援批次操作（若適用）
- [ ] 表單支援 Tab 鍵切換

### 錯誤恢復
- [ ] 破壞性操作有確認對話框
- [ ] 可返回上一步修改
- [ ] 表單驗證為即時（非提交後）

### 視覺一致性
- [ ] 色彩使用符合設計系統
- [ ] 間距/字型/圓角一致
- [ ] Icon 風格統一
- [ ] 響應式斷點正確（Mobile/Tablet/Desktop）

## 可及性 (a11y)

- [ ] 所有互動元件有 ARIA label
- [ ] Tab 焦點順序合理
- [ ] 色彩對比度 >= 4.5:1（AA 標準）
- [ ] 圖片有 alt 文字
- [ ] 表單元件有 label 綁定
