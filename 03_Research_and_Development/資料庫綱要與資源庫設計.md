# 資料庫綱要與資源庫設計 (Database & Vector Store Schema)

## 1. 關聯式資料庫 (Relational DB - PostgreSQL)

### Users 表 (核心帳號與權限)
- `id` (UUID, Primary Key)
- `email` (String, Unique)
- `subscription_tier` (Enum: `FREE`, `PRO_199`)
- `subscription_status` (Enum: `ACTIVE`, `CANCELED`, `PAST_DUE`)
- `current_period_end` (Timestamp)
- `stripe_customer_id` (String, Nullable)
- `created_at` (Timestamp)

### User_Usage_Logs 表 (防濫用與配額追蹤)
- `id` (UUID, Primary Key)
- `user_id` (UUID, Foreign Key)
- `billing_cycle_start` (Timestamp)
- `claude_pro_queries_count` (Integer) -> 用於限制 199 方案的高階模型調用 (如每月 50 次)
- `vision_ocr_pages_count` (Integer) -> 用於限制圖片/手寫數學的解析量
- `youtube_minutes_parsed` (Integer)
- `documents_uploaded_count` (Integer)

### Documents 表 (教材與多媒體資源庫)
- `id` (UUID, Primary Key)
- `user_id` (UUID, Foreign Key)
- `source_type` (Enum: `PDF`, `MARKDOWN`, `YOUTUBE_URL`, `IMAGE_MATH`)
- `title` (String)
- `source_url` (String, S3 Path 或 YouTube 原始連結)
- `mcp_parsed_transcript_url` (String, Nullable, 存放 MCP 抓下來的純文字逐字稿)
- `status` (Enum: `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`, `RATE_LIMITED`)
- `file_size_bytes` (Integer)
- `vision_required` (Boolean) -> 標記是否含有複雜數學公式或圖片需走 Vision Pipeline

### Exams 表 (生成的測驗卷)
- `id` (UUID, Primary Key)
- `document_id` (UUID, Foreign Key)
- `title` (String)
- `exam_type` (Enum: `MOCK_EXAM`, `SPACED_REPETITION`, `FLASHCARD_SET`)
- `score` (Integer, Nullable)
- `created_at` (Timestamp)

### Questions 表 (多模態題庫)
- `id` (UUID, Primary Key)
- `exam_id` (UUID, Foreign Key)
- `question_type` (Enum: `MULTIPLE_CHOICE`, `FILL_IN_BLANK`, `MATH_FORMULA`)
- `content_text` (Text)
- `content_image_url` (String, Nullable, 用於理工科圖片題)
- `correct_answer` (String)
- `explanation_markdown` (Text, 支援 KaTeX 語法)
- `citation_chunk_id` (UUID, 溯源對照：此題源自講義的哪一段，方便 NotebookLM 式體驗)

### User_Answers 表 (錯題與學習追蹤)
- `id` (UUID, Primary Key)
- `user_id` (UUID, Foreign Key)
- `question_id` (UUID, Foreign Key)
- `is_correct` (Boolean)
- `user_choice` (String)
- `ebbinghaus_next_review` (Timestamp) -> 艾賓浩斯間隔重複演算法排程
- `ebbinghaus_multiplier` (Float) -> 答錯頻率權重

## 2. 向量資料庫 (Vector Database - Pinecone)
- **Namespace**: 依據 `document_id` 隔離資料。
- **Metadata**:
  - `page_number` (Integer, 用於溯源追蹤)
  - `chunk_index` (Integer)
  - `content_type` (Enum: `TEXT`, `IMAGE_DESCRIPTION`, `YOUTUBE_TRANSCRIPT`)
  - `timestamp_start` / `timestamp_end` (String, 如果是 YouTube 影片，記錄該段落的時間軸)
- **用途**：當進行 RAG (考題生成或解惑) 時，能精準提取對應的上下文，並在 UI 上標示出處 (Citation)。

## 3. 快取層庫 (Cache - Redis / Memorystore)
- **用途**：大幅降低重複運算成本與提升回應速度。
- **Keys 設計**：
  - `ratelimit:user:{user_id}:vision_ocr` -> 追蹤 Vision API 呼叫頻率
  - `ratelimit:user:{user_id}:export` -> 防禦 Hit-and-Run 極端高頻匯出
  - `doc_hash:{sha256}` -> 記錄該講義/影片是否已經被其他使用者解析過。若是，則可直接秒取快取結果，達成「邊際成本遞減」的商業利益。

## 4. B2B / Ultra 旗艦版擴充預留 (Phase 4)
為了未來無縫銜接生態系整合，系統核心預留以下外掛點：
- **External_Sync_Jobs 表**：記錄與 Notion, Google Drive 或 AWS 官方課綱的定時同步排程 (Cron Job)。
- **Organizations 表**：提供給補習班/教育機構的 B2B 多租戶 (Multi-tenant) 管理，建立老師與學生的從屬關係 (Role-based Access Control)。
