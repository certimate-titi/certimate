# 資源庫與互動心智圖頁 (Knowledge Base & Mind Map)

## 📌 頁面定位與目標

幫助使用者管理已上傳的繁雜教材，並透過 AI 將非結構化的資料轉化為結構化的視覺圖表。核心目標是 **消除閱讀長篇大論的阻力**，並提供 **所見即所得的溯源體驗**。

## 🧩 核心區塊設計 (Sections)

### 1. 資源列表區 (Resource List)

- **展示方式**：卡片式 (Card View) 或 列表式 (List View) 切換。
- **資源屬性展示**：
  - 文件名稱 / YouTube 影片縮圖與標題。
  - 上傳日期、檔案大小或影片長度。
  - AI 狀態標籤 (解析中 / 解析成功 / 解析失敗)。
  - 資源的衍生數據：從此資源已生成的測驗題數。
- **搜尋與篩選**：透過檔名或自動提取的 Tags 進行快速搜尋。

### 2. 互動式心智圖檢視區 (Interactive Mind Map Workspace)

這是本頁面的「核心 UX 亮點」。點擊任一解析完畢的資源，即進入此全螢幕視圖。

- **動態節點 (Nodes)**：由 AI 萃取出的章節架構或知識樹。支援縮放 (Zoom) 與拖曳 (Pan)。
- **色彩語意**：依據使用者的測驗結果，自動為節點上色（例如常錯的知識點顯示紅色，精通的顯示綠色），也就是 **「視覺化弱點地圖」**。

### 3. 溯源面板 (Citation Panel)

當使用者在心智圖上點擊任一知識節點時，畫面右側或側邊欄會平滑滑出此面板：

- **若來源為 PDF/MD 文檔**：
  - 渲染該節點對應的 Markdown 原文。
  - 標示出「出自第 X 頁」。
- **若來源為 YouTube 影片**：
  - 嵌入縮小版的 YouTube Player。
  - 影片會 **自動跳轉並播放** 該節點對應的時間軸片段。

### 4. (Ultra 用戶專屬) 同步設定區 (Sync Settings)

- **Notion 整合**：使用者可貼上 Notion Database ID 或透過 OAuth 授權，設定每日背景同步頻率。
- **Google Drive 整合**：授權存取特定資料夾內的新 PDF，系統自動撈取並建立 Embedding。

## 💻 技術面/實作建議

- **心智圖渲染**：建議使用 `React Flow` 或 Apache ECharts 的 Graph/Tree 模組來渲染流暢可互動的節點網路。
- **影片控制**：YouTube 必須串接 YouTube IFrame Player API 以精準控制 `player.seekTo(seconds)` 行為。
- **版面配置**：心智圖與溯源面板適合採用 Split Pane 的設計，讓使用者可自由拖曳調整兩者的寬度比例。
