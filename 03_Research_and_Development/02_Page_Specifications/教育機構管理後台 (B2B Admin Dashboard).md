# 教育機構管理後台 (B2B Admin Dashboard)

## 📌 頁面定位與目標

這是一個專屬於 **Ultra 旗艦版訂閱戶** (如補習班班主任、企業內訓主管) 的 B2B 視角。目標是提供強大的 **批量管理工具** 與 **宏觀的學生能力剖析**，幫助機構有效追蹤整體學習成效。

## 🧩 核心功能分頁 (Tabs)

本頁面為獨立的 Admin 路由 (例如 `/admin/...`)，避免與一般學生的視角混淆。

### 1. 機構總覽儀表板 (Organization Overview)

- **全局數據卡片**：
  - 活躍學生總數。
  - 班級平均模擬考分數 / 預測通過率。
  - 本週共完成的模擬題庫總量。
- **近期活動動態牆 (Activity Log)**：例如「王大明在 AWS 模考獲得 92 分」、「李小美上傳了新的數學講義」。

### 2. 學生名單與群組管理 (Students & Cohorts)

- **批量匯入工具**：
  - 提供 CSV 模板下載，支援一鍵匯入上百位學生名單 (Name, Email, Cohort Group)。
  - 系統自動寄發「邀請啟動帳號」的註冊信給名單上的學生。
- **分組標籤**：將學生分群（例如：雲端基礎班 A 班、PMP 衝刺班 B 班），方便後續派發專屬考卷。
- **個別學生追蹤**：點擊任一學生，可查看該學生的個人雷達圖與登入頻率。

### 3. 考卷派發系統 (Assignment Dispatch)

- **製作官方測驗**：
  - 主管可從機構的「共用對齊資源庫」中，使用 AI 預先生成一份標準考卷，並手動微調題目。
- **派送與期限**：
  - 指定目標群組（如 A 班全體）。
  - 設定繳交期限 (Deadline) 與開放測驗的時間窗口。
  - 設定為「限制模式」(例如鎖定跳出全螢幕)，以落實防弊。

### 4. 班級弱點分析圖表 (Class-wide Analytics)

- **全局錯題排行榜 (Top Mistakes)**：
  - 列表顯示「本週全班答錯率最高的 Top 10 考題」。
  - 幫助老師在實體/線上授課時，精準針對這些題目進行講解。
- **章節掌握度熱點圖 (Heatmap)**：
  - X 軸為知識章節，Y 軸為各組學生。以顏色深淺標示各班級在不同單元的弱點。

## 💻 技術面/實作建議

- **RBAC (Role-Based Access Control) 權限設計**：後端必須嚴格驗證使用者的 Role 為 `admin` 或 `teacher` 才能存取此組 API。
- **大量資料表渲染 (Data Grid)**：建議採用如 AG Grid 或是 React Table 等高效能的表格組件，支援分頁 (Pagination)、排序 (Sorting) 與匯出 Excel 功能。
- **CSV 匯入處理**：CSV 檔案上傳前端應先利用 `PapaParse` 等套件進行基本格式檢核，減少後端 API 不必要的 Invalid Data 負擔。
