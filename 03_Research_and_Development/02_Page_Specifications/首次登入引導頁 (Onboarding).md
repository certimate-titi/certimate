# 首次登入引導頁 (Onboarding)

## 📌 頁面定位與目標

新用戶首次登入後的 **必經引導流程**，目標是在最短時間內建立使用者的專屬學習歷程，讓後續所有功能（儀表板、考題生成、AI 教練）都能提供 **個人化體驗**。設計上追求低摩擦、高完成率，讓使用者感受到「系統為我量身打造」的第一印象。

## 🔀 觸發與路由邏輯

- **觸發條件**：使用者完成註冊驗證後首次登入，且 `onboarding_completed === false`。
- **強制性**：此頁為半強制——使用者無法直接跳至儀表板，但可在各 Step 內跳過非必填欄位。
- **唯一必要條件**：至少選擇一個備考科目（Step 2），否則無法完成引導。
- **完成後**：將 `onboarding_completed` 標記為 `true`，後續登入不再觸發。

## 🧩 核心區塊設計 (Steps)

### Step 1 — 歡迎與基本資訊

- **歡迎動畫**：品牌 Logo 搭配簡短動態效果（Lottie 或 CSS Animation），營造溫暖的第一印象。
- **顯示名稱輸入**：
  - 預設值取 Email `@` 前的字串（例如 `alice@example.com` → `alice`）。
  - 使用者可自行修改或直接點「下一步」跳過。
- **進度指示器 (Progress Bar)**：頂部顯示 Step 1/4 的進度條，讓使用者知道流程不長。

### Step 2 — 選擇備考科目（核心步驟）

此為整個 Onboarding 的核心，支援 **同時備考多個科目**，每科獨立建立學習歷程。

- **科目探索區**：
  - **分類標籤 (Category Tabs)**：IT / 金融 / 語言 / 醫療 / 公務員 / 其他，點擊後篩選下方科目清單。
  - **搜尋欄**：即時模糊搜尋，支援中英文科目名稱（如輸入「AWS」或「雲端」皆可命中 AWS SAA）。
  - **科目卡片 (Subject Cards)**：每張卡片顯示科目名稱、簡短描述、熱門度標籤（如「本月 TOP 10」）。點擊即選中，再次點擊取消。
- **已選科目面板 (Selected Subjects Panel)**：
  - 固定於畫面底部或右側，列出已選取的科目。
  - 每個科目展開後可設定：
    - **預計考試日期**：日期選擇器，預設為 3 個月後。
    - **自評程度**：三段式選擇——初學者 / 有基礎 / 進階複習，以 Radio Button 或 Segmented Control 呈現。
  - 每個科目旁附「移除」按鈕（X icon）。
- **驗證規則**：至少選擇 1 個科目才可進入下一步；未選擇時「下一步」按鈕置灰並顯示提示。

### Step 3 — 學習偏好設定

- **每日可投入學習時間**：
  - 快速選項按鈕組：15 分鐘 / 30 分鐘 / 1 小時。
  - 「自訂」選項：點擊後展開數字輸入框（分鐘），支援 5~480 分鐘。
  - 預設選中「30 分鐘」。
- **偏好學習方式**：
  - 三張圖文卡片供點選：
    - **大量刷題模式**：「以題目驅動，快速找出盲點」。
    - **觀念理解優先**：「先讀懂再做題，穩紮穩打」。
    - **混合模式**：「系統智慧搭配，兼顧理解與練習」（預設推薦）。
- 此步驟全為選填，使用者可直接「下一步」採用預設值。

### Step 4 — 確認與啟動

- **摘要卡片**：
  - 顯示名稱、所有備考科目（含各科考試日期與自評程度）、每日學習時間、偏好方式。
  - 每個區塊旁附「編輯」按鈕，點擊可跳回對應 Step 修改。
- **CTA 按鈕**：「開始我的學習旅程」，設計為大尺寸、高對比、帶有微動畫（如 ripple 效果）。
- **點擊後行為**：
  1. 顯示全螢幕的啟動動畫（例如火箭發射或書本翻開的 Lottie 動畫），持續 1.5~2 秒。
  2. 背景同步執行：為每個備考科目建立獨立的學習歷程記錄、初始化學習排程。
  3. 動畫結束後自動導向「個人儀表板首頁」。

## 🔄 後續管理入口

Onboarding 完成後，使用者仍可隨時調整：

- **個人儀表板**：科目切換器旁的「+ 新增備考科目」按鈕，開啟與 Step 2 相同的科目選擇介面。
- **會員中心**：「備考科目管理」專區，可新增科目、修改考試日期/自評程度、移除科目（移除時學習紀錄封存而非刪除）。

## 💻 技術面/實作建議

- **狀態管理**：整個 4 步驟的表單資料建議使用 `React Hook Form` + `Zustand` 或 Context 暫存，避免跨步驟時資料遺失。使用者每次「下一步」時將資料暫存至 localStorage，以防頁面意外關閉。
- **科目資料來源**：科目清單建議以後端 API 提供（支援分頁與搜尋），而非前端硬編碼，以便後續擴充。
- **動畫**：歡迎動畫與啟動動畫採用 Lottie（輕量且跨平台）；進度條與 Step 切換使用 Framer Motion 過渡動畫。
- **RWD (響應式設計)**：
  - 手機端 Step 2 的「已選科目面板」改為可展開的底部抽屜 (Bottom Sheet)。
  - Step 4 摘要卡片改為垂直堆疊。
- **無障礙 (a11y)**：所有步驟需支援鍵盤導航 (Tab/Enter)，進度指示器需有 `aria-label`。
