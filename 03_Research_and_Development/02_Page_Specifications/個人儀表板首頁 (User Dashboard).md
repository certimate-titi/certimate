# 個人儀表板首頁 (User Dashboard)

## 📌 頁面定位與目標

作為使用者登入後的第一個主畫面，這是 CertiMate 系統的指揮中心。目標是讓使用者能 **一眼掌握學習進度 (Progress Tracking)** 並提供 **最直覺的核心操作入口 (Quick Actions)**。

## 🧩 核心區塊設計 (Sections)

### 0. 科目切換器 (Subject Switcher)

位於頁面頂部（導覽列下方），讓備考多科的使用者快速切換上下文：

- **切換控制**：水平分頁標籤 (Tabs) 或下拉選單，每個標籤顯示科目名稱、考試倒數天數，以及該科目的專屬**任務模式徽章** (Sprint / Standard / Mastery)。
- **數據聯動**：切換科目後，下方所有區塊（雷達圖、指標卡片、待辦提醒、錯題複習）的數據皆對應更新。
- **新增入口**：最末端固定顯示「+ 新增備考科目」按鈕，點擊後開啟科目選擇介面（與 Onboarding Step 2 相同元件）。
- **僅備考單科時**：科目切換器仍顯示但僅有一個標籤，不影響版面。

### 1. 歡迎與概覽區 (Welcome & Overview)

- **個人化問候**：例如 "Ready to crush your PMP exam, Alex?"（依當前選中科目動態調整）。
- **當前任務模式資訊**：
  - 顯示該科目的任務模式徽章（如 🔥 Sprint Mode, 🏃 Standard Mode, 🌳 Mastery Mode）。
  - Hover 或點擊徽章時，會展開一個互動式 Tooltip 或小彈窗 (Modal)，提供以下資訊讓使用者明白當前階段的設計目的：
    - **模式目標 (Goal)**：解釋為何目前處於此模式（例如：「距離考試剩餘不到 14 天，系統已自動為您切換至衝刺狀態。」）。
    - **加強範圍與策略 (Scope & Strategy)**：說明當前系統的訓練重點（例如：「目前重點加強您曾答錯的高頻題目與未觸及的盲點，暫時忽略已內化的基礎，追求短期高報酬。」）。
    - **考題配分權重 (Weighting)**：以視覺化比例條列出當前系統配題邏輯（例如：「未考知識 40% / 曾錯盲點 50% / 其他 10%」）。
- **每日學習連勝 (Streaks)**：位於問候語旁，顯示連續學習天數與火焰圖示，並配備「斷連保護」冰凍機制以避免挫折。
- **核心指標卡片 (Metric Cards)**：
  - 即將到來的考試倒數計時器（對應當前選中科目的考試日期）。
  - 累積完成的模擬題數。
  - 整體系統預測的及格率 / 答對率區間。
- **能力分佈雷達圖 (Skill Radar)**：利用 Chart.js 等圖表套件，展示當前選中科目各知識領域的強弱項。**此雷達圖的數據會直接連動至後臺的「考題產生器」，當系統依照「任務模式」調配完大比例後（如要求 40% 為新題目），會進一步根據雷達圖自動優先抽取您的弱點領域進行出題設計。**

### 2. 快速上傳區 (Upload Widget)

這是此頁面最重要的行動呼籲 (Call to Action)，採用大面積的拖曳區塊與分頁設計：

- **Tab A (實體檔案)**：支援拖曳或點選上傳 PDF、Markdown、PowerPoint、Word 文件或螢幕截圖/手寫照片。
- **Tab B (影音連結)**：
  - 一個居中放大的 URL 輸入框。
- **隱性版權同意機制 (Implicit Consent)**：
  - 為避免干擾學習並消除操作摩擦，取消強制勾選框。改為在「一鍵解析與生成心智圖」的超級大按鈕**下方**，放置一行視覺高度弱化（如超小字體、淡灰無邊框）的免責聲明：「*點擊上傳即代表您保證擁有此檔案／影片的合法使用授權，且同意不公開散佈生成的內容。*」
  - 當使用者點擊主按鈕即在行為上視為同意，兼顧 UX 流暢度與法律防護。
- **狀態回饋**：當上傳或解析中時，必須提供平滑的進度條或 Skeleton 骨架屏動畫。

### 3. 動態提醒與待辦清單 (Action Items)

依據使用者的學習行為，由系統動態產生的建議清單：

- **每日微任務 (Daily Quests)**：例如「複習昨天答錯的 5 題」或「完成 15 題快速測驗」，完成可獲取經驗值或觸發成就。
- **近期錯題複習**：例如 3 天前做錯的 15 題，提示「依照遺忘曲線，現在是複習的最佳時機」。
- **未完成的考卷**：顯示上次中斷的模擬測驗進度 (例如 "AWS SAA Mock #3 - 50% Completed")。
- **新解析完成的講義**：提示知識心智圖已生成完畢，點擊查看。
- **(Ultra 用戶專屬) 匿名共同備考感**：顯示如「目前有 368 位考生一起奮鬥」等同時段同機構或同證照的活躍使用者數據，創造陪伴氛圍但不暴露個資。

### 4. 導覽列 (Navigation)

全站通用的 導覽列，包含：

- 🏠 儀表板 (Dashboard)
- 📚 資源庫與心智圖 (Knowledge Base)
- 📝 模擬測驗 (Mock Exams)
- 📖 錯題本 (Review Book)
- ⚙️ 設定與訂閱 (Settings)

## 💻 技術面/實作建議

- **資料預取 (Data Fetching)**：這頁的圖表與數據較多，建議使用 SWR 或 React Query 進行快取與 Optimistic UI 更新。
- **RWD (響應式設計)**：雷達圖與上傳區塊在手機端需要調整堆疊順序，確保上傳區塊始終在第一屏可見。
