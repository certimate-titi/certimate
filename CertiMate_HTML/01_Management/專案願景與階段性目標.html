專案願景與階段性目標

1. 專案願景 (Vision)

成為華語圈首屈一指的「AI 賦能證照考試平台」，打破傳統單向輸入的學習模式，利用生成式 AI 技術將龐雜的考試資源轉化為個人化的學習體驗，幫助每位學習者以最高效率取得專業認證。

2. 階段性目標 (Phases & Milestones)

Phase 1: MVP (Minimum Viable Product) 開發與驗證

  • 目標：完成核心 AI 資源解析與考題生成工作流。
  • 關鍵成果 (KR)：
    1. 支援 PDF/Markdown 格式資源上傳。
    2. 自動生成選擇題、名詞解釋等題型 (參考既有之 AI應用規劃能力鑑定_MOC 模式)。
    3. 提供基礎的錯題解析與觀念釐清功能。

Phase 2: 平台化與封閉測試 (Closed Beta)

  • 目標：建立網站入口，邀請初期使用者 (Seed Users) 進行測試。
  • 關鍵成果 (KR)：
    1. 完成使用者註冊與登入系統。
    2. 確保使用者自行上傳之中型 PDF (約 50 頁) 能夠在 3 分鐘內完成解析與考題生成。
    3. 收集 100 位使用者的深度回饋與評分，優化解析精準度。

Phase 3: 商業化與推廣 (Go-To-Market)

  • 目標：導入付費訂閱 (199 TWD) 機制，並啟動數位行銷。
  • 關鍵成果 (KR)：
    1. 實作金流串接 (Stripe / 綠界)。
    2. 達到 1,000 位活躍 Pro 付費使用者。
    3. 完善進階工具功能 (例如：無限制 YouTube 轉考題、手寫數學公式解析)。

Phase 4: 生態系整合與 Ultra 旗艦方案 (Ecosystem Integration)

  • 目標：從單點的 SaaS 工具進化為與教育生態系 (LMS / 官方課綱) 深度整合的平台，推出針對極重度考生或 B2B 教育機構的 Ultra 旗艦版 (例如 499~999 TWD/月)。
  • 關鍵成果 (KR)：
    1. API 級別的課綱自動同步：與外部官方證照網站 (如 AWS Training、Cloud Native Computing Foundation) 建立自動化爬蟲或 API 串接。當官方考綱更新時，Ultra 用戶的學習地圖會「自動產生新版模擬考卷」，無需手動重新上傳講義。
    2. Notion/Google Drive 雙向整合：Ultra 用戶可授權存取個人的 Notion 資料庫或 Google Drive 資料夾，系統會在背景以 Cron Job 自動重新 Embedding 被修改過的筆記，隨時維持考題與個人筆記的同步率。
    3. 補習班/教育機構專屬特權：提供機構批量匯入學生名單、派發統一考卷並回收全局成績弱點分析圖表的儀表板 (Dashboard)。
