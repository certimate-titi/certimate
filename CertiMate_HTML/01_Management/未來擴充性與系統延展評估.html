未來擴充性與架構延展評估 (Scalability & Extensibility)

CertiMate 目前採用的結合「GCP Serverless 無伺服器架構」與「MCP (Model Context Protocol)」的微服務混合設計，賦予了專案極高的未來擴充與轉型便利性。

當平台度過早期的 PoC 階段並開始獲利後，可以輕易且低門檻地往以下四個維度進行擴充：

1. 流量層級的無縫擴容 (Traffic Scalability)

  • Cloud Run 的 Auto-Scaling：目前的運算核心 (前後端 API 與 MCP 爬蟲伺服器) 都架構在 Cloud Run 上。這意味著當考季來臨、流量瞬間從 100 人暴增到 10,000 人時，系統會自動在幾秒內長出新的實例 (Instances) 來承載流量，流量退去後又自動縮容至 0。完全不需要人工介入開機或關機。
  • 資料庫升級平滑：初期考量成本使用的微型 Cloud SQL，未來只要在 GCP 控制台點擊幾下，就能不中斷服務地升級為具備高可用性 (HA) 與多讀取複本 (Read Replicas) 的企業級叢集。

2. 功能生態系的橫向擴充 (MCP Ecosystem)

透過我們在「YouTube 影片解析」所驗證的 MCP (Model Context Protocol) 架構，未來要新增任何「輸入源」都非常簡單，不需要更動 CertiMate 的核心程式碼。這就像是在替系統外掛裝備： 1. GitHub Repository 解析器：可以再寫一個 MCP Server，讓使用者輸入一個 GitHub 網址，系統就能直接幫他針對某個開源專案的程式碼出考題。 2. Podcast / 音檔解析器：串接 Whisper 的 MCP Server，讓通勤族丟入一段 Podcast 音檔連結，回家就能做上面提過的測驗。 3. Notion / Google Drive 匯入器：透過 MCP 授權，直接一鍵將使用者的線上筆記本變成考題。

3. B2B 企業市場的平行擴張 (B2B Expansion)

  • 多租戶架構 (Multi-Tenancy) 準備：由於架構切分乾淨，未來若有補習班或企業想採購這套系統，我們只需在資料庫加上 TenantID (租戶 ID)，就能輕易為每個企業開出「獨立專屬的測驗後台」。
  • API 經濟 (API-as-a-Service)：我們強大的「異質講義轉考題引擎」本身就是一個極具價值的資產。未來可以不只做 B2C 的網頁版，而是將引擎包裝成 API 販售給其他教育平台 (EdTech)，讓他們按次呼叫付費 (SaaS API Model)。

4. LLM 模型的無痛抽換 (Model Flexibility)

  • 不被單一廠商綁架：由於核心是標準的 RAG (檢索增強生成)，且我們已經抽象化了 AI 呼叫層。如果明天 OpenAI 漲價，或是 Llama-4 表現超越了 Gemini，我們只需在設定檔中抽換 API Key 與 Endpoint，系統就能在一夜之間切換大腦。
  • 地端化 / 私有化部署：如前述 SWOT 所提，當我們收集了足夠多的「學生錯題對話記錄」後，未來完全有機會自行 Fine-tune 一個開源的 Llama 模型，並部署在我們自己的 GPU 伺服器上，徹底擺脫對雲端大廠 API 的依賴，使得單次考題生成成本真正趨近於 0。
