收費與退費機制準則 (Billing & Refund Policy)

為了保障 CertiMate 平台 (做為純工具 SaaS) 的現金流健康，並兼顧消費者的合理權益與使用體驗，針對定價 199 TWD/月 的 Pro 訂閱服務，制定以下收費、取消與退費準則。

1. 訂閱收費原則 (Billing Cycle)

  • 週期性扣款 (Auto-Renewal)：Pro 方案採「月費制」，使用者綁定信用卡或第三方支付 (如 Stripe, Line Pay, Apple Pay) 後，系統將於每個計費週期 (滿 30 天) 的同一日自動扣款 199 TWD。
  • 隨買隨用 (Immediate Access)：付款成功當下，帳號立即升級為 Pro 權限，解鎖無廣告、無限上傳、無時長 YouTube 解析、以及進階 AI 錯題分析 (如 Claude 3.5 次數解鎖)。
  • 發票開立：依照營運所在地法規，於扣款成功後開立電子發票發送至註冊信箱。

2. 訂閱取消機制 (Cancellation Policy)

  • 隨時可取消 (Cancel Anytime)：使用者可隨時在「帳戶設定/訂閱管理」頁面點擊「取消訂閱」，過程不得設立人為障礙 (如強迫聯繫客服)。
  • 權益保留至期末 (Prorated Access)：取消訂閱後，系統將停止次月的自動扣款。但使用者已支付的當期 Pro 權限將保留至該計費週期結束為止。週期結束後，帳號將自動降級為 Free 免費版。
  • 歷史資料保留：降級為 Free 版後，使用者於 Pro 期間生成的龐大題庫、心智圖與錯題記錄不會被刪除，但可能會受到免費帳號的「每日存取/解析次數限制」。

3. 退費政策與防護機制 (Refund Policy & Abuse Prevention)

考量到 CertiMate 的核心價值在於「消耗高昂的 AI API 算力運算 (如長篇 YouTube 與巨型 PDF)」，我們必須設立嚴格但合理的退費門檻，防止「惡意白嫖算力」的行為。

A. 絕對不退費情境 (No Refund Allowed)

若符合以下任一條件，代表實質的系統算力已被消耗，原則上不予退費 (No Questions Asked Refund)： 1. 已使用核心算力：在當期計費週期內，使用者有「成功上傳並向量化 (Embedding)」任何一份超過一定額度 (例如 5 頁以上) 的講義，或「成功解析 YouTube 影片」並產出模擬考卷。 2. 已調用高階 AI 教練：在當期計費週期內，進行過任何一次 Pro 專屬的「深度錯題解析對話 (如調用 Claude 3.5)」。 3. 週期過半：距離扣款日已超過 7 天的法定猶豫期或該計費週期已過半。

B. 特例全額退費 (Full Refund Exceptions)

基於善意與消保法精神，符合以下狀況可透過客服信箱申請全額退費： 1. 誤觸扣款 (Accidental Renewal)：在自動續訂扣款發生後的 48 小時內提出申請，且紀錄顯示在「該續訂週期內」完全沒有使用任何生成/解析 API (用量紀錄為 0 發生)。 2. 重大系統故障 (Service Outage)：因 CertiMate 系統或底層 API 供應商 (如 GCP, OpenRouter) 發生無預警連續當機超過 24 小時，導致使用者在考前黃金期無法使用付費功能。 3. 重複扣款 (Duplicate Billing)：因系統金流 Bug 導致同一帳號在同一週期被扣款兩次以上。

C. 防濫用阻斷機制 (Anti-Abuse System)

為防範少數惡意使用者濫用 199 元吃到飽的機制，進而拖垮整體系統效能與 API 成本，系統將導入以下「帳號異常偵測 (Anomaly Detection)」與阻斷規則：

  1. 共享帳號偵測 (Account Sharing)：
    • 情境：同一組 Pro 帳號在極短時間內（例如 10 分鐘內），出現於多個地理位置差異巨大的 IP 登入，或同時有 3 個以上的裝置 (Session) 同時觸發耗時的文件解析或 YouTube 轉換。
    • 處置：系統強制登出所有 Session，並發送警告信。若單月觸發達 3 次，立刻凍結帳號，當月不予退費。
  2. 極端高頻匯出 (Hit-and-Run Exporting)：
    • 情境：帳號剛升級為 Pro 的前 48 小時內，瘋狂上傳超過 30 份巨量講義 (或數十部超長 YouTube)，並且完全沒有進行「線上測驗」與「錯題檢討」的互動，而是直接將生成的數百題模擬考卷與 Anki 閃卡「全部匯出 (Export)」。
    • 處置：觸發 Rate Limit (速率限制) 閘道，暫停該帳號的文件解析權限 24 小時。防堵「付 199 元買斷一個月，把整學期題庫幹走然後退訂」的羊毛黨。
  3. API 腳本惡意爬蟲 (Scripted Scraping)：
    • 情境：上傳行為與答題行為呈現高度規律性 (例如每 2.5 秒精準觸發一次 API)，缺乏人類操作的隨機滑鼠軌跡或停留時間，疑似使用 Python 腳本將 CertiMate 當作底層的廉價 LLM API 轉接頭 (Wrapper)。
    • 處置：觸發 Cloudflare 或 API Gateway 的 WAF 阻擋，要求強制進行 reCAPTCHA 驗證，未通過即鎖卡。
  4. 巨型垃圾檔案攻擊 (DoS via Garbage PDF)：
    • 情境：上傳蓄意構造的「文字炸彈 (Text Bomb)」PDF、或是完全由無意義亂碼組成、或是刻意將 100 頁純白圖片打包的檔案，意圖耗損系統的 Vision OCR 與 Embedding 算力。
    • 處置：在文字預處理 (Preprocessing) 階段若偵測到重複率過高或無法辨識的亂碼比例過高，直接終止工作管線 (Pipeline)，並跳出「文件解析失敗，請確認檔案格式正常」的錯誤，該次解析不計入使用額度，但也阻斷後續向 OpenAI/Anthropic 發送 API 的成本。
  • 無按比例退費 (No Prorated Refunds)：為降低客服與金流手續費成本，除上述特例外，本平台不接受依使用天數「按比例退還剩餘款項」。取消訂閱一律視為「用到該週期最後一天」。

4. 決策面考量與結論

  • 199 元的保護色：定價 199 元是一把雙面刃，雖然客單價低，但也因為「沉沒成本極低」，絕大多數正常使用者在考完試後，如果忘記取消訂閱被多扣了一個月，通常摸摸鼻子就算了，較少會為 199 元憤而發動耗時的信用卡爭議款 (Chargeback)。
  • 明確的標示：必須在結帳頁面 (Checkout Page) 最顯眼處標明：「本服務包含即時巨量 AI 運算，一旦產生首份專屬考卷即代表履約完畢，除系統重大故障外恕不接受退費。」以建立最強的法務與客訴防禦盾牌。
