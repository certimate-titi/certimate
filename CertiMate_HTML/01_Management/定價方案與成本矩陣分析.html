定價方案與成本矩陣分析 (99 vs 199 vs 299)

針對 CertiMate 這樣一款高頻依賴 LLM API 與多模態模型的 AI SaaS，產品定價 (Pricing) 不只影響營收，更是直接決定了防禦惡意使用 (Abuse) 的門檻與毛利率 (Margin) 的生死線。

以下針對三種潛在定價區間 (99 TWD、199 TWD、299 TWD) 進行成本結構與戰略意義的深度剖析。

1. 成本基準線 (Cost Baseline)

在評估定價前，我們必須先抓出一個「重度付費用戶」每月的極端成本消耗 (Worst-case Scenario)。

Pro 用戶每月最大極限用量設定： - 純文字/PDF 解析：生成 30 份考卷 (約 3.0 USD) - YouTube 長影音解析：15 支 1 小時影片 (約 1.0 USD) - 手寫數學/圖片 OCR (Vision)：上傳 100 頁手寫筆記 (約 0.5 USD) - 高階 AI 教練 (如 Claude 3.5)：提問 200 次大會考級深度解析 (約 3.0 USD) - 資料庫/儲存/流量攤提：約 0.5 USD

📊 極端重度用戶變動成本 (Max API Cost)：約 $8.0 USD (約 256 TWD) 📊 一般正常用戶變動成本 (Avg API Cost)：約 $1.5 USD (約 48 TWD)

(註：因系統備有 Redis 快取，若多位學生上傳同一份熱門講義，實際平均成本會進一步大幅下降。)

3. 各方案戰略解析與結論

❌ 99 TWD 方案：致命的毒藥 (已排除)

  • 商業陷阱：在 AI 產品中，99 元是極度危險的定價。因為 AI 的成本是「看用量 (Token)」而非固定頻寬。99 元很容易吸引到「想花小錢把系統用到極限」的羊毛黨。
  • 金流耗損：如果是用藍新或綠界，單筆交易往往有基本的定額手續費 (如 5~10 元) 加上 % 數。99 元的客單價會讓金流成本佔比高得嚇人。
  • 結論：容錯率太低，只要出現幾個把 10 小時 YouTube 影片丟進來狂轉的用戶，當月該帳號立刻呈現虧損。

🛡️ 299 TWD 方案：安穩但缺乏爆發力

  • 商業陷阱：299 元在心理學上已經脫離了「衝動購物」的區間。台灣學生對於購買一個「還不知道考了有沒有用」的數位工具，超過 200 元就會開始猶豫，並嘗試尋找免費替代品 (如阿摩的看廣告模式)。
  • 結論：雖然毛利可達 80% 以上極度安全，但會大幅降低新註冊用戶的轉換率 (Conversion Rate) 與社群傳播速度，對於初期急需擴張知名度的 SaaS 來說不是最佳解。

🏆 199 TWD 方案：最完美的「特洛伊木馬」(強烈建議)

  • 心理學護城河：「1 字頭」在台灣定價學上有著奇妙的魔力。199 元買一個月「無廣告、YouTube 課程秒轉考卷、手寫微積分詳解」，這在考前兩週的衝刺期，對學生來說幾乎等同於「免費救命仙丹」。
  • 數據平衡：根據上述試算，199 元的定價下，極端用戶雖會導致些微虧損 (-57 TWD)，但只要搭配 「嚴格次數閘道 (限額呼叫 Claude 3.5)」 來控制，加上絕大多數的「一般用戶 (毛利 +151 TWD)」與「忘記退訂的沉睡用戶」，整體的現金流會非常豐沛且健康。
  • 結論：這是一個能無情絞殺競爭對手（有資金的大廠看不上這點利潤，沒資金的新創因為沒有 Serverless 架構會直接虧本倒閉）的完美破壞性價格。

💡 最終策略落地

採用 199 TWD/月，但必須配合《收費與退費機制準則》中的無按比例退費條款，並在 OpenRouter 對頂級模型 (Claude 3.5) 設定合理的使用次數上限 (例如：每月 50 次深度提問)，其餘皆由便宜且極速的 Gemini Flash 或 Llama 3 負責，確保 199 元的護城河堅不可摧。
