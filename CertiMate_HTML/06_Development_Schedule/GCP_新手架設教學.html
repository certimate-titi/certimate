GCP_新手架設教學

雲端新手村：Google Cloud Platform (GCP) 基礎設施架設教學

這份教學專為初學者設計，將帶你一步步完成 CertiMate Phase 1 (M1) 中提到的雲端基礎設施架設。不用擔心，我們會像在設定手機 App 一樣，從註冊帳號到開通服務，手把手帶你完成！

🚀 第一步：踏入雲端世界 (註冊與建立專案)

就像蓋房子需要先買一塊地，在 GCP 上開發任何東西前，我們都要先建立一個「專案 (Project)」。

1. 註冊 GCP 帳號

  1. 前往 Google Cloud 官網。
  2. 點擊右上角的「免費開始使用 (Get started for free)」。
  3. 登入你的 Google 帳號 (Gmail)。
  4. 填寫國家/地區，並同意服務條款。
  5. 綁定信用卡：別擔心！GCP 會要求綁定信用卡來驗證你是真人。Google 對新用戶非常大方，會送你 $300 美金 的免費額度 (效期 90 天)，而且在你「主動」升級為付費帳號之前，絕對不會偷偷扣你錢。

2. 建立新專案 (Project)

  1. 進入 GCP 控制台 (Console) 後，點擊左上角 Google Cloud Logo 旁邊的下拉式選單 (通常會顯示 “Select a project” 或預設的專案名稱)。
  2. 點擊右上角的「新增專案 (NEW PROJECT)」。
  3. 專案名稱：輸入 certimate-dev (或你喜歡的名字)。
  4. 點擊「建立 (CREATE)」。等個幾秒鐘，你的第一塊雲端建地就買好啦！
  5. 重要：確保你在左上角的下拉選單中，選中的是剛剛建立的 certimate-dev 專案。

🗄️ 第二步：打造雲端硬碟 (Google Cloud Storage - GCS)

GCS 就像是無限容量的 Google Drive，我們將用它來存放使用者上傳的講義、PDF 和圖片。

操作步驟：

  1. 在 GCP 控制台左側選單，找到 Cloud Storage，點擊 Buckets (儲存區)。 (如果找不到，可以直接在上方搜尋列搜尋 “Cloud Storage”)
  2. 點擊上方的「建立 (CREATE)」。
  3. 命名你的 Bucket：名字必須是全世界唯一的 (就像網址一樣)。建議取名為 certimate-assets-你的名字或日期 (例如：certimate-assets-2026)。點擊 “Continue”。
  4. 選擇位置：選擇 Region (單一區域)，並在下拉選單選擇 asia-east1 (Taiwan)。這可以讓台灣的用戶上傳下載速度最快！點擊 “Continue”。
  5. 儲存級別：保持預設的 Standard。點擊 “Continue”。
  6. 存取控制：保持預設的 Uniform。這代表我們之後可以統一設定誰能讀取這些檔案。點擊 “Continue”。
  7. 剩下的設定保持預設，直接滑到最下面點擊「建立 (CREATE)」。
  8. 跳出警示框時，點擊「確認 (Confirm)」。

🎉 完成！ 你已經擁有了一個專屬的雲端儲存空間。

🧠 第三步：建立大腦記憶庫 (Cloud SQL for PostgreSQL)

這裡我們要架設資料庫，用來記住使用者的帳號、密碼、測驗紀錄，以及最重要的「向量資料 (Vector)」。

操作步驟：

  1. 在上方搜尋列搜尋 SQL 並點擊進入。
  2. 點擊「建立執行個體 (Create Instance)」。
  3. 選擇 PostgreSQL。
  4. 如果遇到需要啟用 API 的提示，請點擊「啟用 (Enable)」。
  5. 設定執行個體資訊：
    • Instance ID：輸入 certimate-db。
    • 密碼 (Password)：輸入一組你記得住但夠複雜的密碼，或是點擊右邊的眼睛圖示旁的按鈕讓他幫你隨機產生 (請務必把這組密碼記在筆記本上！)。
    • 資料庫版本：選擇 PostgreSQL 15 或更新的版本。
  6. 選擇區域 (Region)：一樣選擇 asia-east1 (Taiwan)。
  7. 選擇機器規格設定 (重要，幫你省錢！)：
    • 在下方找到「設定機器類型 (Customize your instance)」或類似的選項，將層級改為 Shared core (共用核心)，並選擇最小的 db-f1-micro。因為我們現在還在開發階段，用最便宜的機器就夠了。
    • 找到「儲存空間 (Storage)」，將容量改為 10 GB (預設可能是 100GB，太多了)。
  8. 點擊最下方的「建立執行個體 (CREATE INSTANCE)」。

☕ 休息一下：建立資料庫大約需要 5~10 分鐘，你可以去泡杯咖啡。等它旁邊出現綠色勾勾，就代表建立完成了！

🚀 第四步：準備程式運行的舞台 (Cloud Run)

Cloud Run 是我們用來跑後端程式碼 (API) 的地方。它的超強好處是：有人用才算錢，沒人用就不用錢 (Scale to zero)，非常適合初期的新創專案！

雖然我們現在還沒有寫好程式碼來部署，但我們可以先認識它在哪裡。

操作須知：

  1. 在上方搜尋列搜尋 Cloud Run。
  2. 如果跳出提示，請點擊「啟用 API (ENABLE API)」。
  3. 現在你可能會看到一個空空的頁面。這樣就對了！
  4. 等到未來我們的工程師 (或是你) 寫好了 Node.js 或 Python 的 API 程式碼，我們會把它打包成一個貨櫃 (Docker Image)。
  5. 到時候，只要在這個畫面點擊「建立服務 (CREATE SERVICE)」，把那包貨櫃丟上去，GCP 就會自動幫你產生一串專屬的網址 (例如 https://api.certimate.run.app)，你的服務就正式上線啦！

🎯 總結你的 MVP 戰果

恭喜你！跟著上面的步驟，你已經成功在雲端上開墾了 CertiMate 的基礎設施： 1. 買好建地 (GCP 專案 certimate-dev 建立完成) 2. 蓋好倉庫 (GCS Bucket 建置完畢，可以收納講義圖片) 3. 裝好記憶大腦 (Cloud SQL PostgreSQL 啟動中，準備好記住考題資料) 4. 準備好舞台 (Cloud Run API 啟用完成，等待程式碼上線)

這就是所謂的 M1 (基礎架構建立)。萬事起頭難，最複雜的雲端環境開通你已經搞定了！下一步，我們就會開始寫程式碼，讓這些服務真正串聯起來。
