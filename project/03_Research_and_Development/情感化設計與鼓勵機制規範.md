# 情感化設計與鼓勵機制規範

讓 CertiMate 從「考試工具」升級為「備考夥伴」，核心策略是在使用者旅程的每個關鍵時刻注入**情感回饋**，使學習者感受到「有人懂我的辛苦、有人陪我走過低谷」。

此規範定義了 CertiMate 系統中所有的鼓勵機制 UX 設計，並與現有的頁面模組進行整合。

---

## 一、AI 教練人格化 — 從工具到夥伴

### 1.1 賦予 AI 教練角色形象

目前的 AI 教練僅在錯題解析時出現，定位偏向「功能型 Chatbot」。建議升級為有**名字、有語氣、有情緒反應**的專屬學伴角色。

- **命名與視覺**：給 AI 一個預設角色名稱（例如「Certi」），搭配輕量的 Avatar 圖示或 Lottie 動畫。
- **語氣策略**：
  - 答對率高時：「太帥了吧！這個章節你根本已經融會貫通 🔥」
  - 答對率低但有進步：「跟上次比你多對了 3 題耶，有感覺到進步嗎？繼續刷！」
  - 遇到瓶頸時：「這章本來就是大魔王，很多人卡在這裡。喘口氣，我們用不同角度再看一次。」
- **記住使用者歷程**：AI 教練應能引用使用者的歷史紀錄，例如「你上週在 IAM 那邊也卡了一下，但後來不是破關了嗎？這次你也可以的。」

### 1.2 情感化的考前/考後對話

- **考前打氣**：每次開始模擬測驗前，AI 自動顯示一段簡短鼓勵語（非制式隨機語錄，而是基於使用者**當前學習狀態**動態生成）。
- **考後安撫/慶祝**：
  - 成績進步 → 撒花動畫 (Confetti) + AI 角色開心表情 + 具體稱讚。
  - 成績退步 → 溫暖的語句 + AI 角色陪伴表情 + 自動規劃接下來的複習策略。

## 二、成就系統與里程碑 — 看得見的成長

### 2.1 成就徽章 (Achievement Badges)

設計一系列與**學習行為**而非僅結果掛鉤的徽章，強調「過程比結果重要」。徽章基於里程碑 (milestone-based) 自動頒發，使用者達成條件時系統即時授予，並觸發**全螢幕慶祝動畫**強化正向回饋。

**已確認實作的徽章**：

| 徽章 ID | 徽章名稱 | 觸發條件 | 設計用意 |
| :--- | :--- | :--- | :--- |
| `first_upload` | 播種者 | 首次成功上傳一份資源 | 獎勵踏出第一步 |
| `streak_7` | 堅持不懈 | 連勝天數達到 7 天 | 長期堅持的肯定 |

**規劃中的擴展徽章**（後續迭代）：

| 徽章名稱 | 觸發條件 | 設計用意 |
| :--- | :--- | :--- |
| 三日連續 | 連續 3 天登入並完成學習活動 | 養成每日學習習慣 |
| 弱點克星 | 某弱點章節答對率從 <50% 提升至 >80% | 獎勵最有價值的進步 |
| 滿分時刻 | 任一測驗獲得 100% 正確率 | 完美表現的即時慶祝 |
| 求知若渴 | 累計向 AI 教練提問超過 50 次 | 鼓勵主動追問 |
| 登頂者 | 累計完成 100 回模擬考 | 超級用戶的榮耀勳章 |
| 夜貓學霸 | 晚上 11 點後完成一回考卷 | 幽默化的陪伴感 |
| 不屈不撓 | 同一章節重新挑戰超過 5 次 | 鼓勵面對困難不放棄 |

### 2.2 學習里程碑通知

在使用者達成特定累積量時，觸發全螢幕的慶祝動畫與訊息：

- 「你已經完成了第 50 回模擬考！你在這趟旅途中已經比 87% 的考生更認真了。」
- 「你上傳的學習資源總計超過 500 頁了，知識量驚人！」

## 三、學習連續性與習慣養成

### 3.1 學習連勝 (Streaks)

在 **個人儀表板首頁 (User Dashboard)** 中加入類似 Duolingo 的**每日學習連勝火焰**：

- **視覺位置**：Dashboard 頂部歡迎區旁邊，與問候語並列。
- **累積規則**：每日登入並完成至少一次學習活動（完成測驗、複習錯題等）才計入連勝。**僅登入而未進行學習活動不計入**。
- **連勝凍結機制 (Streak Freeze)**：
  - 使用者擁有「凍結額度」，當某天未登入時，系統**自動消耗 1 次凍結額度**以保護連勝不中斷。
  - 凍結生效時，隔日登入顯示溫馨提示：「**休息也是學習的一部分，歡迎回來**」。
  - 凍結額度的獲取方式由訂閱方案或成就系統決定。
- **連勝歸零**：當某天未登入且凍結額度為 0 時，連勝天數重置為 0。

### 3.2 每日微任務 (Daily Quests)

系統在使用者每日首次登入時自動生成 **1~3 個微任務**，降低「今天該做什麼」的決策疲勞：

- **任務類型 (`quest_type`)**：
  - `quiz`：完成指定數量的測驗題目（例如「完成一份 15 題測驗」）
  - `explore`：探索新的知識節點或資源
  - `review`：複習過往錯題或待複習內容（例如「複習昨天答錯的 5 題」）
- **任務欄位**：每個任務包含 `quest_type`、`description`（任務描述）、`xp_reward`（完成後獲得的 XP 經驗值）、`status`（初始 `pending`，完成後更新為 `completed`）。
- **完成判定**：任務由系統事件**自動觸發完成**，**不接受使用者手動回報**。當使用者實際完成對應動作（例如完成一份測驗），系統自動將匹配的 quest 標記為 `completed` 並發放 XP。

## 四、社群歸屬感 — 你不是一個人在戰鬥

### 4.1 匿名學習夥伴 / 共同備考感 (Ultra 用戶專屬)

考慮在不增加社交壓力的前提下，針對 Ultra 帳號底下的學員創造「一起努力」的氛圍：

- **「目前有 N 位考生正一起奮鬥」**：在儀表板顯示同時段同證照的活躍使用者數（N 為正整數），僅限 **ULTRA_1599** 訂閱方案可見。**隱私保護**：橫幅內容不得包含任何 Email、姓名或使用者 ID，僅顯示匿名統計數字。
- **里程碑共鳴**：「上週有 23 位跟你一樣也在準備 AWS SAA 的考生成功突破 80 分大關 🎉」。

### 4.2 考後成績分享（選配功能）

- 在 **測驗結果與分析頁 (Exam Results)** 中擴充設計精美的**個人化成績卡片** (Score Card)，包含：
  - 使用者暱稱 + 考試名稱。
  - 得分與個人最佳紀錄。
  - CertiMate 品牌浮水印。
  - 自動生成一句鼓勵文案。
- 支援一鍵分享至 LinkedIn，兼具口碑行銷效果。

## 五、記憶回顧與成長視覺化

### 5.1 每週學習報告 (Weekly Learning Report)

系統每週自動為活躍用戶生成個人化學習週報：

- **觸發條件**：系統排程每週自動執行。僅對本週有學習活動的使用者生成週報；**本週無任何學習活動的使用者不會收到週報**，避免空白報告造成挫折感。
- **週報內容**：
  - `study_hours` — 本週學習時數
  - `exams_completed` — 本週完成的考試數量
  - `questions_answered` — 本週答題數量
  - **AI 生成的進步摘要** — 由 AI 根據使用者本週數據與歷史趨勢產生的個人化進步總結（例如：「你這週花了不少時間在 VPC 安全組規則上，已經能看出明顯起色了。下週我們來搞定路由表吧！」），內容不得為空白。
- **隱私原則**：週報數據僅與使用者自己的歷史數據進行比較（**跟自己比，不跟別人比**），**不包含任何排名機制**，避免競爭焦慮。

### 5.2 成長時間軸 (Growth Timeline)

在 **會員中心與訂閱管理 (Account & Billing)** 或 Dashboard 中加入一條**視覺化時間軸**：

- 標記每個重要節點：第一次上傳、第一次測驗、首次及格、各章節攻克日期。
- 使用者能回顧自己「從零到接近及格」的完整歷程，產生「原來我已經走了這麼遠」的正向感受。

## 六、低谷偵測與主動關懷

### 6.1 智慧偵測學習低谷

當系統偵測到以下信號時，**主動出擊**而非被動等待：

| 信號 | 系統反應 |
| :--- | :--- |
| 超過 3 天未登入 | 推送溫暖的站外通知 (Email/Push)：「最近忙嗎？Certi 等你回來，隨時可以繼續 💛」 |
| 連續 2 回測驗成績明顯下滑 | AI 教練主動開啟對話：「我注意到最近幾次的分數有點波動，這很正常！我幫你分析了一下，看看是不是這兩個概念混淆了...」 |
| 反覆在同一章節卡關超過 5 次 | 自動建議切換學習策略：「換個角度試試？我從你的講義中幫你抽了相關的閃卡，先記牢基礎再回來打 Boss。」 |
| 首次使用後 24 小時內未再登入 | 發送 Onboarding 引導信：「你的第一份講義解析好了！來看看 AI 幫你生成了什麼考題 👀」 |

### 6.2 情緒安全網語調設計

在所有成績展示處，系統文案(Copywriting)必須避免使用「失敗」、「不及格」等負面詞彙，改用：

- ❌「你不及格了」→ ✅「距離通過門檻還差一點點，加把勁！」
- ❌「答對率 40%」→ ✅「你已經掌握了 40% 的內容，接下來我們一起攻克剩下的部分。」
