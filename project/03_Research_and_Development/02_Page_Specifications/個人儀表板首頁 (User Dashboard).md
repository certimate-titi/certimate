# 個人儀表板首頁 (User Dashboard)

## 頁面定位與目標

作為使用者登入後的第一個主畫面，這是 CertiMate 系統的指揮中心。目標是讓使用者能 **一眼掌握學習進度 (Progress Tracking)** 並提供 **最直覺的核心操作入口 (Quick Actions)**。

## 核心區塊設計 (Sections)

### 0. 科目切換器 (Subject Switcher)

位於頁面頂部（導覽列下方），讓備考多科的使用者快速切換上下文：

- **切換控制**：水平分頁標籤 (Tabs) 或下拉選單，每個標籤顯示科目名稱、考試倒數天數，以及該科目的專屬**任務模式徽章** (Sprint / Standard / Mastery)。
- **數據聯動**：切換科目後，下方所有區塊（雷達圖、指標卡片、待辦提醒、錯題複習）的數據皆對應更新。
- **新增入口**：最末端固定顯示「+ 新增備考科目」按鈕，點擊後開啟科目選擇介面（與 Onboarding Step 2 相同元件）。
- **僅備考單科時**：科目切換器仍顯示但僅有一個標籤，不影響版面。

### 1. 歡迎與概覽區 (Welcome & Overview)

- **個人化問候**：例如 "Ready to crush your PMP exam, Alex?"（依當前選中科目動態調整）。
- **當前任務模式資訊**：
  - 顯示該科目的任務模式徽章（如 Sprint Mode, Standard Mode, Mastery Mode）。
  - Hover 或點擊徽章時，會展開一個互動式 Tooltip 或小彈窗 (Modal)，提供以下資訊讓使用者明白當前階段的設計目的：
    - **模式目標 (Goal)**：解釋為何目前處於此模式（例如：「距離考試剩餘不到 14 天，系統已自動為您切換至衝刺狀態。」）。
    - **加強範圍與策略 (Scope & Strategy)**：說明當前系統的訓練重點（例如：「目前重點加強您曾答錯的高頻題目與未觸及的盲點，暫時忽略已內化的基礎，追求短期高報酬。」）。
    - **考題配分權重 (Weighting)**：以視覺化比例條列出當前系統配題邏輯（例如：「未考知識 40% / 曾錯盲點 50% / 其他 10%」）。
- **每日學習連勝 (Streaks)**：位於問候語旁，顯示連續學習天數與火焰圖示，並配備「斷連保護」凍結機制以避免挫折（詳見下方「連勝火焰」區塊）。
- **核心指標卡片 (Metric Cards)**：
  - 即將到來的考試倒數計時器（對應當前選中科目的考試日期）。
  - 累積完成的模擬題數。
  - 整體系統預測的及格率 / 答對率區間。
- **能力分佈雷達圖 (Skill Radar)**：利用 Chart.js 等圖表套件，展示當前選中科目各知識領域的強弱項。**此雷達圖的數據會直接連動至後臺的「考題產生器」，當系統依照「任務模式」調配完大比例後（如要求 40% 為新題目），會進一步根據雷達圖自動優先抽取您的弱點領域進行出題設計。**

### 2. 快速上傳區 (Upload Widget)

這是此頁面最重要的行動呼籲 (Call to Action)，採用大面積的拖曳區塊與分頁設計：

- **Tab A (實體檔案)**：支援拖曳或點選上傳下列格式：
  - **所有方案 (FREE / PRO_199 / PRO_PLUS_399 / ULTRA_1599)**：PDF、Markdown (.md)、TXT 純文字
  - **PRO_PLUS_399 以上限定**：Image（PNG / JPG / JPEG / WebP，手寫數學/工程圖等 Vision OCR 解析）
    - 若 PRO_199 以下方案嘗試上傳圖片，上傳按鈕消失並即時顯示升級提示：「手寫/圖片辨識需要多模態算力，升級 PRO_PLUS_399 解鎖 Vision OCR」
- **Tab B (影音連結)**：
  - 一個居中放大的 YouTube URL 輸入框，**所有方案皆可使用，PRO_199 以上無時長限制**。
- **隱性版權同意機制 (Implicit Consent)**：
  - 取消強制勾選框，改為在主上傳按鈕**正下方**放一行視覺弱化（超小字、淡灰色、無邊框）的免責聲明：「*點擊上傳即代表您保證擁有此檔案／影片的合法使用授權，且同意不公開散佈生成的內容。*」
  - 點擊按鈕即視為同意，後端自動附加同意標記，兼顧 UX 流暢度與法律防護。
- **解析狀態回饋 (Status Feedback)**：
  - **PENDING / PROCESSING**：顯示帶百分比的進度條（搭配 SSE 或輪詢即時更新）與 Skeleton 骨架屏動畫，避免使用者誤以為當機。
  - **COMPLETED**：進度條轉綠，跳出即時浮動通知 (Toast)：「解析完成！心智圖已生成，立即查看」。按鈕連結至資源庫對應的心智圖節點。原始檔案此時在後端**靜默刪除**，使用者面無感知。
  - **FAILED**：進度條轉紅，顯示具體失敗原因（如「無法識別文字內容」或「影片無字幕」），並提供「重新解析」按鈕觸發重試。此時原始檔仍保留於後端，直至重試成功後才刪除。

### 3. 動態提醒與待辦清單 (Action Items)

依據使用者的學習行為，由系統動態產生的建議清單：

- **每日微任務 (Daily Quests)**：
  - 系統在使用者每日首次登入時自動產生 **1-3 個微任務**。
  - 任務類型 (`quest_type`) 分為三種：
    - `quiz`：完成指定數量的測驗題目（例如「完成一份 15 題測驗」）。
    - `explore`：探索新的知識節點或資源。
    - `review`：複習過往錯題或待複習內容（例如「複習昨天答錯的 5 題」）。
  - 每個任務包含以下欄位：
    - `quest_type` — 任務類型 (quiz / explore / review)
    - `description` — 任務描述文字
    - `xp_reward` — 完成後獲得的 XP 經驗值
    - `status` — 初始狀態為 `pending`，完成後更新為 `completed`
  - **完成判定方式**：任務由系統事件自動觸發完成，**不接受使用者手動回報完成**。當使用者在系統中實際完成對應動作（例如完成一份測驗），系統自動將匹配的 quest 標記為 `completed` 並發放 XP 獎勵。若使用者嘗試透過 API 手動完成任務，系統將回應錯誤：「任務完成狀態由系統自動判定，不接受手動更新」。
- **近期錯題複習**：例如 3 天前做錯的 15 題，提示「依照遺忘曲線，現在是複習的最佳時機」。
- **未完成的考卷**：顯示上次中斷的模擬測驗進度 (例如 "AWS SAA Mock #3 - 50% Completed")。
- **新解析完成的講義**：提示知識心智圖已生成完畢，點擊查看。
- **(ULTRA_1599 用戶專屬) 匿名共同備考感**：
  - 僅 ULTRA_1599 訂閱方案的使用者可看到此橫幅區塊。FREE、PRO_199、PRO_PLUS_399 用戶不會看到。
  - 顯示格式固定為：「**目前有 N 位考生正一起奮鬥**」，其中 N 為正整數，代表同時段同證照的活躍使用者數。
  - **隱私保護**：橫幅內容**不得包含任何 Email、姓名或使用者 ID**，僅顯示匿名統計數字，創造陪伴氛圍但嚴格保護個資。

### 4. 連勝火焰 (Learning Streaks)

連勝火焰機制透過持續學習的正向回饋，激勵使用者養成每日學習習慣：

- **累積規則**：使用者每日登入系統並完成至少一次學習活動（如完成測驗、複習錯題等）即累積一天連勝。僅登入而未進行學習活動不計入連勝。
- **連勝凍結機制 (Streak Freeze)**：
  - 使用者擁有「凍結額度」，當某天未登入時，系統自動消耗 1 次凍結額度以保護連勝不中斷。
  - 凍結生效時，隔日登入系統會顯示溫馨提示：「**休息也是學習的一部分，歡迎回來**」。
  - 凍結額度的獲取方式由訂閱方案或成就系統決定。
- **連勝歸零**：當使用者某天未登入且凍結額度為 0 時，連勝天數重置為 0。
- **顯示位置**：連勝天數與火焰圖示顯示於歡迎區問候語旁，為儀表板最醒目的視覺元素之一。

### 5. 成就徽章 (Achievement Badges)

成就徽章系統透過里程碑式的獎勵，為學習歷程增添儀式感與成就感：

- **徽章類型**：基於里程碑 (milestone-based) 自動頒發，使用者達成特定條件時系統即時授予。已知徽章包括：
  - `first_upload` — **播種者**：首次成功上傳一份資源。
  - `streak_7` — **堅持不懈**：連勝天數達到 7 天。
  - 後續可擴展更多徽章（如 streak_30、first_exam_pass 等）。
- **解鎖動畫**：徽章解鎖時觸發**全螢幕慶祝動畫**，強化正向回饋體驗。
- **徽章展示**：已獲得的徽章可在個人資料頁或儀表板中查看。

### 6. 每週學習報告 (Weekly Reports)

系統每週自動為活躍用戶生成個人化學習週報，幫助使用者回顧學習成果並持續進步：

- **觸發條件**：系統排程每週自動執行。僅對本週有學習活動的使用者生成週報；**本週無任何學習活動的使用者不會收到週報**，避免空白報告造成挫折感。
- **週報內容**：
  - `study_hours` — 本週學習時數
  - `exams_completed` — 本週完成的考試數量
  - `questions_answered` — 本週答題數量
  - **AI 生成的進步摘要** — 由 AI 根據使用者本週數據與歷史趨勢產生的個人化進步總結，內容不得為空白。
- **隱私與設計原則**：週報數據僅與使用者自己的歷史數據進行比較（自我對比），**不包含任何排名機制**，避免競爭焦慮，維持正向學習氛圍。

## 技術面/實作建議

- **資料預取 (Data Fetching)**：這頁的圖表與數據較多，建議使用 SWR 或 React Query 進行快取與 Optimistic UI 更新。
- **RWD (響應式設計)**：雷達圖與上傳區塊在手機端需要調整堆疊順序，確保上傳區塊始終在第一屏可見。
- **全螢幕動畫**：成就徽章解鎖的慶祝動畫建議使用 Motion 或 Lottie 實現，確保動畫不阻擋使用者操作流程（可設定自動消失或點擊關閉）。
- **每日微任務生成**：首次登入時由後端根據使用者學習歷程與待辦項目動態生成，建議透過事件驅動架構 (Event-Driven) 監聽學習事件以自動完成任務判定。
- **週報排程**：透過後端定時任務 (Cron Job / Celery Beat) 每週執行，AI 摘要生成可使用非同步處理避免阻塞主流程。
