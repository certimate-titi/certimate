# 教育機構管理中心 (B2B Edu Console)

## 📌 頁面定位與目標

這是一個專屬於 **Ultra 旗艦版訂閱戶** (如補習班班主任、企業內訓主管) 的 B2B 視角。目標是提供強大的 **批量管理工具** 與 **宏觀的學生能力剖析**，幫助機構有效追蹤整體學習成效。

## 🧩 頁面佈局與功能區塊

本頁面為獨立的教育管理路由 (`/edu-console`)，避免與一般學生視角及平台管理後台 (`/super-admin`) 混淆。

---

### 0. 班級健康 KPI 列（頁面最頂部）

> 靈感來源：Redmenta 的 Class Overview，讓管理員一眼掌握整體狀況。

4 個 KPI 卡片橫排顯示：

| 卡片 | 數值來源 | 顏色 |
|------|---------|------|
| 總學生數 | 機構授權學員總數 | 中性 |
| 活躍率 | 過去 7 天登入學員比例 | 綠色 |
| 需關注人數 | 平均分 <60 或趨勢持續下降 | 紅色（有問題時） |
| 班級平均分 | 全班最近測驗平均 | 中性 |

---

### 1. 早期預警面板（Early Warning）

> 靈感來源：Redmenta 的 Early Detection — 系統主動浮出問題學員，而非等待教師手動翻查。

- 自動條件（任一觸發）：平均分 < 60 分 ／ 連續 3 次趨勢下降 ／ 5 天以上未登入
- 每張預警卡片顯示：學員名字、最弱節點名稱與分數、距上次登入天數、趨勢圖示
- 每張預警卡片附「**AI 補強**」一鍵按鈕

---

### 2. 快速操作列

三個操作入口橫排顯示（非 Tab，為快捷動作卡）：

| 操作 | 說明 |
|------|------|
| 批量匯入名單 | 上傳 CSV（固定欄位：姓名、電子郵件、群組），自動建立帳號並寄送啟用邀請信；執行前需同意個資聲明。CSV 防呆：缺少欄位→「CSV 格式錯誤，請使用系統提供的範本（需包含姓名、電子郵件、群組欄位）」；重複 Email→「CSV 中包含重複的電子郵件：xxx」 |
| 派發模擬考卷 | 從知識庫選範圍，統一生成考卷並設定截止日期；派發後群組學員看到待完成測驗任務 |
| 全局弱點分析 | 查看班級共同知識盲區 |

---

### 3. 學生能力檔案列表（Competency Profiles）

> 靈感來源：Redmenta 的 Competency Profiles — 超越單一分數，每位學員有多維度技能追蹤。

**列表欄位（每行）：**
- 頭像縮寫 + 趨勢箭頭（↑↓→，依最近 3 次測驗變化計算）
- 姓名 + Email
- 整體進度條（0–100%，顏色依高低：綠/橘/灰）
- 平均分數（彩色：≥70 綠、≥50 橘、<50 灰）
- 狀態標籤（活躍 / 需關注 / 未啟用）

**點擊展開（Competency Detail Panel）：**

> 靈感來源：Redmenta 的 per-student skill breakdown，每項技能獨立評分。

- 各知識節點能力分析條：節點名稱 + 分數條 + 數值，顏色：綠（≥70）/ 橘（40–69）/ 紅（<40）
- 操作按鈕：
  - **「AI 個人化補強建議」**：呼叫後端 AI 根據弱點生成 1–3 條針對性建議
  - **「指派補考」**：向該學員派發補強測驗
  - 最後活躍時間

### 4. 班級學習概況（右側統計面板）

- 班級平均分 + 週趨勢
- 共同弱點 Top 3：節點名稱 + 答錯率橫條
- **班級熱力圖 (Heatmap)**：知識節點（X 軸）× 學員（Y 軸）的答對率矩陣，顏色深淺代表答對率（0–100%），一目了然班級共同盲區
- **全班錯題排行 (Top Mistakes)**：答錯率最高的前 10 道題目，每筆顯示題目原文、全班答錯百分比、所屬知識節點
- 「匯出詳細報告」按鈕

---

### 5.1 自訂預警閾值

機構管理員可自行調整早期預警的觸發條件（預設值如下）：

| 參數 | 預設值 | 說明 |
|------|--------|------|
| 最低平均分 (min_avg_score) | 60 | 學員平均分低於此值觸發預警 |
| 最大連續下降次數 (max_decline_trend) | 3 | 連續 N 次成績下降觸發預警 |
| 最大未登入天數 (max_inactive_days) | 5 | 超過 N 天未登入觸發預警 |

## 📡 API 端點規劃

| 端點 | 方法 | 說明 |
|------|------|------|
| `/edu/class-health` | GET | 取得 KPI 概覽（總數/活躍率/需關注/平均分） |
| `/edu/at-risk` | GET | 取得早期預警學員清單 |
| `/edu/students` | GET | 取得學員列表（含 trend 欄位） |
| `/edu/students/:id/competencies` | GET | 取得單一學員多維度能力檔案 |
| `/edu/students/:id/ai-reinforcement` | POST | 生成 AI 個人化補強建議 |
| `/edu/students/import` | POST | CSV 批量匯入（含個資同意確認） |
| `/edu/assignments` | POST | 派發測驗給指定群組 |
| `/edu/analytics/weak-spots` | GET | 班級共同弱點分析 |
| `/edu/analytics/top-mistakes` | GET | 全班答錯率 Top 10 題目 |

## 💻 技術面/實作建議

- **RBAC 權限設計**：後端必須驗證 `subscription_tier = ULTRA_1599` 且 `role` 為機構管理員才能存取此組 API。
- **能力分數計算**：每個知識節點的分數由該節點下所有測驗題目的答對率計算；使用加權平均（近期測驗權重更高）。
- **趨勢計算**：比較最近 3 次測驗與前 3 次測驗的平均分；差距 > 5 分為 `up`/`down`，否則為 `flat`。
- **AI 補強建議**：呼叫 Gemini API，傳入學員弱點節點清單，生成繁體中文補強建議；結果可快取 24 小時。
- **大量資料表渲染**：建議採用 React Table，支援排序、分頁與匯出 Excel。
- **CSV 匯入處理**：前端使用 PapaParse 預先格式檢核；後端驗證重複 Email、欄位完整性後才建立帳號。
