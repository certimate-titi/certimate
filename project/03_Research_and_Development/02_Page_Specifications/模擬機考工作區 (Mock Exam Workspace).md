# 模擬機考工作區 (Mock Exam Workspace)

## 📌 頁面定位與目標

打造一個極具沉浸感、毫無干擾的考試環境。核心目標是 **逼真模擬 Pearson VUE 等真實機考介面**，讓考生在平時就熟悉真正的考場壓迫感。

## 🧩 核心畫面配置 (Layout)

本頁面應採用 **全螢幕模式 (Full-screen) 或隱藏主側邊欄**，確保畫面專注於題目本身。

### 1. 頂部資訊狀態列 (Header Status Bar)

- **計時器 (Timer)**：
  - 大字體顯示倒數時間 (如 `01:45:22`)。
  - 時間快到時變更顏色（如倒數 5 分鐘變為醒目紅色）或給予輕微動畫跳動。
- **進度區**：顯示當前題號與總題數 (如 `Question 12 of 65`)。
- **結束按鈕**：「提早交卷 (Submit Exam)」與「暫停測驗 (Pause)」。

### 2. 題目與操作主區塊 (Main Workspace)

- **題目顯示區**：
  - 支援 Markdown 與精準的 KaTeX 數學公式渲染。
  - 字體大小適中，背景色塊與文字應有極高的對比度（可提供明/暗色模式切換）。
- **選項操作區**：
  - 取代傳統的圓形 Radio input，採用大面積的卡片式點擊設計，確保滑鼠或平板手指點選零失誤。
  - 單選題點擊後卡片邊框變色；複選題則顯示 Checkbox 選中狀態。

### 3. 底部/側邊導覽控制列 (Navigation Controls)

- **左右切換**：「上一題 (Previous)」「下一題 (Next)」的大按鈕。
- **標記功能 (Mark for review)**：
  - 提供一個醒目的 Flag 或 Checkbox。標記的題目會在題號導覽網格中顯示特殊圖示，提醒考生交卷前再看一眼。
- **題號導覽網格 (Question Grid)**：
  - 點開可見一個包含所有題號的矩陣狀 Drawer（抽屜）或側邊欄。
  - 顏色編碼：
    - 灰色：未作答。
    - 藍色/綠色：已作答。
    - 黃色旗幟：標記待複查 (Marked)。

## 💻 技術面/實作建議

- **狀態管理與暫存 (Auto-save)**：
  - 使用者的每一個選擇都必須在背景自動儲存 (寫入 LocalStorage 或透過 Debounce 打 API 到資料庫)。
  - 避免因為瀏覽器當掉、網路斷線導致考生做了一小時的題目全部白費。
- **阻止頁面重整防呆 (Prevent Reload)**：
  - 使用 `beforeunload` 事件監聽，當使用者試圖按下 F5 或關閉分頁時，彈出原生警告框詢問「確定要離開測驗嗎？您的進度已暫存」。
- **鎖定功能 (Lockdown UI)**：
  - 設計純淨 UI，移除無關聯的 NavBar 與 Footer。
