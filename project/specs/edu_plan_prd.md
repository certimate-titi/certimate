## 1. 產品概述

### 1.1 背景
CertiMate ULTRA 方案定位為 B2B 教育市場，服務對象為證照培訓教師與教育機構。為完善 P-C（Parent-Child）帳號模型，新增 EDU 方案供機構底下的學生使用。

### 1.2 目標
- 建立 ULTRA（教師/機構） → EDU（學生）的帳號階層關係
- 提供學生受限但實用的學習功能
- 讓教師透過 edu-console 管理學生與追蹤學習成效

### 1.3 非目標
- EDU 不提供自助註冊（必須由機構管理者建立）
- EDU 不涉及付費（費用由 ULTRA 方案承擔）
- 本階段不支援學生自行升級為付費方案

## 3. 帳號生命週期

### 3.1 建立
```
ULTRA 機構管理者 → edu-console → CSV 匯入（需先簽署 DPA）
                                → 手動新增（email + 姓名）
                                ↓
                          系統建立 EDU 帳號
                                ↓
                          寄送啟用 Email 給學生
                                ↓
                          學生設定密碼、完成 onboarding
```

### 3.2 使用
```
學生登入 → 儀表板（受限版）
         → 作答機構指派的測驗
         → AI 對話（5次/天）
         → 查看知識心智圖
         → 複習錯題
         → 接收學習週報
```

### 3.3 移除
```
機構管理者 → edu-console → 移除學生
                              ↓
                        EDU 帳號降級為 FREE
                              ↓
                        學習記錄保留 90 天
```

### 3.4 機構取消
```
ULTRA 方案取消/到期
        ↓
所有 EDU 帳號同步降級為 FREE
        ↓
edu-console 存取權限關閉
```

## 4. edu-console 流程

### 4.1 首次使用流程
```
教師購買 ULTRA 方案
    ↓
首次進入 edu-console
    ↓
簽署 DPA（資料處理協議）
    ↓
建立機構資料（機構名稱、類型）
    ↓
匯入學生（CSV 或手動）
    ↓
建立班級/群組
    ↓
指派測驗或學習資源
```

### 4.2 日常管理流程
```
edu-console 首頁
    ├── 班級總覽（出席率、平均成績、弱點分布）
    ├── 學生管理（新增/移除/查看個別學習狀態）
    ├── 測驗管理（指派測驗、查看成績、生成補救練習）
    ├── 學習報告（週報/月報、班級趨勢）
    └── 設定（機構資料、DPA、帳號額度）
```

### 4.3 超額學生計費
```
機構學生數 > 30
    ↓
系統顯示超額確認對話框
    「超過 30 人的額度，每增加 1 人將加收 NT$30/月。
     目前人數：31，每月加收：NT$30。確認新增？」
    ↓
確認 → 新增學生，下期帳單反映加收
取消 → 返回學生管理頁
```

## 5. 技術需求

### 5.1 後端 API（7 個新端點）
| 方法 | 路徑 | 說明 |
|------|------|------|
| POST | /b2b/dpa/sign | DPA 電子簽署 |
| GET | /b2b/dpa | 查詢 DPA 簽署狀態 |
| POST | /b2b/students/import | CSV 批次匯入學生 |
| DELETE | /b2b/students/{id} | 移除學生（降級為 FREE） |
| GET | /b2b/class/weakness | 班級弱點統計 |
| POST | /b2b/exam/remediation | 生成補救練習卷 |
| GET | /b2b/students/{id}/report | 個別學生學習報告 |

### 5.2 資料庫變更
- `users` 表新增 `org_id` FK → `institutions` (已在 migration 028 完成)
- `institutions` 表新增 `dpa_signed_at` 欄位
- 新增 `institution_surcharges` 表（追蹤超額學生計費）

### 5.3 前端頁面
- `/edu-console` — 機構管理首頁（已有基礎版）
- `/edu-console/students` — 學生管理
- `/edu-console/exams` — 測驗指派與成績
- `/edu-console/reports` — 學習報告
- `/edu-console/settings` — 機構設定
