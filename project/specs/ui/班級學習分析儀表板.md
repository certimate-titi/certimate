# 班級學習分析儀表板

## 描述
B2B 機構管理者的班級學習數據總覽。路由：`/admin`（Ultra 方案 + org_admin 角色限定）

## 行為
### 班級健康 KPI 列（頂部）
- 4 張 KPI 卡片：總學生數（中性）/ 活躍率（綠色）/ 需關注人數（紅色）/ 班級平均分（中性）

### 早期預警面板
- 自動觸發條件（任一）：平均分 <60 / 連續 3 次趨勢下降 / 5 天以上未登入
- 預警卡片：學員名字、最弱節點與分數、距上次登入天數、趨勢圖示
- 每張卡片附「AI 補強」一鍵按鈕

### 快速操作列
- 批量匯入名單（CSV + 個資同意聲明）
- 派發模擬考卷（選範圍 + 設期限）
- 全局弱點分析

### 學生能力檔案列表
- 列表欄位：頭像 + 趨勢箭頭、姓名/Email、進度條、平均分（彩色）、狀態標籤
- 點擊展開 Competency Detail：各知識節點能力分析條 + 「AI 個人化補強建議」/「指派補考」按鈕

### 班級學習概況（右側統計面板）
- 班級平均分 + 週趨勢
- 共同弱點 Top 3
- 「匯出詳細報告」按鈕

### 個資合規
- CSV 匯入前強制顯示個資處理同意提示
