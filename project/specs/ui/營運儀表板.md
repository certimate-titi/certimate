# 營運儀表板

## 描述
超級管理員的平台營運數據總覽。路由：`/super-admin/dashboard`（super_admin / admin 角色限定）

## 行為
### KPI 卡片
- DAU/MAU（即時）、新註冊用戶數（今日/本週/本月）、訂閱轉換率（每小時）
- MRR（每日）、AI Token 今日消耗金額（每 15 分鐘）、任務佇列深度（即時）

### 趨勢圖表
- 用戶成長曲線：DAU/MAU 折線圖（30/90 天/年度切換）
- 營收趨勢：MRR + ARPU + Churn Rate 多軸折線圖
- AI 成本分析：各 LLM 模型（Gemini Flash / Claude Sonnet / GPT-4o）每日 Token 堆疊柱狀圖（Phase 1 僅 Gemini，多模型為未來規劃）
- 系統負載：Cloud Run CPU/Memory、Cloud SQL 連線數、Redis 快取命中率（Phase 1 為 Firebase 架構：Firestore 讀寫次數、Firebase Auth 活躍用戶、Hosting 頻寬；未來遷移後切換至完整指標）

### 近期異常警報
- Worker 任務失敗率 >5%
- 單一用戶觸發 Rate Limit
- Cloud SQL 連線數 >80%
- OpenRouter 單日費用超預算

## 子模組（其他路由）
- 用戶管理：`/super-admin/users`（搜尋/篩選/停權/調整訂閱/批量操作）
- 財務管理：`/super-admin/finance`（訂閱分布/交易紀錄/退款審核/優惠碼/成本分析）
- 內容審核：`/super-admin/moderation`（上傳審查/AI 濫用監控/檢舉管理）
- 系統設定：`/super-admin/settings`（AI 模型路由/方案限額/公告/Feature Flags/管理員 CRUD）
