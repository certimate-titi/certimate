# 個人儀表板

## 描述
使用者登入後的指揮中心，一眼掌握學習進度並提供核心操作入口。路由：`/dashboard`

## 行為
### 科目切換器（頂部）
- 水平分頁標籤：科目名稱 + 考試倒數天數 + 任務模式徽章（Sprint/Standard/Mastery）
- 切換後下方所有數據聯動更新
- 末端固定「+ 新增備考科目」按鈕
- 單科時仍顯示（僅一個標籤）

### 歡迎與概覽區
- 個人化問候（依當前科目動態調整）
- 任務模式徽章（Hover 展開 Tooltip：模式目標 + 策略 + 考題配分權重）
- 每日學習連勝 Streak（火焰圖示 + 斷連保護冰凍機制）
- 核心指標卡片：考試倒數、累積完成題數、系統預測及格率
- 能力分佈雷達圖（連動考題產生器的弱點出題）

### 快速上傳區
- Tab A 實體檔案：拖曳上傳（PDF/MD/TXT 全方案；Image 需 Pro Plus）
- Tab B 影音連結：YouTube URL 輸入框（全方案可用）
- 隱性版權同意：按鈕下方灰色免責小字
- 解析狀態回饋：PENDING 進度條 → COMPLETED Toast 通知 → FAILED 原因 + 重試

### 動態提醒與待辦
- 每日微任務（Daily Quests）+ 經驗值
- 近期錯題複習（遺忘曲線提示）
- 未完成考卷進度
- Ultra 專屬：匿名共同備考人數
