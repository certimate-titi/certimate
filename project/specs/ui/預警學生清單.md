# 預警學生清單

## 描述
符合預警條件的高風險學生列表，由系統主動浮出問題學員。

## 行為
- 觸發條件由機構管理者自訂（系統預設：平均分 <60 / 連續 3 次趨勢下降 / 5 天以上未登入），可於「預警規則設定」頁面調整
- 預警卡片顯示：學員名字、最弱節點名稱與分數、距上次登入天數、趨勢圖示
- 每張卡片附「AI 補強」一鍵按鈕（呼叫 Gemini API 生成繁體中文補強建議，快取 24 小時）
- 可點擊進入個人能力剖面
