# 功能開關設定

## 描述
超級管理員管理 Feature Flags 的設定頁面，支援分群控制與漸進式上線。

## 行為
- Flag 列表：flag_key、描述、啟用狀態、rollout 百分比、最後更新者/時間
- 新增/編輯 Flag：
  - flag_key（唯一識別碼，如 `enable_notion_sync`）
  - 描述
  - 啟用/停用開關
  - rollout_percentage（0-100% 滑桿）
  - 目標篩選條件：
    - 依訂閱方案（FREE / PRO / PRO_PLUS / ULTRA）
    - 依特定使用者 ID 清單
    - 依機構 ID
  - 支援 A/B 測試分組
- Flag 狀態快取於 Redis，Fallback 查 Cloud SQL
- 所有變更寫入稽核日誌
