# 財務管理

## 描述
平台營收、訂閱與支付分析頁面。路由：`/super-admin/finance`（super_admin / admin 角色限定）

## 行為
### KPI 卡片（6 張）
- Total MRR（月經常性收入）
- Churn Rate（流失率）
- ARPU（每用戶平均收入）
- Expansion Revenue（升級收入）
- Failed Payments（付款失敗次數）
- Refunds（退款總額）

### 圖表
- MRR 趨勢折線圖（LineChart）
- 營收分布圓餅圖（PieChart）：新客、升級、流失
- 付款狀態堆疊柱狀圖（BarChart）：成功、待處理、失敗
- 訂閱方案分布

### 篩選
- 搜尋交易
- 狀態篩選（success / failed / refunded）
- 日期範圍
- CSV 匯出
