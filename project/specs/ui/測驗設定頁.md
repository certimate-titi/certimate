# 測驗設定頁

## 描述
使用者自訂模擬考卷參數的設定介面，支援範圍選擇、題型偏好與難度配置。

## 行為
### 測驗範圍選擇
- 樹狀選擇器（根目錄=資源，展開=心智圖章節節點）
- 精準勾選特定概念
- 「一鍵全選弱點區塊」（結合心智圖紅色標記）

### 測驗參數
- 題數：預設按鈕選擇（10 / 20 / 50 / 100）
- 難易度分配：1-3 級滑桿
- 題型偏好：勾選（單選 / 多選 / 填空 / 情境計算題等）

### 生成與等待
- 「生成專屬模擬考」大按鈕
- 多階段 Skeleton 進度提示（非 Spinner）：
  - "正在從向量庫提取知識點..." (0-3s)
  - "AI 教練正在設計考題陷阱..." (3-8s)
  - "校對邏輯與排版中..." (8-12s)
  - "考卷準備完畢！" → 自動導向機考工作區
- 未選範圍時按鈕禁用
