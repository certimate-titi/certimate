# 稽核日誌

## 描述
管理員與系統操作的完整稽核紀錄（唯讀、append-only）。路由：`/super-admin/audit-logs`（super_admin / admin 角色限定）

## 行為
### 即時日誌串流
- 透過 Firestore `onSnapshot` 即時監聽 `admin_audit_logs` collection
- 依時間戳降序排列，預設載入最近 100 筆

### 篩選
- 操作類型篩選（CREATE / UPDATE / DELETE / LIST / GET / WRITE）
- 日期範圍
- 關鍵字搜尋

### 日誌欄位
- 時間戳
- 管理員 ID / Email
- 操作類型
- 目標資源
- 詳細內容
- 錯誤資訊（含 stack trace，如適用）

### 操作
- CSV 匯出下載
- 分頁導覽

### 認證資訊
- 顯示當前登入管理員的 user ID、Email、驗證狀態
