# 系統設定

## 描述
平台層級的配置管理頁面。路由：`/super-admin/settings`（super_admin 角色限定）

## 行為
### Tab 1 — AI 模型路由（Cpu）
- 選擇 Gemini API 模型
- Fallback 策略設定
- 成本追蹤

### Tab 2 — 方案限額（Zap）
- 各方案 Token 限制
- API 速率限制
- 文件大小限制

### Tab 3 — 系統公告（Bell）
- 建立平台公告
- 目標對象分群
- 發布 / 排程

### Tab 4 — Feature Flags（Flag）
- A/B 測試控制
- 功能開關
- Rollout 百分比
- 依方案 / 用戶 ID / 機構篩選

### Tab 5 — 管理員帳號（ShieldCheck）
- 新增 / 移除管理員
- 角色管理（super-admin / moderator / analyst）
- 活動監控

### 共用操作
- 儲存按鈕（含 loading 狀態）
- 重新載入伺服器資料
- 所有變更自動記錄至稽核日誌
