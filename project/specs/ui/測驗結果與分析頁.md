# 測驗結果與分析頁

## 描述
交卷後的即時反饋頁面，建立正向成就感並精準點出學習盲點。

## 行為
### 總結成績看板
- 情境化動態回饋：進步時 Confetti 撒花 + 開心表情；退步時溫暖慰藉提示
- 大數字得分展示（避免生硬的「Fail」，改用鼓勵語氣）
- 進步幅度：與上次測驗比較（如「↑ 提升 15 分」）
- 完賽數據：作答總時間、平均每題時間、標記題答對率

### 知識點掌握度分析
- 長條圖：橫軸=知識節點、縱軸=答對率
- 顏色：<60% 紅色警戒、>80% 綠色安全
- AI 考後總評：LLM 即時生成的文字分析與補強建議

### 行動導覽
- 第一順位：「進入錯題本進行深度檢討」（直達 AI 教練頁）
- 第二順位：「回到儀表板」
- 成績卡片分享（含暱稱、得分、AI 鼓勵語、品牌浮水印），支援分享至 LinkedIn
- 底部免責小字：「本模擬考試結果僅反映當前熟悉度」
