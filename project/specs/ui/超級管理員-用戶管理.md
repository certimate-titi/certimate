# 用戶管理

## 描述
超級管理員的用戶生命週期管理頁面。路由：`/super-admin/users`（super_admin / admin 角色限定）

## 行為
### 搜尋與篩選
- 關鍵字搜尋（姓名 / Email）
- 訂閱方案篩選（FREE / PRO_199 / PRO_PLUS_399 / ULTRA_1599）
- 排序：最近登入、註冊日期
- 分頁導覽（上一頁 / 下一頁）

### 用戶列表
- 欄位：姓名、Email、訂閱方案、狀態（active / suspended / cooling）、最近登入、註冊日期、Token 使用量
- 狀態標籤以顏色區分

### 操作
- 檢視詳情 → `/super-admin/users/{userId}`
- 發送 Email
- 變更角色
- 停權 / 解除停權
- 刪除帳號
- 批量匯出 CSV

### 管理員操作日誌
- 所有操作透過 `logAdminAction()` 自動記錄至稽核日誌
