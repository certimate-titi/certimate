# 用戶詳情

## 描述
單一用戶的完整資料與行為分析頁面。路由：`/super-admin/users/{userId}`（super_admin / admin 角色限定）

## 行為
### 用戶基本資料
- 頭像、姓名、Email、訂閱方案、狀態、註冊日期
- 操作按鈕：發送 Email、停權、調整訂閱

### 使用量（Usage）
- Token 消耗量
- API 呼叫次數
- 儲存空間使用

### 訂閱（Subscription）
- 當前方案、計費日期
- 發票連結

### 活動紀錄（Activity）
- 登入歷史時間軸
- 考試完成次數（柱狀圖）
- 文件上傳紀錄

### 審核紀錄（Moderation）
- 內容標記、警告、停權歷史

### 圖表
- 考試嘗試次數趨勢（BarChart）
- Token 使用分布（PieChart）
