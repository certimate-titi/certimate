# 模擬機考工作區

## 描述
全螢幕沉浸式考試環境，仿 Pearson VUE 真實機考介面。

## 行為
### 頂部狀態列
- 倒數計時器（大字體，≤5 分鐘變紅色跳動）
- 進度：「Question 12 of 65」
- 「提早交卷」+「暫停測驗」按鈕

### 題目主區塊
- 支援 Markdown + KaTeX 數學公式渲染
- 卡片式大面積選項（非 Radio input），點擊邊框變色
- 單選：邊框高亮；多選：Checkbox 選中狀態

### 導覽控制
- 「上一題」/「下一題」大按鈕
- 「Mark for review」Flag 標記
- 題號導覽網格（Drawer/側邊欄）：灰=未作答、藍/綠=已作答、黃旗=標記待複查

### 系統行為
- Auto-save：每次選擇自動暫存（LocalStorage + Debounce API）
- `beforeunload` 防呆：離開時彈出原生警告
- 隱藏 NavBar / Footer（Lockdown UI）
