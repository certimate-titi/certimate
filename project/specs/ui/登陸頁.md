# 登陸頁

## 描述
對外行銷門面，展示價值主張並轉換訪客為註冊用戶。

## 行為
- Hero Section：大標題 + 副標題 + 「立即免費註冊」CTA + 「查看 Demo」次要按鈕
- 核心功能展示區：三步驟流程（上傳 → 生成心智圖/考卷 → AI 教練解析），採滾動視差或標籤切換
- 社群證明：數字佐證（提升 300% 複習效率等）+ 使用者見證卡片
- 定價方案表：Free / Pro 199 TWD / Ultra 499+ TWD 三方案對比，強調免費版低門檻與 Pro 版高價值
- Footer：再次 CTA + 隱私權政策 / 服務條款 / 聯絡我們連結
