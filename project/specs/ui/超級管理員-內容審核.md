# 內容審核

## 描述
內容審查、AI 濫用偵測與使用者安全管理。路由：`/super-admin/moderation`（super_admin / admin 角色限定）

## 行為
### 審核佇列（Moderation Queue）
- 標記項目：大型 PDF、OCR 失敗、觸發關鍵字的對話、使用者檢舉（如版權聲明）
- 狀態：flagged / pending / reported
- 操作：核准、駁回、冷卻用戶、封鎖

### AI 濫用監控（Abuse Monitoring）
- 偵測項目：QA 轟炸（15 次/10 分鐘）、Token 濫用（2.5M/小時）、API 濫用（500 次/分鐘）
- 狀態：cooling（冷卻中）/ flagged / blocked
- 手動解除冷卻功能

### 統計報表（4 張卡片）
- 待處理檢舉數
- 今日自動標記數
- 冷卻中用戶數
- 系統誤判率

### 優先度指標
- 各項目顯示優先度等級，協助管理員排序處理順序
