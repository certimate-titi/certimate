# 身分驗證頁

## 描述
使用者註冊、登入與密碼重設的身分驗證介面，採低摩擦設計。

## 行為
### 註冊頁
- 表單：Email（必填）+ 密碼（必填，即時強度檢測進度條）
- SSO：「Continue with Google」（最優先）+「Continue with GitHub」
- 同意核取方塊：服務條款 + 隱私權政策（含「上傳資料不用於訓練 AI 模型」聲明）
- 密碼顯示/隱藏切換（eye icon）

### 登入頁
- 表單：Email + 密碼
- 「記住我」核取方塊 +「忘記密碼？」連結
- SSO 按鈕同註冊頁

### 忘記密碼
- Step 1：輸入 Email → 發送重設信
- Step 2：點擊信件連結 → 輸入新密碼
- 成功後顯示綠色勾勾與確認提示
