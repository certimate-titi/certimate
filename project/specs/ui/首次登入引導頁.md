# 首次登入引導頁

## 描述
新用戶首次登入後的步驟式引導流程，建立專屬學習歷程以啟用個人化功能。

## 觸發條件
- `onboarding_completed === false` 時強制導向
- 完成後標記 `onboarding_completed = true`，後續登入不再觸發

## 行為
### Step 1 — 歡迎與基本資訊
- 歡迎動畫（Lottie / CSS Animation）
- 顯示名稱輸入（預設 Email @ 前綴，可跳過）
- 頂部進度指示器 Step 1/4

### Step 2 — 選擇備考科目（唯一必填）
- 分類標籤：IT / 金融 / 語言 / 醫療 / 公務員 / 其他
- 即時模糊搜尋（中英文）
- 科目卡片點選，支援多選
- 已選科目面板（底部或右側）：
  - 預計考試日期（預設 3 個月後）+ 動態模式提示（<14天: Sprint / 1-3月: Standard / >6月: Mastery）
  - 自評程度：初學者 / 有基礎 / 進階複習
- 至少選 1 科才可進入下一步

### Step 3 — 學習偏好設定（全選填）
- 每日學習時間：15 分 / 30 分（預設）/ 1 小時 / 自訂
- 偏好方式：大量刷題 / 觀念理解優先 / 混合模式（預設推薦）

### Step 4 — 確認與啟動
- 摘要卡片（含各區塊「編輯」按鈕可跳回修改）
- 「開始我的學習旅程」CTA → 全螢幕啟動動畫（1.5-2 秒）→ 導向個人儀表板
