# 資源庫與心智圖

## 描述
管理已上傳教材，並以互動式心智圖視覺化知識結構，核心在右側的溯源與 AI 教練面板。

## 行為
### 資源列表（左側管理區）
- 「+ 新增資源」按鈕（同儀表板上傳組件）
- 卡片式 / 列表式切換，支援資料夾與 Tag 分類
- 屬性：檔名、上傳日期、大小/長度、AI 狀態（解析中/成功/失敗）、已生成題數
- 刪除需防呆警告：「刪除將同步移除心智圖關聯節點，且停止 AI 出題，此動作無法復原」

### 溯源與 AI 教練面板（中央+左半，70-75% 寬度）
- **上半：動態原文溯源**
  - PDF/MD：渲染 Markdown 原文 + Highlight 核心句 + 頁碼標示
  - YouTube：嵌入播放器（自動跳轉時間軸）+ 同步逐字稿滾動
- **下半：上下文感知 AI 教練**
  - Zero-Shot Context：自動載入當前節點主題與溯源原文
  - Quick Action Chips：「五歲小孩聽得懂」/「總結這三段」/「轉成 1 題測驗」
  - 主動式引導：發呆過久教練主動提問
  - Free 用戶：單一節點 ≤3 次追問，耗盡後毛玻璃遮擋 + 升級提示

### 互動式心智圖（右側，25-30% 寬度）
- AI 萃取的知識樹節點，點擊節點刷新左側面板
- 色彩語意：精熟綠色 / 常錯紅色
- 可全螢幕展開或收合

### Ultra 專屬
- Notion 同步設定（OAuth 或 Database ID）
- Google Drive 同步（授權指定資料夾）
