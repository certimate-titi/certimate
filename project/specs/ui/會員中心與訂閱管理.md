# 會員中心與訂閱管理

## 描述
使用者管理個人資料、訂閱狀態、系統偏好與學習成就的整合入口。

## 行為
### 個人資料分頁
- 大頭貼、姓名、顯示名稱、Email 修改
- 變更密碼
- Danger Zone：「匯出所有資料」+「刪除帳號」（需二次確認 Modal）

### 訂閱與帳單分頁
- 目前方案卡片：當前方案 + 下次扣款日期/金額
- Free 用戶：顯示升級 CTA + 功能比較表
- 付費用戶：「取消訂閱」無痛連結（不隱匿）
- 帳單歷史紀錄：月扣款列表 + 發票/收據 PDF 下載
- 導向 Stripe Customer Portal 處理信用卡管理

### 系統偏好分頁
- 淺色/深色模式切換
- 通知設定：每日複習提醒、考前衝刺信等 Email 開關

### 學習歷程與成就分頁
- 成長時間軸：從初次登入到攻克各知識模組的視覺化歷程
- 成就徽章櫃：連續登入、克服弱點等行為解鎖的榮譽徽章
