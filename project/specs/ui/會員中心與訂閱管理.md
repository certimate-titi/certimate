# 會員中心與訂閱管理

## 描述
使用者管理個人資料、訂閱狀態、系統偏好與學習成就的整合入口。

## 行為
### Tab 1 — 個人資料（Profile）
- 大頭貼、顯示名稱、Email 顯示
- 更新個人資料（display_name、age、education、career）

### Tab 2 — 訂閱與帳單（Billing）
- 目前方案卡片：當前方案 + 下次扣款日期/金額
- 使用量摘要（AI 對話次數、上傳數、考試數、Vision OCR 額度）
- Free 用戶：顯示升級 CTA + 功能比較表
- 付費用戶：「取消訂閱」無痛連結（不隱匿）
- 帳單歷史紀錄：月扣款列表 + 發票/收據下載

### Tab 3 — 安全性（Security）
- 變更密碼
- 雙重驗證（2FA）設定
- Danger Zone：「刪除帳號」（需二次確認 Modal）

### Tab 4 — 系統偏好（Preferences）
- 通知設定：每日複習提醒、考前衝刺信等 Email 開關
- 匯出所有資料

### Tab 5 — 成就（Achievements）
- 成就徽章櫃（AchievementGrid）：連續登入、克服弱點等行為解鎖的榮譽徽章
- 成長時間軸（GrowthTimeline）：從初次登入到攻克各知識模組的視覺化歷程
