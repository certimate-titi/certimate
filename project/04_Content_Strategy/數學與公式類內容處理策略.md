# 數學與公式類內容處理策略 (Math & Formula Parsing Strategy)

在各類檢定與考試中，數學、物理、統計等理工科目的教材充滿了複雜的**數學符號、方程式 (Equations)、圖表與手寫計算過程**。這些內容傳統上是 AI 辨識的超級災難區。

為了讓 CertiMate 能真正通吃這些「硬核理工科目」，必須在此領域建立一套專屬的內容處理與渲染流水線。本策略分為「輸入端解析」與「輸出端渲染」兩個維度：

---

## 1. 輸入端：檔案解析與公式辨識 (Input & Parsing)

處理含有數學公式的 PDF 或圖片時，絕對不能使用普通開源的 PDF-to-Text 工具 (例如 PyPDF2)，那會讓公式變成一堆亂碼符號，導致後續 LLM 出題完全失真。

### A. 多模態視覺解析 (Vision-Based OCR)
- **策略**：放開放棄純文字萃取，全面採用具備「多模態 (Multimodal)」能力的 OCR 引擎或 LLM。
- **實作選擇**：
  1. **Gemini 1.5 Pro / Flash (Native Vision)**：我們系統架構端點本就選擇 GCP。Gemini 模型身為目前最強大的多模態模型之一，我們可以直接將含有數學公式的 PDF 轉成圖片格式 (Images) 再丟入模型。Prompt 下達：`"請精準理解畫面中的文字與數學算式，並將所有的數學公式一律轉換為標準的 LaTeX 語法格式返回。"`
  2. **專門的 Math OCR API (如 Mathpix Snip)**：若遇上高階的付費用戶 (Pro 版可解鎖此通道)，遇上極度複雜的手寫微積分推導講義，可考慮串接市面上辨識公式最強的 Mathpix API，將圖片完美轉成 LaTeX 再丟給我們的 LLM。

### B. 手寫筆記的處理 (Handwritten Notes)
理工科學生常上傳 iPad 上的 GoodNotes 或 Notability 手寫推演講義。
- **挑戰**：手寫字跡潦草，且公式排版不規則。
- **解法**：同樣依賴強大的 Vision 模型。在系統前端，我們會**提示使用者「若上傳手寫講義，請確保字跡清晰」**。後端收到圖像後，交由 Gemini Vision 解析手寫邏輯，轉譯為結構化的 LaTeX 文本，然後再進行後續的 Embedding 切塊。

---

## 2. 輸出端：考題生成與畫面渲染 (Output & Rendering)

如果 LLM 能正確讀懂 LaTeX 公式出題，那麼前端 UI 也必須具備完美顯示這些公式的能力。

### A. 全面統一採用 LaTeX / KaTeX 標準
- **後端限制**：在生成 50 題 JSON 考題的 Prompt 中，必須強制加上鐵律約束：`"所有題目與選項中的數學式子、化學式、上下標，都必須嚴格使用 LaTeX 標籤包覆，例如行內公式用 $...$，獨立公式用 $$...$$。"`。
- **前端渲染庫 (KaTeX)**：在 React / Next.js 的前端介面中，**捨棄傳統的 MathJax (渲染較慢)，全面導入 KaTeX 函式庫**。
- **預期效果**：當系統從資料庫讀取包含 `$E=mc^2$` 的題目時，KaTeX 能在網頁上以教科書等級的排版格式瞬間渲染出完美的方程式，帶來極度專業的學習體驗。

### B. 結合圖表的綜合題型
數學與物理考題常見「請看下圖，計算阻力」。
- **實作解法 (進階護城河)**：
  1. 在解析階段，MCP 或 PDF 解析器若偵測到獨立圖表，需將圖表裁切並上傳至 GCS，並在生成的 Markdown 中插入 `![圖表1](url)`。
  2. 出題時，LLM 可參照該圖表生成對應方程式的考題。
  3. 前端測驗介面必須支援**「圖表與公式混排顯示」**的 Markdown 渲染組件。

---

## 3. 免費與付費方案的權限切割 (Tier Strategy)

數學解析極其耗費多模態模型的運算資源 (Vision Tokens 遠比 Text Tokens 貴)。這剛好能作為 Free/Pro 的完美切割點：

- **🆓 免費版 (Free Tier)**：
  - **限制**：只支援**純文字** PDF 或網頁匯入，不支援處理手寫講義、不支援圖片格式的複雜公式 OCR。
  - **系統行為**：若使用者上傳了充滿圖片公式的講義，系統雖嘗試用輕量級 LLM 解讀，但會在畫面上提示「偵測到複雜公式，免費版解析準確率可能受限」。
- **👑 Pro 訂閱版 (199 TWD/月)**：
  - **解鎖「旗艦級公式解析模式」**：後端掛載**最強的 Vision 模型 (如 Gemini 1.5 Pro) 或串連 Mathpix OCR 模型**，支援上傳滿滿算式的 iPad 手寫筆記、黑板板書照片。
  - **賣點**：只要 199 元，你就能把你那字跡潦草的微積分筆記本，一鍵變成排版堪比原文書的漂亮線上模擬考題！這對理工科學生將是毀滅等級的吸引力。

## 4. 總結
將「LaTeX 轉換」與「前端 KaTeX 渲染」列為系統核心規格，加上透過 Vision 模型解析手寫公式，CertiMate 就能輕鬆跨出單純背誦式文科的圈子，一舉吃下微積分、統計學、工程數學等高門檻的「硬核理工測驗市場」。
