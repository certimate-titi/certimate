# 考題生成與結構設計

## 1. 考題 JSON 結構標準 (Schema)
為了讓前端有效渲染，AI 輸出的考題必須符合以下結構：

```json
{
  "exam_title": "使用者自訂講義名稱 - 第三章測試",
  "questions": [
    {
      "id": "q_001",
      "type": "single_choice",
      "difficulty": "medium",
      "question_text": "根據上傳的文件內容，下列何者是該章節提到的首要步驟？",
      "options": {
        "A": "選項 A 描述",
        "B": "選項 B 描述",
        "C": "選項 C 描述",
        "D": "正確選項 D 描述"
      },
      "correct_answer": "D",
      "explanation": "根據講義第 3 頁第 2 段，所有規劃必須由重點 D 出發。",
      "knowledge_tags": ["章節重點 1", "核心概念 A"]
    }
  ]
}
```

## 2. 知識心智圖 JSON 結構標準 (Schema)
為了讓前端能將文件轉化為互動式心智圖，並支援「點擊節點查看原始資料」，AI 生成的心智圖結構應如下：

```json
{
  "document_id": "doc_12345",
  "root": {
    "node_id": "root_01",
    "label": "第三章：商業目標與技術規劃",
    "source_chunk_ids": ["chunk_001", "chunk_002"],
    "summary": "本章節概述從商業痛點出發，如何選擇合適的 AI 技術架構。",
    "children": [
      {
        "node_id": "sub_01",
        "label": "1. 評估首要步驟",
        "source_chunk_ids": ["chunk_003"],
        "summary": "所有規劃必須由定義明確的商業目標與痛點出發。",
        "children": []
      },
      {
        "node_id": "sub_02",
        "label": "2. 資料安全風險",
        "source_chunk_ids": ["chunk_004", "chunk_005"],
        "summary": "評估導入 LLM 時可能面臨的機敏資料外洩風險。",
        "children": []
      }
    ]
  }
}
```

## 3. Prompt 工程守則
- **角色扮演**：設定 LLM 為嚴格的國家考試出題委員與專業知識萃取員。
- **選項誘答性**：要求 LLM 產生的錯誤選項 (Distractors) 不能太瞎，必須是具備邏輯的常見誤區。
- **來源標示與節點綁定**：要求在考題的 `explanation` 以及心智圖的 `source_chunk_ids` 中，精準對應到分塊的 ID，確保使用者能溯源檢視。
