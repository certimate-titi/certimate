# TiTi｜AI 賦能學習平台 -- 策略計畫書

**Product Strategy Document v3.0 -- 2026 年 4 月**

---

## 一、專案願景與使命

### 1.1 願景

成為華語圈首屈一指的「AI 賦能證照考試平台」，打破傳統單向輸入的學習模式，利用生成式 AI 技術將龐雜的考試資源轉化為個人化的學習體驗，幫助每位學習者以最高效率取得專業認證。

### 1.2 使命

> **TiTi 的使命：用 AI 讓每一次考試準備都變得更有效率、更有依據。**

### 1.3 雙軌產品架構

TiTi 為雙軌產品平台，共享底層 RAG 引擎與題庫基礎設施：

```
                        TiTi 平台
                            │
          ┌─────────────────┴─────────────────┐
          │                                   │
  ┌───────▼────────┐                 ┌────────▼───────┐
  │  系統一         │                 │  系統二         │
  │  個人證照學習   │                 │  老師輔助系統   │
  │  Personal Pro  │                 │  EduAssist     │
  └───────┬────────┘                 └────────┬───────┘
          │                                   │
  使用者：考生                         使用者：老師
  目標：通過目標考試                    目標：高效出題＋追蹤學生學習
  商業模式：B2C 訂閱                   商業模式：B2B 學校/班級授權
```

本文件聚焦系統一（B2C）之整體策略。系統二（B2B）之完整規劃 → 詳見 06_B2B_機構方案規劃.md

### 1.4 共用底層基礎設施

兩套系統共享以下核心元件，降低開發成本：

- **RAG 引擎**：考點驅動的混合召回機制
- **向量題庫**：公共考古題庫（個人系統）/ 老師自建題庫（教師系統）
- **出題規劃層**：先定骨架再填題目的核心邏輯
- **批改引擎**：選擇題自動批改 + 考點對應標注
- **信度標示系統**：🟢🟡🔴 三層標示

→ 詳見 04_技術架構總覽.md

## 二、市場分析與目標用戶

### 2.1 個人證照學習市場（B2C）

| 類別 | 市場概況 | 優先級 |
|------|---------|--------|
| 金融證照 | 每年逾 30 萬人次報考，全選擇題，考古題完整公開 | 🏆 A |
| 不動產證照 | 不動產經紀人 + 地政士，市場穩定，科目重疊度高 | 🏆 A |
| iPAS 經濟部產業人才 | AI 規劃師等新興科技類，市場成長快 | 🥈 B |
| 公務員/高普考 | 每年數萬報考，但申論題比例高 | 🥈 B |
| 醫療專技 | 護理師、藥師等，需人工審題機制 | 🥉 C |
| 語言證照 | 考古題幾乎無法合法取得，競爭強 | ❌ 暫緩 |

### 2.2 價值主張

- **對考生**：節省整理重點與找尋考古題的時間，透過 AI 產生的模擬考卷快速找出知識盲點
- **核心差異**：不是問答，是符合真實考試格式的完整試卷，含題型比例、難度梯度、考點覆蓋

## 三、B2C 產品策略（Personal Pro）

### 3.1 產品定位

> 「用最短時間，最精準地通過目標考試。AI 知道你哪裡不會，每次模擬考都在幫你修補弱點。」

與競爭者的差異：

| 產品 | 定位 | 缺失 |
|------|------|------|
| NotebookLM | 被動問答 | 無法主動出題、無試卷結構、無學習追蹤 |
| 公職王、志光題庫 | 靜態考古題 | 無個人化、無 AI 解析、無弱點追蹤 |
| **TiTi Personal Pro** | 主動出題 + 考點覆蓋 + 弱點自適應 | — |

### 3.2 核心功能架構

```
素材層
├── 公共層（TiTi 維護）：歷屆考古題 + 官方命題大綱
└── 個人層（使用者上傳）：PDF / YouTube / 錄音 / PPT

知識層
├── 大綱考點樹（結構化）
├── 素材考點標注（自動 + 人工校正）
└── 向量索引（考點 metadata + 全文）

規劃層（核心差異化）
├── 試卷骨架生成（依大綱比例）
├── 覆蓋度分析（缺口考點警示）
└── 個人弱點加權出題

考試層
├── 計時作答 + 即時批改
├── 解析 + 考點對應
└── 掌握度地圖 + 學習歷程
```

→ 詳見 02_產品功能與方案矩陣.md

### 3.3 RAG 信度分層標示

| 標示 | 來源 | 說明 |
|------|------|------|
| 🟢 **考古題** | 歷屆真實試題 | 有官方標準答案，品質最高 |
| 🟡 **AI 模擬題（考古題為基底）** | AI 參考考古題生成 | 建議搭配原題複習 |
| 🟡 **AI 模擬題（使用者素材）** | 依上傳素材生成 | 素材品質影響正確性 |
| 🔴 **AI 模擬題（素材不足）** | 素材嚴重不足 | 準確性較低，建議先補充素材 |

### 3.4 使用者素材支援

| 素材類型 | 處理難度 | 建議策略 |
|---------|---------|---------|
| PDF / 文字教材 | 低 | 主力格式，優先支援 |
| YouTube 影片 | 中 | STT 後處理 + 術語字典校正 |
| 錄音檔 MP3/M4A | 中高 | 同上，加語速/雜音處理 |
| 投影片 PPT | 中 | 解析結構後向量化 |
| 手寫筆記照片 | 高 | Phase 3 後評估 |

## 四、四階梯定價策略概覽

TiTi B2C 採四層級訂閱制：

| 方案 | 月價 | 定位 |
|------|------|------|
| **FREE** | $0 | 每月 3 份模擬考，僅考古題，無 AI 生成 |
| **PRO_199** | $199/月 | 無限模擬考，AI 生成題，弱點追蹤 |
| **PRO_PLUS_399** | $399/月 | Pro 全功能 + 進階 AI 教練 + 手寫解析 |
| **ULTRA_1599** | $1,599/月 | 旗艦版：API 課綱自動同步、Notion/Google Drive 雙向整合、無限一切 |

**年繳優惠**：各方案年繳約省 17%（例如 PRO_199 年繳 $1,990/年）。

**冷啟動策略**：以考古題免費使用吸引用戶，轉換點在「想要 AI 個人化出題」的需求。

→ 詳見 03_定價與財務分析.md（完整價格矩陣、方案功能比較、財務模型）

## 五、四階段發展 Roadmap

### 5.1 整體時程總覽

| 階段 | 時程 | 系統一（B2C 個人） | 系統二（B2B 老師） |
|------|------|-------------------|-------------------|
| **Phase 1** | 0-6 個月 | 金融 + 不動產 MVP | -- |
| **Phase 2** | 6-12 個月 | 公職/iPAS 擴充 | 補習班老師 MVP |
| **Phase 3** | 12-15 個月 | 醫療/IT + 多媒體素材 | 國中學校版 |
| **Phase 4** | 15-18 個月 | 語言類評估 + 生態系整合 | 高中 108 課綱版 |

### 5.2 Phase 1：MVP 開發與驗證（0-6 個月）

**目標**：在金融 + 不動產類別跑通完整「出題 → 模擬考 → 解析 → 追蹤」閉環。

**月度里程碑**：

| 月份 | 重點工作 |
|------|---------|
| M1（4月） | 確立架構設計、AI Prompt 優化與測試（使用現有 LLM APIs） |
| M2（5月） | 開發後端資源處理 pipeline 與資料庫規劃；建立大綱考點樹（金融、不動產） |
| M3（6月） | 完成前端核心介面（上傳、測驗、錯題檢閱）；考古題結構化入庫，含考點 metadata 標注；內部 MVP 測試 |

**關鍵成果**：
- 支援 PDF / Markdown / PowerPoint / Word / 錄音檔等格式資源上傳
- 自動生成選擇題、名詞解釋等題型
- 選擇題模擬考：計時作答、批改、解析
- 素材覆蓋度分析頁面
- 基本弱點追蹤：跨次答對率記錄
- 基礎的錯題解析與觀念釐清功能

**刻意排除**：申論題批改、老師功能、語言類

### 5.3 Phase 2：封測、商業化與 B2B 啟動（6-12 個月）

**B2C 目標**：建立網站入口、邀請初期使用者進行封閉測試、導入付費機制。

**月度里程碑**：

| 月份 | 重點工作 |
|------|---------|
| M4（7月） | 招募 100 位封測用戶進行 Closed Beta 測試 |
| M5（8月） | 根據回饋進行 UI/UX 改善與 AI 準確度調優，修正幻覺（Hallucination）問題 |
| M6（9月） | 準備 Public Beta，實作金流（綠界）與會員進階權限系統 |
| M7（10月） | 官方 v1.0 正式上線，啟動第一波行銷宣傳與 SEO 操作 |
| M8（11月） | 導入進階金流訂閱機制，優化付費轉化漏斗；公職/iPAS 擴充 |
| M9（12月） | 達到 1,000 位活躍 Pro 付費使用者目標；評估 B2B 需求 |

**關鍵成果**：
- 確保中型 PDF（約 50 頁）能在 3 分鐘內完成解析與考題生成
- 收集 100 位使用者深度回饋，優化解析精準度
- 金流串接完成（綠界 ECPay）
- 完善進階工具功能（YouTube 轉考題、手寫數學公式解析）

**B2B 啟動**：同步於 Phase 2 後半啟動補習班老師 MVP → 詳見 06_B2B_機構方案規劃.md

### 5.4 Phase 3：雙系統擴充（12-15 個月）

**B2C 個人系統**：
- 醫療專技類上線（含人工審題機制）
- IT 資訊證照（官方樣題 + 社群整理）
- YouTube / 錄音素材支援
- iPAS 類別完整覆蓋

**B2B 老師系統**：進入國中學校市場 → 詳見 06_B2B_機構方案規劃.md

### 5.5 Phase 4：深化與生態系整合（15-18 個月）

**B2C 個人系統**：
- 語言類證照評估切入方式
- API 級別課綱自動同步（AWS Training、CNCF 等官方考綱）
- Notion / Google Drive 雙向整合（ULTRA 方案專屬）

**B2B 老師系統**：高中 108 課綱深度整合 → 詳見 06_B2B_機構方案規劃.md

**跨系統聯動**：補習班老師的學生可同步使用個人系統備考，老師題庫可授權豐富個人系統素材。

## 七、競爭差異化

### 7.1 Personal Pro 的護城河

**考試結構化輸出**：不是問答，是符合真實考試格式的完整試卷，含題型比例、難度梯度、考點覆蓋。

**考古題品質錨點**：以官方公開考古題驗證所有 AI 生成題，確保風格、難度、答案可靠性。

**個人弱點自適應**：跨次記憶學習歷程，主動偵測弱點並加強出題，靜態題庫與通用 AI 都做不到。

### 7.2 雙系統的整體護城河

兩套系統共享同一套 RAG 引擎與題庫基礎，但面向不同市場，互不競爭，還能相互導流——個人備考的使用者可以成為老師系統的學生端，老師建立的題庫可以豐富個人系統的素材。

→ B2B 護城河分析詳見 06_B2B_機構方案規劃.md
