# 法律聲明與免責條款規範 (Legal & Disclaimer Guidelines)

**建立日期**：2026-03-19
**文件目的**：針對 CertiMate 系統特性（特別是 AI 生成內容以及使用者上傳文件），列出在平台上線前必須涵蓋的使用者條款 (Terms of Service) 與隱私權政策 (Privacy Policy) 的核心法律宣告與免責聲明。

---

## 1. 核心法律風險與防禦策略

做為一個結合「生成式 AI」與「使用者自建內容 (UGC)」的平台，CertiMate 在營運上面臨以下三大核心潛在法律風險：

1. **使用者上傳侵權內容（著作權風險）**：使用者可能上傳受版權保護的電子書、官方教材、補習班講義。
2. **AI 幻覺與不正確的內容（過失免責）**：AI 可能產生錯誤的考題解答或錯誤的解釋，導致考生在真實考試中落榜。
3. **無間斷服務保證（第三方依賴問題）**：高度依賴如 OpenAI / Anthropic / Google 等第三方 LLM，當上游服務中斷時導致平台無法運作。

---

## 2. 服務條款 (Terms of Service) 必備免責聲明

在使用者註冊時，必須勾選同意的「服務條款」中，應明文涵蓋以下條款：

### 2.1 AI 內容免責聲明 (AI Content Disclaimer)
*   **非專業保證（No Guarantee of Accuracy）**：明確標明平台產生之測驗考題、知識節點、AI 教練的對話「皆由人工智慧模型自動生成，系統無法 100% 保證內容之正確性、完整性與時效性」。
*   **考試結果免責**：明確聲明「本平台提供的模擬考試成績僅供參考，**平台與營運方對使用者的實際考試、證照取得結果不負任何直接或間接之擔保責任**」。如因信賴本系統解答而導致落榜、考試失利，不構成退款、賠償之理由。

### 2.2 使用者內容上傳與著作權規範 (UGC & Copyright Policy)
*   **合法授權宣誓**：使用者上傳之任何文檔（PDF、影像）、影音連結（YouTube 網址），皆須自行保證擁有合法使用權利或已取得版權方授權，得用以作為個人學習之用途。
*   **安全港灣條款 (Safe Harbor / DMCA)**：平台做為網路服務提供者 (ISP)，不事先審核使用者上傳之檔案。若第三方版權方提出侵權申訴，平台有權（在不經通知使用者的情況下）徑行刪除或隱藏該爭議資源，且不承擔任何連帶賠償責任。
*   **禁止公開分享侵權內容**：即便系統未來支援筆記分享或題庫共享，使用者亦不得將包含未授權版權內容的測驗庫公開至社群，否則平台有權立刻停權。
*   **三振退場機制 (Three-Strike Policy)**：為加強平台自律，若使用者的公開分享庫遭版權方檢舉達三次（ Strikes ），系統將永久封禁該帳號，且不予退還任何已預繳之訂閱費用。

### 2.3 服務中斷與第三方服務依賴 (Service Interruption)
*   **不保證中斷**：本平台使用第三方 AI 模型服務與雲端基礎設施。如遇不可抗力（如上游模型 API 故障、海底電纜斷線、大型網路攻擊），導致功能（包含但不限於文件解析、AI 教練問答）暫時無法使用，平台將盡力修復，但不對暫時性服務中斷衍生的損失提供賠償。
*   **合規使用第三方模型**：使用者同意在上傳文件及發送對話時，相關資料將可能傳輸至 OpenAI / Anthropic / Google 以進行處理。

## 3. 隱私權政策 (Privacy Policy) 重點宣告

針對個資與隱私保護（特別對齊台灣個資法或 GDPR）：

1. **AI 模型訓練排除宣告**：
   *   必須清楚告知使用者：「**本平台承諾，使用者上傳之私人學習資料、文件與測驗記錄，不會被用來作為平台訓練自家 AI 模型的語料庫**。所有資料僅透過安全的 API 傳送給第三方 LLM（並要求第三方不作為訓練資料）進行您專屬的任務處理。」（這能大幅度降低企業/教育機構用戶的防備心）。
2. **個資保留與刪除權 (Right to be Forgotten)**：
   *   明確告知於發生退費、刪除帳號時，使用者有權要求清空所有的使用紀錄與個人資訊，系統將於指定天數內從資料庫中徹底銷毀（包含向量資料庫中的 Embedding 特徵）。
   *   **快取合規補充**：Redis 快取等效能加速工具中的關聯資料，必須在後端刪除邏輯中同步執行 `del` 清除指令。所有 Redis Key 應設定 **TTL（Time-to-Live）自動過期機制**，以確保暫存資料不會無限期留存，以此落實隱私權保護並避免法律爭議。

## 4. 系統主動式版權防禦機制 (Active Copyright Defense)

為了將侵權風險降至最低，除了文字聲明外，平台將實施以下「技術性防禦機制」：

1. **上傳前沿版權掃描 (Copyright Pre-Filter)**：
   * 在文件進入 LLM 解析前，系統會快速掃描 Metadata 與純文字內容。若密集偵測到 "Copyright", "All Rights Reserved", "版權所有翻印必究", "Do Not Distribute" 等強烈版權宣告字眼（且佔比超過安全閾值），系統將自動暫停解析並彈出警告，要求使用者再次確認擁有個人授權，或直接拒絕高風險文件。
2. **數位隱形浮水印 (Invisible Digital Watermarking)**：
   * 針對由系統產生的 PDF 考卷匯出檔、心智圖或可下載的靜態資源，系統將在底層（或以肉眼無法察覺的微小像素）嵌入該使用者的 **UID 與生成時間截記**。
   * 若未來網路上出現未經授權大規模流傳的 CertiMate 題庫，平台營運方可透過反解析浮水印，精準鎖定洩漏源頭並執行帳號封鎖，以達到絕佳的嚇阻作用。

## 5. UI 介面上的免責提示設計 (UX/UI Implementation)

法律條文往往很長，使用者大多不會仔細閱讀，因此建議在前端系統介面上加入以下「防預防禦性設計」：

1. **AI 標示與免責小字**：
   *   在 AI 教練聊天視窗的底部，固定顯示灰色小字：「💡 AI 生成內容僅供參考，請隨時自行查證重要資訊。」
2. **隱性同意與視覺弱化設計 (Implicit Consent & Visual Muting)**：
   *   為確保使用者沉浸在學習心流中不被打斷，**放棄造成摩擦的強制勾選框**。改為在上傳按鈕區、AI 教練聊天輸入框的極邊緣處（正下方或角落），使用對比度極低的無干擾設計（如淡灰色 `#9CA3AF`、字號 10px）顯示聲明。
   *   文案如：「*點擊上傳即視為您保證擁有此檔案的合法使用權，並同意不公開散佈。*」透過「執行動作即同意 (Clickwrap / Browsewrap)」的網路慣例取代打勾，完成法律免責。
3. **成績單下的提示**：
   *   在測驗結果單元下方加入：「本模擬考試結果僅反映當前熟悉度，並不保證實測通過率。」

## 6. B2B / 企業客戶的附加法律條約 （針對模組 10）
如果開放補習班、企業機構使用（B2B 機構管理後台）：
*   **Data Processing Agreement (DPA)**：機構做為「資料控制者(Data Controller)」，CertiMate 做為「資料處理者(Data Processor)」，需明定雙方權責。
*   **未成年學生條款**：若補習班匯入的學員包含未成年人（如高中職以下），需在合約內要求補習班「已依法取得法定代理人之同意」方能匯入個人識別資料（姓名、Email）。
