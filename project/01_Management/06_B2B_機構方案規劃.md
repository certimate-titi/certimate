## 一、B2B 產品定位

### 1.1 EduAssist 概述

EduAssist 是 TiTi 平台的 B2B 產品線，專為教師、補習班與學校設計的 AI 輔助出題與學習分析系統。

> 「AI 幫老師出草稿，老師決定最終版本。考完自動產出班級分析，精準找出哪些學生、哪些考點需要補救。」

### 1.2 與個人系統的定位差異

| 維度 | 個人證照學習（Personal Pro） | 老師輔助系統（EduAssist） |
|------|---------------------------|------------------------|
| 主要使用者 | 備考中的個人考生 | 國中小/高中老師 |
| 出題者 | AI 主導，考生被動作答 | 老師主導，AI 輔助草稿 |
| 素材來源 | 公共考古題 + 個人上傳 | 老師上傳課綱/講義/歷年自出題 |
| 追蹤維度 | 個人弱點 | 個人 + 班級 + 跨班比較 |
| 競爭對手 | 補教業題庫（公職王、志光） | 幾乎沒有（市場空白） |
| 付費模式 | 個人月費/年費 | 學校採購/班級授權 |
| 核心價值 | 最快通過考試 | 節省出題時間 + 精準補救教學 |

### 1.3 共用底層技術

EduAssist 與 Personal Pro 共享同一套核心基礎設施：

- **RAG 引擎**：考點驅動的混合召回機制
- **出題規劃層**：先定骨架再填題目的核心邏輯
- **批改引擎**：選擇題自動批改 + 考點對應標注
- **信度標示系統**：🟢🟡🔴 三層標示

## 二、目標市場分析

### 2.1 市場區隔與優先級

| 類別 | 市場概況 | 優先級 |
|------|---------|--------|
| 補習班 | 決策快、付費意願強，是最快驗證的切入口 | 🏆 A（早期） |
| 國中數學/自然 | 考點結構清晰，選擇題比例高，補救教學需求明確 | 🏆 A |
| 高中選修科目 | 108 課綱學習歷程需求強烈，老師備課壓力大 | 🥈 B |
| 國小各科 | 題型發散，AI 出題難度高，暫緩 | 🥉 C |

### 2.2 為什麼老師市場比學生市場更值得投入

**競爭者幾乎不存在**

台灣現有的老師出題工具停留在 Word 模板層級。Google 表單可收作答但無考點分析。均一教育服務學生不服務老師出題。這個市場幾乎是空白的。

**一個老師帶動數十個學生**

```
B2C 個人訂閱：1 個用戶 = 1 份收入
B2B 老師授權：1 位老師 × 30 學生 = 規模化效益
學校採購：1 所學校 × N 位老師 = 高客單價，高續約率
```

**108 課綱創造明確需求**

108 課綱要求學習歷程記錄，每位高中生都需要系統性整理自己的學習成果。老師需要工具協助追蹤並產生有依據的評量報告，這是過去沒有的剛性需求。

### 2.3 解決的核心痛點

老師每學期面對的問題：

- 出一份考試要 2-3 小時，AI 輔助後目標縮短至 30 分鐘
- 改完考卷只知道分數，不知道全班哪個概念沒學好
- 108 課綱要求學習歷程，但老師沒有工具自動產生結構化報告
- 補救教學沒有依據，靠老師主觀判斷

## 三、B2B 功能規劃

### 3.1 核心功能架構

```
素材層（老師上傳）
├── 課綱單元 / 講義 PDF
├── 歷年自出題庫
└── 參考教材

出題工作流
├── 老師設定：科目、單元、題型比例、難度分布
├── AI 生成題目草稿（RAG 從素材召回 + LLM 生成）
├── 老師審閱 / 修改 / 刪除
└── 定稿 → 產生試卷 PDF

作答收集層
├── 線上作答（學生端）
└── 紙本作答 → 老師手動輸入選擇題答案

分析層（最核心差異化）
├── 個人分析：每位學生各考點答對率趨勢
├── 班級分析：全班考點掌握度熱力圖
├── 跨班比較：A 班 vs B 班 同考點表現
└── 補救教學建議：自動標示需加強的考點與學生名單

學習歷程層（108 課綱）
├── 自動產生個人學習歷程報告
└── 匯出格式：PDF / Excel
```

### 3.2 班級考點分析報告（核心輸出）

這是市場上目前幾乎沒有的功能，也是老師最願意付費的地方：

```
📊 班級考點分析報告
─────────────────────────────────────
考試：110 班 第一次段考（國中數學）
作答人數：32 人 ／ 日期：2026-04-01

考點掌握度：
✅ 整數四則運算     平均答對率 89%   正常
✅ 分數計算         平均答對率 81%   正常
⚠️ 負數運算         平均答對率 61%   需關注
❌ 一元一次方程式   平均答對率 43%   建議複習

需個別輔導（答對率 < 50%）：
王小明 / 陳小華 / 林小美 ⋯ 共 5 人

建議行動：
→ 下週安排「一元一次方程式」補充練習
→ 以上 5 位學生優先安排課後輔導
─────────────────────────────────────
```

### 3.3 功能比較：個人系統 vs 老師系統

| 功能 | 個人系統 | 老師系統 |
|------|---------|---------|
| 出題決策者 | AI 主導 | 老師主導，AI 輔助草稿 |
| 批改責任 | 全自動 | 選擇題自動，非選老師手動 |
| 追蹤對象 | 自己 | 班上所有學生 |
| 報告對象 | 學生本人 | 老師（班級）+ 學生（個人）|
| 最重要的輸出 | 弱點練習題 | 班級分析報告 + 補救建議 |

### 3.4 各階段功能範圍

**Phase 2 MVP（補習班）**：
- 老師上傳教材 → AI 生成題目草稿 → 老師審閱定稿
- 線上派發給學生作答
- 基本班級答對率分析（考點層級）
- 匯出 PDF 試卷

**Phase 3 擴充（國中學校版）**：
- 跨班比較分析
- 學習歷程自動報告（對應 108 課綱需求）
- 非選擇題輔助批改（關鍵字評分 + 老師確認）

**Phase 4 深化（高中版）**：
- 高中版 + 108 課綱深度整合
- 跨系統聯動：補習班老師的學生可同步使用個人系統備考
- 老師題庫可授權給 Personal Pro 使用者作為練習素材

## 四、B2B 定價方案

| 方案 | 月價 | 內容 |
|------|------|------|
| **個人老師版（Teacher）** | $499/月 | 1 位老師，5 個班，無限出題 |
| **補習班版（Cram School）** | $1,999/月 | 最多 10 位老師，無限班級 |
| **學校授權（School）** | 客製報價 | 全校老師，含導入服務、教育訓練 |

### 4.1 早期策略

- 前 3 個月提供補習班老師**免費試用**，換取深度使用回饋與口碑
- 試用後付費轉換率目標：≥ 40%

### 4.2 轉換邏輯

選擇補習班而非公立學校作為首發市場的原因：
- **決策快**：老師個人決定使用，不需學校採購流程
- **付費意願強**：補習班有商業利益，工具節省時間直接轉化為收入
- **回饋即時**：補習班競爭激烈，老師對工具效果敏感

### 4.3 潛在跨系統加值

長期可考慮：老師在 EduAssist 建立的題庫，可以授權給 Personal Pro 使用者作為練習素材，形成內容生態閉環。

## 五、B2B 合規要點

### 5.1 學生資料隱私

- 符合個人資料保護法（個資法），學生資料不用於訓練模型
- 學校版需與校方簽訂資料處理契約
- 未成年學生資料需取得法定代理人同意

### 5.2 AI 生成內容責任

- AI 只提供題目草稿，老師擁有最終決定權與審閱責任
- 明確標示 AI 生成內容（信度分層標示）
- 老師定稿後即為老師之著作

### 5.3 學校採購合規

- 政府採購法相關規範（公立學校）
- 教育主管機關資安要求
- 資料在地化儲存需求

→ 詳見 05_法律合規與稅務.md Part 4（教育機構資料處理合規細則）

## 六、B2B 發展時程

對應主 Roadmap 四階段架構：

→ 詳見 01_策略計畫書.md 第五章 Roadmap

### 6.1 Phase 1（0-6 個月）：B2B 不啟動

此階段專注 B2C 個人系統 MVP，不投入 B2B 開發資源。

### 6.2 Phase 2（6-12 個月）：補習班 MVP

**目標**：在補習班老師族群驗證出題輔助流程，收集真實使用回饋。

| 月份 | 重點工作 |
|------|---------|
| M7-M8 | 補習班老師需求訪談、MVP 功能定義 |
| M9 | B2B 啟動開發：上傳教材 → AI 出題 → 審閱定稿 |
| M10-M11 | 線上派發作答 + 基本班級分析；招募 5-10 間補習班免費試用 |
| M12 | 收集回饋、優化流程；啟動付費轉換 |

**關鍵指標**：
- 試用後付費轉換率 ≥ 40%
- 老師出 20 題試卷平均時間 ≤ 30 分鐘

**暫不做**：學習歷程報告、跨班比較、108 課綱整合

### 6.3 Phase 3（12-15 個月）：國中學校版

**目標**：進入國中學校市場，需應對學校採購流程。

- 跨班比較分析
- 學習歷程自動報告（對應 108 課綱需求）
- 非選擇題輔助批改（關鍵字評分 + 老師確認）
- 與學校行政系統對接（導入服務 + 教育訓練）

**關鍵指標**：
- 班級分析報告老師滿意度 ≥ 4.2 / 5.0
- 學校採購後年續約率 ≥ 80%

### 6.4 Phase 4（15-18 個月）：高中 108 課綱版

- 高中版 + 108 課綱深度整合
- 學習歷程報告自動產生（符合 108 課綱格式）
- 跨系統聯動：補習班學生同步使用 Personal Pro 備考
- 內容生態閉環：老師題庫授權給個人系統

## 八、B2B 風險管理

| 風險項目 | 嚴重程度 | 因應策略 |
|---------|---------|---------|
| AI 生成題目品質不穩 | 高 | 老師審閱定稿，AI 只提供草稿，責任在老師 |
| 學校採購流程漫長 | 高 | 先從補習班切入，積累案例後再攻學校 |
| 老師使用習慣難改變 | 中 | 提供完整導入訓練，設計極低學習門檻 |
| 學生資料隱私 | 高 | 符合個資法，學生資料不用於訓練模型 |
| 108 課綱政策變動 | 低 | 功能設計保持彈性，不強綁課綱版本 |

## 九、B2B 競爭差異化

### 9.1 EduAssist 的護城河

**老師主導 + AI 加速**：AI 只提供草稿，老師擁有最終決定權，解決老師對 AI 品質疑慮的根本問題。

**班級考點分析**：從個人答對率到全班考點熱力圖，這是市場上幾乎不存在的功能，也是老師最難自行製作的東西。

**108 課綱原生設計**：學習歷程報告自動產生，解決老師與學生最具體的行政負擔。

### 9.2 雙系統協同效應

兩套系統面向不同市場，互不競爭，還能相互導流——個人備考的使用者可以成為老師系統的學生端，老師建立的題庫可以豐富個人系統的素材。
