# TiTi 定價與財務分析

本文件整合 TiTi 平台的定價策略、營運成本、退費機制與品牌資產投資，作為財務決策的統一參考依據。

## 第一章：單位經濟與邊際分析

### 1.1 各階層方案成本基準線與功能分拆

為有效精算毛利，以單一「極端用好用滿的重度用戶」作為壓力測試基準。

#### FREE 方案 (0 TWD / 月) - 免費體驗

- **核心定位**：低門檻體驗，每月 3 份文件額度，受限的解析與出題次數。
- **重度用戶滿載變動成本估算**：
  - 用滿每月 3 份文件額度並生成 9 回考卷，純 API 總成本約 **$0.09 USD (不到 3 TWD)**
  - 含錯題解析，每位活躍免費用戶每月 API 成本約 **$0.1 ~ $0.5 USD (約 3 ~ 15 TWD)**
  - 動態演算法 (DB IOPS/Egress) 攤提：極端情境下單人約 **$1.0 ~ $2.0 USD (約 30 ~ 64 TWD)**
  - **極端單人最高佔用**：約 **$1.34 USD**

#### PRO_199 方案 (199 TWD / 月) - 衝量型護城河

- **核心定位**：極致便宜的「影片與講義秒轉考卷」工具。
- **功能權限**：無限量使用高速平價模型 (Gemini 1.5 Flash / Llama 3) 進行解析與出題。**禁用**高階 AI 教練 (Claude 3.5) 與手寫圖片 OCR。
- **重度用戶滿載變動成本估算**：
  - PDF/YT 解析生成 (30 卷 + 15 影片)：約 **4.0 USD**
  - 動態演算法運算 (DB/Egress)：約 **2.0 USD**
  - **最大極限成本**：**$6.0 USD (約 192 TWD)**
- **一般正常用戶變動成本**：約 **$2.0 USD (約 64 TWD)**

#### PRO_PLUS_399 方案 (399 TWD / 月) - 高利潤核心引擎

- **核心定位**：帶有「大會考級深度教練」的全功能學霸輔助工具。
- **功能權限**：包含 PRO_199 所有功能，再追加「每月 200 次高階 AI 教練 (Claude 3.5) 深度錯題解析」與「手寫數學/圖片等多模態 OCR」。
- **重度用戶滿載變動成本估算**：
  - 基礎 PRO_199 開銷 (解析生成與資料庫)：**6.0 USD**
  - 高階 AI 教練深度對話 (額度全滿)：**3.0 USD**
  - 手寫/圖片 Vision OCR：**0.5 USD**
  - **最大極限成本**：**$9.5 USD (約 304 TWD)**
- **一般正常用戶變動成本**：約 **$3.5 USD (約 112 TWD)**

#### ULTRA_1599 方案 (1,599 TWD / 月) - 無限火力/小班教學

- **核心定位**：為國考狂熱者、家教老師、或重度研究員準備的無限制專屬火力。
- **功能權限**：無限高階 AI 教練調用次數、超大容量專屬向量庫、支援家教自定義 Prompt 分發給學生。
- **重度用戶滿載變動成本估算**：
  - 無限制頂級模型對話：約 **15.0 USD**
  - 鉅量 DB 資料庫查表與 Egress：**5.0 USD**
  - **最大極限成本**：**$20.0 USD (約 640 TWD)**

### 1.3 戰略解析

1. **利用 PRO_199 血洗市場並建立護城河**：將最貴的 Claude 3.5 對話與 OCR 成本抽離後，199 方案的極端成本死死卡在 192 TWD（驚險轉正）。可放心推廣 199 方案（主打 YouTube 轉考題無限量），不用擔心被羊毛黨刷到破產。
2. **真正的獲利引擎：PRO_PLUS_399**：透過 PRO_199 的破盤價吸引海量用戶上傳知識庫。當用戶解題遇到困難、發現廉價模型講不清楚時，中央面板的「毛玻璃遮擋」高質感地提示升級。只要升級到 399 元，即便最重度使用者，系統也擁有近 100 元的絕對淨底線盈餘。
3. **ULTRA_1599 的視覺定錨效應 (Price Anchoring)**：除承接極少數有「代客生題」剛需的家教外，1,599 方案的存在主要是為了心理學上的「定錨效應」。當學生看到 1,599 的頂規天價時，原本猶豫的 399 元方案瞬間顯得「便宜到流淚」，大幅推升主力的升級轉換率與 ARPU。

相較於 199 TWD 的月費，這筆支出僅佔 **1%**，但能顯著提升留存率與升級意願。

### 2.4 動態演算法的資料庫與數據流攤提成本

為實現「精力調度」與「防遺忘排程」，系統底層具備三大消耗特徵：

1. **超高頻率讀寫 (High IOPS)**：每一次作答皆觸發 `update_stats` 寫入，短期衝刺模式下單日單人可達上百次
2. **高算力複雜檢索 (Complex Queries)**：「關聯性檢索」需大量 PostgreSQL CPU 進行跨標籤全文配對
3. **龐大 JSON 數據流 (Network Egress)**：心智圖全域節點結構推播，頻繁互動下產生大量出站流量

針對「超級活躍付費用戶」，其資料庫運算力與出網流量攤提，預估每月 **$1.0 ~ $2.0 USD (約 30 ~ 64 TWD)**。此成本甚至超越 Gemini Flash API 費用，是維運中最易被忽略的盲點。

### 2.5 平台整體營運成本佔比情境

假設平台共有 **100 位極端 FREE** + **20 位 PRO_199** + **10 位 PRO_PLUS_399**，平台每月支出約 $380 USD (約 12,000 TWD)：

| 成本類別 | 預估總額 (USD) | 佔總費用比例 (%) | 核心組成 |
| :--- | :--- | :--- | :--- |
| 平價模型 API (Gemini/Embedding) | $144 | **37.9%** | 各階層影音/文本出題與解析總和 |
| 資料庫運算與流量 (DB & Egress) | $145 | **38.1%** | 全平台會員的動態記憶演算法攤提 |
| 高階模型 API (Claude 3.5) | $30 | **7.9%** | 僅限 PRO_PLUS_399 獨享的頂級開銷 |
| 固定基礎設施 (Fixed Infra.) | $61 | **16.1%** | Cloud SQL 底層基數與 GCS 儲存 |

> **洞察**：「龐大運算與網路流量成本 (38.1%)」已與「平價 AI 出題 (37.9%)」平起平坐，證明 TiTi 不僅是一個 AI 生成器，更是一個依靠精密實時資料吞吐建立壁壘的工程級教育 SaaS。

### 2.6 損益兩平點與獲利推估

- **損益兩平點 (Breakeven Point)**：
  - 每月固定基礎開銷 (約 1,500 TWD) 僅需 **4 個 PRO_PLUS_399 用戶**或 **8 個 PRO_199 用戶**即可完全打平
- **極端免費用戶壓力測試**：
  - 100 位免費用戶每日上線狂洗題庫，單人最高佔用約 $1.34 USD，總極限虧損約 4,300 TWD
  - 加上固定伺服器成本，平台極致承壓支出為 **5,800 TWD**
  - 只需 **20 名 PRO_199 + 5 名 PRO_PLUS_399** 訂閱即可越過盈虧平衡點
  - 教育 SaaS 免費轉付費只要達到 3%~5% 即算成功指標

## 第三章：計費週期、退費政策與防濫用機制

### 3.1 訂閱收費原則

- **週期性扣款 (Auto-Renewal)**：所有付費方案採「月費制」，使用者綁定信用卡或第三方支付 (如 Stripe, Line Pay, Apple Pay) 後，系統於每個計費週期 (滿 30 天) 的同一日自動扣款。
- **隨買隨用 (Immediate Access)**：付款成功當下，帳號立即升級至對應方案權限。
- **發票開立**：依營運所在地法規，於扣款成功後開立電子發票發送至註冊信箱。

| 方案 | 月費 (TWD) | 解鎖功能概述 |
| :--- | :---: | :--- |
| PRO_199 | 199 | 無廣告、無限上傳、YouTube 解析、平價模型出題 |
| PRO_PLUS_399 | 399 | 含 PRO_199 全部 + 高階 AI 教練 (200 次/月) + 手寫 OCR |
| ULTRA_1599 | 1,599 | 含 PRO_PLUS_399 全部 + 無限高階 AI 教練 + 專屬向量庫 + 家教 Prompt 分發 |

### 3.2 訂閱取消機制

- **隨時可取消 (Cancel Anytime)**：使用者可隨時在「帳戶設定/訂閱管理」頁面點擊「取消訂閱」，過程不得設立人為障礙。
- **權益保留至期末 (Prorated Access)**：取消後停止次月自動扣款，已支付的當期權限**保留至計費週期結束**。週期結束後自動降級為 FREE。
- **歷史資料保留**：降級為 FREE 後，付費期間生成的題庫、心智圖與錯題記錄**不會被刪除**，但可能受免費帳號的每日存取/解析次數限制。

### 3.3 退費政策 (各方案適用)

考量 TiTi 的核心價值在於「消耗高昂的 AI API 算力運算」，必須設立嚴格但合理的退費門檻，防止「惡意白嫖算力」的行為。

#### A. 絕對不退費情境 (No Refund Allowed)

符合以下任一條件，代表實質系統算力已被消耗，**原則上不予退費**：

1. **已使用核心算力**：在當期計費週期內，使用者有「成功上傳並向量化 (Embedding)」任何一份講義，或「成功解析 YouTube 影片」並產出模擬考卷。
2. **已調用高階 AI 教練** (PRO_PLUS_399 / ULTRA_1599)：進行過任何一次高階深度錯題解析對話。
3. **已啟動情感化互動/週報**：已接收 AI 教練生成的「個人化考前打氣」、「學習週報」或與 AI 教練進行過**累計 10 次以上**的鼓勵對話。
4. **帳號已達成成就徽章**：在訂閱期間已觸發並獲得至少一個成就徽章。
5. **週期過半**：距離扣款日已超過 7 天的法定猶豫期或該計費週期已過半。

#### B. 特例全額退費 (Full Refund Exceptions)

符合以下狀況可透過客服信箱申請全額退費（適用所有方案）：

1. **誤觸扣款 (Accidental Renewal)**：在自動續訂扣款發生後的 **48 小時內**提出申請，且紀錄顯示在該續訂週期內**完全沒有使用任何生成/解析 API** (用量紀錄為 0)。
2. **重大系統故障 (Service Outage)**：因 TiTi 系統或底層 API 供應商 (如 GCP, OpenRouter) 發生無預警連續當機超過 24 小時，導致使用者在考前黃金期無法使用付費功能。
3. **重複扣款 (Duplicate Billing)**：因系統金流 Bug 導致同一帳號在同一週期被扣款兩次以上。

#### C. 各方案退費上限與門檻差異

由於不同方案的單期算力消耗規模差異極大，退費門檻需相應調整：

| 項目 | PRO_199 | PRO_PLUS_399 | ULTRA_1599 |
| :--- | :--- | :--- | :--- |
| **月費** | 199 TWD | 399 TWD | 1,599 TWD |
| **誤觸退費時限** | 扣款後 48 小時內 | 扣款後 48 小時內 | 扣款後 72 小時內 |
| **零用量退費** | 全額退還 199 TWD | 全額退還 399 TWD | 全額退還 1,599 TWD |
| **按比例退費** | 不適用 | 不適用 | **僅限首次訂閱 7 天內**，若高階 AI 教練調用次數 < 10 次且無家教 Prompt 使用紀錄，可退還 **75% (約 1,199 TWD)**；超過 7 天不退 |
| **系統故障補償** | 全額退款或補償延長 1 週期 | 全額退款或補償延長 1 週期 | 全額退款或補償延長 1 週期 |
| **重複扣款** | 退還多扣金額 | 退還多扣金額 | 退還多扣金額 |

> **設計邏輯**：PRO_199 與 PRO_PLUS_399 因客單價相對低，採一致的「無按比例退費」策略以降低客服與金流手續費成本。ULTRA_1599 因客單價高達 1,599 TWD，若完全不提供退費選項，易引發高額信用卡爭議款 (Chargeback)，因此於首次訂閱的 7 天冷靜期內提供有條件的 75% 退款，兼顧消費者信心與算力成本回收。

### 3.4 防濫用阻斷機制 (Anti-Abuse System)

#### 1. 共享帳號偵測 (Account Sharing)

- **情境**：同一帳號在極短時間內 (10 分鐘內) 出現於多個地理位置差異巨大的 IP 登入，或同時有 3 個以上 Session 同時觸發耗時的文件解析或 YouTube 轉換。
- **處置**：系統強制登出所有 Session，並發送警告信。單月觸發達 3 次，立刻凍結帳號，當月不予退費。

#### 2. 極端高頻匯出 (Hit-and-Run Exporting)

- **情境**：帳號剛升級的前 48 小時內，瘋狂上傳超過 30 份巨量講義或數十部超長 YouTube，完全沒有進行線上測驗與錯題檢討，而是直接將生成的數百題模擬考卷與 Anki 閃卡全部匯出。
- **處置**：觸發 Rate Limit 閘道，暫停該帳號的文件解析權限 24 小時。

#### 3. API 腳本惡意爬蟲 (Scripted Scraping)

- **情境**：上傳與答題行為呈現高度規律性 (如每 2.5 秒精準觸發一次 API)，缺乏人類操作的隨機滑鼠軌跡或停留時間，疑似使用腳本將 TiTi 當作廉價 LLM API 轉接頭。
- **處置**：觸發 Cloudflare 或 API Gateway 的 WAF 阻擋，要求強制 reCAPTCHA 驗證，未通過即鎖卡。

#### 4. 巨型垃圾檔案攻擊 (DoS via Garbage PDF)

- **情境**：上傳蓄意構造的「文字炸彈」PDF、無意義亂碼檔案、或刻意將純白圖片打包的檔案，意圖耗損 Vision OCR 與 Embedding 算力。
- **處置**：在文字預處理階段偵測到重複率過高或無法辨識的亂碼比例過高，直接終止工作管線，跳出錯誤提示。該次解析**不計入使用額度**，但也阻斷後續向 API 發送的成本。

### 3.5 結帳頁面法律標示

必須在結帳頁面 (Checkout Page) 最顯眼處標明：

> 「本服務包含即時巨量 AI 運算，一旦產生首份專屬考卷即代表履約完畢，除系統重大故障外恕不接受退費。」
