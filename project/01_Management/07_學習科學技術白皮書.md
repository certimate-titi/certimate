## 一、核心記憶引擎

### 1. 艾賓浩斯間隔複習 (Ebbinghaus Spaced Repetition)

> **學術依據**：Hermann Ebbinghaus (1885) 發現人類記憶遵循可預測的遺忘曲線——新學習的內容在 24 小時內遺忘 70%，但在關鍵時間點複習可將記憶留存率提升至 90% 以上。

**TiTi 實現**：
- **五階段智慧排程**：24 小時 → 3 天 → 7 天 → 14 天 → 30 天，每個考點自動計算最佳複習時機
- **Google Calendar 整合**：系統直接寫入使用者日曆，推送「今日特訓」事件，一鍵進入複習
- **動態重置**：任一階段答錯即重置遺忘權重，確保真正掌握而非表面通過

**對投資人的意義**：這是留存率的基石。每日日曆推送 = 每日主動觸及用戶，形成習慣迴路。

---

### 2. SuperMemo-2 自適應演算法 (SM-2 Adaptive Algorithm)

> **學術依據**：Piotr Wozniak (1987) 開發的 SM-2 演算法是全球間隔複習軟體的基礎，透過 ease factor（簡易度因子）動態調整每張卡片的複習間隔。

**TiTi 實現**：
- 每道題目追蹤 `ease_factor`（預設 2.5），根據作答正確率動態調整
- 連續答對的題目間隔自動拉長；答錯的題目間隔自動縮短
- 與信心度校準（見第 7 項）整合，實現更精準的記憶預測

**對投資人的意義**：這是個人化的數學基礎——每位用戶看到的複習內容都不同，且會隨時間自動優化。

## 二、智慧出題引擎

### 3. Bloom 認知層次分類 (Bloom's Taxonomy)

> **學術依據**：Benjamin Bloom (1956) 將認知能力分為六個遞進層次——記憶、理解、應用、分析、評估、創造。研究顯示，考試中各層次的分佈直接影響鑑別度。

**TiTi 實現**：
- AI 出題引擎為每道題目自動標記 Bloom 認知層次
- **考古題驅動配比**：自動分析歷年考古題的 Bloom 分佈，AI 出題時自動套用相同比例，確保模擬考與真實考試的認知結構一致
- 測驗結果頁提供各 Bloom 層次的得分率雷達圖，精準定位認知盲區

**對投資人的意義**：這是 AI 出題品質的學術保障——不是隨機出題，而是有結構的認知測試，也是 B2B 對教育機構的核心賣點。

---

### 4. 交錯練習 (Interleaving Practice) 🆕

> **學術依據**：Rohrer & Taylor (2007) 實驗證明，交錯練習（混合不同主題的題目）比集中練習（同主題連續刷題）的**長期記憶效果提升 43%**。雖然學習者主觀感覺交錯練習「更難」，但客觀測試成績顯著更好。

**TiTi 實現**：
- 選擇多個知識節點出題時，預設以交錯方式排列（A → B → C → A → B → C），而非集中排列（AAA → BBB → CCC）
- 同時考慮難度分散，避免連續高難度題打擊信心
- 前 3 題保證至少 1 題簡單題，建立正向開局
- Sprint 模式下，錯題節點的題目優先穿插，均勻分散於整份考卷

**對投資人的意義**：極低成本的高效學習策略——僅改變出題排序邏輯，即可顯著提升學習成效，且競品普遍未實作。

## 三、自適應學習系統

### 5. 三模式動態任務分配 (Adaptive Learning Modes)

> **學術依據**：結合 Bjork (1994) 的「可期望困難 (Desirable Difficulties)」理論與認知負荷理論 (Sweller, 1988)——不同學習階段需要不同的練習策略。

**TiTi 實現**：

| 模式 | 觸發條件 | 核心策略 | 出題配比 |
|------|----------|---------|---------|
| 🔥 **衝刺模式** | 距考 < 14 天 | 高頻錯題 + 快速覆蓋 | 錯題 50% / 新題 40% / 關鍵字 10% |
| 📚 **標準模式** | 距考 1-3 月 | 動態位移，隨時間自動調整 | 前期新題 60% → 後期複習 40% |
| 🧠 **精熟模式** | 距考 > 6 月 | 抗遺忘 + 跨域連結 | 遺忘邊緣 70% / 跨章節 20% / 新題 10% |

系統根據使用者設定的「預計考試日期」自動切換模式，無需手動操作。多科目同時備考時，各科目獨立運行各自的模式。

**對投資人的意義**：這是產品差異化的核心——真正的「個人化」不只是推薦算法，而是根據你的考試日程自動調整整套學習策略。

### 6. 後設認知與能力雷達 (Metacognition & Skill Profiling)

> **學術依據**：Flavell (1979) 的後設認知理論指出，學習者對自身能力的準確評估是有效學習的前提。Dunning-Kruger 效應則顯示，能力不足者往往高估自己。

**TiTi 實現**：
- 能力分佈雷達圖：每次測驗後即時更新各知識領域的掌握度
- 知識節點以三色標示掌握程度（🟢 綠色 ≥ 80% / 🟡 黃色 / 🔴 紅色 < 60%）
- 出題引擎的「雙漏斗篩選」：大方向依循時間軸模式，小細節瞄準雷達圖最弱區域

**對投資人的意義**：視覺化的「能力儀表板」是用戶願意長期使用的關鍵——看到自己紅色區域變綠色的過程極具成就感，直接驅動續訂率。

---

### 6b. 全維度知識節點掌握度評估 (Multi-Dimensional Mastery Assessment) 🆕

> **學術依據**：單一指標（如答對率）無法可靠反映真實掌握程度——Anderson & Krathwohl (2001) 修訂版 Bloom 分類學指出，掌握一個知識點需要在多個認知層次上展現能力；Koriat (2007) 的後設認知研究證實，學習者的自信心與實際表現之間的落差（calibration gap）是預測考試失敗的最強指標。

**問題**：傳統備考平台的弱點分析只看「本次考試答對幾題」。一個知識節點如果只分到 1 題，答對就 100%、答錯就 0%——完全不具統計意義，更無法反映長期掌握。

**TiTi 實現 — 四維度加權評估模型**：

每個知識節點的掌握度由四個正交維度加權計算，而非單一答對率：

```
掌握分數 = SM-2 累計掌握度 × 40%     ← 長期記憶深度
         + Bloom 認知覆蓋度 × 20%     ← 認知廣度
         + 信心度校準分數   × 25%     ← 後設認知準確度
         + 本次考試答對率   × 15%     ← 即時表現（降權）
```

| 維度 | 資料來源 | 計算方式 | 意義 |
|------|---------|---------|------|
| **SM-2 累計掌握度** | `node_mastery.base_mastery × retention` | 跨多次考試的指數加權平均 + 記憶衰退曲線 | 你真的學會了嗎？還是三個月前學的已經忘了？ |
| **Bloom 認知覆蓋度** | `question.bloom_category` | 已答對的 Bloom 層次數 ÷ 6 | 你只會「記憶」型題目，還是能「分析」和「評估」？ |
| **信心度校準分數** | `answer.confidence` + `answer.is_correct` | 高信心答對 ÷ (高信心答對 + 高信心答錯) | 你知道自己知道什麼嗎？「很確定但答錯」= 危險盲點 |
| **本次答對率** | 本次考試 correct/total | 簡單比率（權重僅 15%） | 即時參考，但不作為主要判斷依據 |

**實際效果對比**：

```
情境：某考生在「專案規劃基礎」節點只做了 1 題且答對

傳統系統：100% ✅ 已掌握 ← 完全誤導
TiTi 四維度：55%（SM-2 累計 30% + Bloom 只覆蓋記憶層 17% + 本次 100%）
             ← 真實反映：答對 1 題不代表掌握，認知深度不足
```

**API 回傳結構**（每個知識節點）：

```json
{
  "domain": "專案規劃基礎",
  "percentage": 55,
  "exam_accuracy": 100,
  "mastery": 30,
  "bloom_coverage": 17,
  "confidence_calibration": 100,
  "decay_status": "fresh",
  "dimensions": {
    "sm2": { "base_mastery": 0.3, "retention": 1.0, "effective": 0.3 },
    "bloom": { "covered": ["remember"], "total": 6 },
    "confidence": { "calibration_rate": 1.0, "blind_spots": 0 }
  }
}
```

**四維度如何驅動個人化學習建議**：

| 診斷結果 | AI 教練建議 |
|---------|-----------|
| SM-2 高但 Bloom 低 | 「你記得夠牢，但需要練習更高層次的題目（應用、分析）」 |
| Bloom 高但 SM-2 低 | 「你能力到位但記憶衰退中，安排間隔複習」 |
| 信心校準低（盲點多） | 「你有 {N} 個危險盲點，這些是最優先要釐清的觀念」 |
| 衰退狀態 critical | 「這個知識點已超過複習期限，建議立即做記憶喚醒測驗」 |

**對投資人的意義**：這是 TiTi 與所有競品的根本差異——市場上沒有任何備考平台做到四維度掌握度評估。它不只是「答對幾題」的統計，而是從長期記憶深度、認知廣度、自我認知準確度、記憶新鮮度四個維度全面診斷學習狀態。這產出的學習數據質量遠超競品，也是 B2B 教育機構最看重的分析維度。

## 四、深度學習強化

### 7. 信心度校準 (Confidence-Based Learning) 🆕

> **學術依據**：Hunt (2003) 的信心度學習研究發現，讓學生同時標記「答案信心度」可顯著提升後設認知能力。關鍵發現：**「非常確定但答錯」的題目是最危險的認知盲點**，比「猜對」更需要優先處理。

**TiTi 實現**：
- 作答時一鍵標記信心度：😰 完全猜測 → 😐 有點把握 → 😎 非常確定
- 測驗結果產出「四象限分析」：

```
              答對           答錯
確定  │ ✅ 真正掌握     │ 🔴 危險盲點    │ ← 最高複習優先
猜測  │ 🟡 幸運猜對     │ ⚪ 預期中弱點   │
```

- **危險盲點**（confident + 答錯）：複習間隔縮短至 12 小時，ease_factor 額外降低
- **幸運猜對**（guessing + 答對）：仍排入複習排程，不因答對而跳過
- 儀表板追蹤「信心校準率」趨勢，校準率 > 80% 代表考生真正了解自己的能力

**對投資人的意義**：這是市場上獨一無二的功能——沒有任何主流備考平台做信心度校準。它解決了「假性掌握」的致命問題，也產出極有價值的學習數據。

---

### 8. 蘇格拉底式 AI 教練 (Socratic AI Coaching)

> **學術依據**：蘇格拉底式教學法 (Socratic Method) 透過提問而非直接告知答案，引導學生自行發現知識。研究顯示此方法的知識保留率是傳統講授的 2-3 倍。

**TiTi 實現**：
- AI 教練角色「Certi」，具備個性化的對話風格
- 根據使用者學歷與職業自動調整語言深度（高中生用白話文，工程師用專業術語）
- 錯題複習時不直接給答案，而是引導使用者思考「為什麼不是 C 而是 B」
- 記憶使用者歷史錯誤模式，在後續對話中引用

**對投資人的意義**：AI 教練是付費轉換的核心驅動力——FREE 用戶無 AI 教練，PRO 用戶有完整的個人化指導。

## 五、行為設計與習慣養成

### 9. 遊戲化與情感設計 (Gamification & Emotional Design)

> **學術依據**：Deci & Ryan (1985) 的自我決定理論指出，內在動機由三要素驅動：自主性、能力感、歸屬感。遊戲化機制在正確設計下可顯著提升學習投入度。

**TiTi 實現**：
- **9 項成就徽章**：播種者、堅持不懈（7 天連續）、弱點克星、登頂者（100 場考試）、滿分時刻等
- **連續學習天數**：類 Duolingo 火焰機制 + 每週凍結保護
- **每日微任務**（1-3 個）：quiz / explore / review，完成獲得 XP
- **情感化回饋**：成績進步 → 撒花動畫；退步 → AI 陪伴安撫（絕不使用負面詞彙）
- **低谷偵測**：3 天未登入、連續退步、反覆重做同一章節 → 主動推送關懷訊息
- **核心原則**：「和昨天的自己比，而非和別人比」——無排行榜，無競爭機制

**對投資人的意義**：遊戲化直接影響日活 (DAU) 和 7 日留存率。連續天數機制在 Duolingo 驗證了每增加 1 天連續使用，月留存率提升 2-3%。

### 10. 番茄鐘學習節奏 (Pomodoro Technique) 🆕

> **學術依據**：Francesco Cirillo 的番茄工作法搭配 Desktime 的生產力研究顯示，25 分鐘專注 + 5 分鐘休息的節奏能維持最佳注意力。對長時間備考（90 分鐘模擬考）尤其關鍵。

**TiTi 實現**：
- 可選功能，啟用後在學習頁面角落顯示低調的番茄計時器
- 🍅 25 分鐘專注 → 🌿 5 分鐘休息 → 每 4 個番茄鐘後 ☕ 15 分鐘長休息
- **建議性質**：休息提醒不強制中斷，使用者可選擇繼續作答
- 休息時推送進度摘要：「剛才 25 分鐘答對 8/10 題 🎉」
- 儀表板追蹤每日/每週番茄鐘數，以 🍅 圖示視覺化
- 累計 50 個番茄鐘解鎖「番茄達人」成就

**對投資人的意義**：低成本的 UX 功能，但顯著提升「每次學習時長」——每個番茄鐘 = 25 分鐘的深度使用時間，直接提升平台的 time-on-site 指標。

六、動態知識管理架構 (Dynamic Knowledge Management) 🆕
傳統備考系統最大的致命傷，在於隨著作答量增加，錯題本會變成一個「塞滿雜物的資料堆填區」，導致認知超載（Cognitive Overload）。TiTi 透過以下機制，將扁平的紀錄轉化為結構化的個人專屬知識網。

11. 狀態機自動分箱與雙向連結 (State Machine & Bi-directional Linking)
學術依據：建構主義心理學 (Constructivism) 強調，學習是將新資訊與舊有知識網絡建立連結的過程。同時，Miller (1956) 的資訊處理理論指出，透過「意元集組 (Chunking)」將資訊分類，能大幅降低工作記憶的負擔。

TiTi 實現：

錯題生命週期狀態機：考題不再只有「對/錯」，底層自動賦予生命週期，前端自動分箱：

🔥 頑固盲點區：歷史錯誤 > 2 次且最近一次答錯（需優先介入）

⚠️ 粗心滑鐵盧區：曾經連續答對，近期卻意外答錯（觀念混淆）

⏳ 待鞏固區：補考剛答對，排入間隔複習等待驗證

✅ 永久掌握區：連續 3 次答對，自動封存降低視覺干擾

知識節點雙向連結：這也是目前最先進的筆記管理哲學。在 TiTi 中，每一道題目都不是孤島，而是帶有雙向錨點。學生在看錯題時，點擊標籤即可「反向跳轉」回降維生成的 Markdown 講義原文；在閱讀講義時，也能一鍵拉出所有關聯此段落的歷史錯題。

對投資人的意義：這是建立極高轉換成本（Switching Cost）的關鍵。當使用者在 TiTi 內建立起盤根錯節的知識網與雙向連結後，他們將無法輕易遷移到其他扁平化的刷題競品。

12. 認知演進軌跡與場景化視圖 (Trajectory & Smart Views)
學術依據：Bandura 的自我效能理論 (Self-Efficacy) 證明，看見自己克服困難的具體軌跡，能產生最強大的內在學習動力。而情境學習理論 (Situated Learning) 則強調知識提取應配合當下情境。

TiTi 實現：

單一概念的演進軌跡：遇到反覆出錯的題目時，系統提供「歷程展開」。學生能看見自己第一週選 A（觀念不熟）、第二週選 C（被誘答騙）、第三週選正確答案 B 的思考演化過程，將挫折感轉化為破關成就感。

Smart Views 過濾器：將龐大知識庫動態適應學習場景：

🎒 通勤模式：只顯示「L1 記憶型」+「⏳ 待鞏固區」的短題目。

🚀 考前衝刺：只顯示「高權重考點」+「🔥 頑固盲點區」。

🧘 考前定心：只顯示「✅ 永久掌握區」，快速刷題建立上場自信。

對投資人的意義：解決長週期備考（3-6 個月）最容易發生的「中後期疲勞流失」。透過場景化視圖，將沈重的知識庫化整為零，確保用戶在任何零碎時間都能無痛開啟 APP 學習。

## 七、資源解析與個人題庫（EPIC-035） 🆕

傳統備考平台對「使用者自備資源」的處理僅止於切片檢索；TiTi 則透過統一 LLM 解析流程，從單一資源衍生出結構化知識、個人題庫、學習鷹架三種產物，並透過隔離機制避免汙染既有的掌握度模型。

### 13. 盲推論作答與反錨定機制 (Blind Inference & Anti-Anchoring)

> **學術依據**：Tversky & Kahneman (1974) 的錨定效應 (Anchoring Bias) 指出，人類在判斷時會不自覺受到先前看到的數值或答案影響；Bjork (1994) 的「渴望困難 (Desirable Difficulty)」理論則主張，學習者必須自行提取答案，才能建立長期記憶。若 AI 事先顯示推論答案，使用者會直接「認可 AI 判斷」，喪失主動思考。

**問題**：使用者上傳的教材（講義、考古題）常常正解缺漏，AI 可以推論但無法 100% 保證正確。若把 AI 推論的答案直接顯示，會形成兩個災難：
1. **錨定效應**：使用者看了 AI 答案就不再獨立思考，答對率虛高但理解度低
2. **錯誤定型**：若 AI 推論錯誤，使用者更難發現，並內化為錯誤知識

**TiTi 實現 — needs_answer 題目的盲推論流程**：

```
AI 解析資源 → 偵測題目缺正解 → 標記 answer_source = "ai_inferred"
                                            │
                                            ▼
使用者在練習模式看到該題 → 先作答（看不到 AI 推論）
                                            │
                                            ▼
提交答案後才揭示：「你選 B，AI 推論為 C，confidence=0.72，請自行判斷」
                                            │
                                            ▼
使用者可標記「我的答案正確」→ 題目轉為 user_verified
                  或「接受 AI 判斷」→ 題目轉為 ai_inferred_accepted
```

**關鍵設計**：
- `confidence` 欄位透明呈現 AI 自評把握度（0-1），不隱藏不確定性
- 使用者保有最終裁定權，AI 僅提供參考
- 所有 `ai_inferred` 題目預設 `never_for_scoring=True`，避免推論錯誤汙染掌握度

**對投資人的意義**：這是 AI 備考平台最容易踩的陷阱——大多數競品直接信任 LLM 產出，造成長期錯誤累積。TiTi 透過盲推論流程把 AI 定位為「提示者」而非「權威」，既保留自備教材的便利性，又確保學習品質不被汙染。

---

### 14. 個人題庫隔離（never_for_scoring） (Personal Bank Isolation)

> **學術依據**：心理計量學 (Psychometrics) 的測量效度要求，只有經過品質驗證的題項才能納入能力估計；Messick (1995) 的建構效度理論警告，將未經驗證的題目混入評量會產生系統性偏誤，使能力分數失真。

**問題**：使用者自行上傳的資源衍生題（needs_answer / 難度未知 / 自編題）若直接參與節點掌握度計算，會造成兩種汙染：
1. **系統性高估**：使用者可能無意中偏好出簡單題，答對率虛高
2. **統計汙染**：樣本數不足、品質未驗證的題目混入，破壞 SM-2 與四維度掌握度的可靠性

**TiTi 實現 — 雙層隔離**：

| 層級 | 機制 | 效果 |
|------|------|------|
| 資料層 | `Question.never_for_scoring` 布林欄位 + `owner_user_id` 私有化 | 個人題庫僅該使用者可見，不進入共用題池 |
| 計算層 | 練習 API 提交作答時，若 `never_for_scoring=True` 則跳過 `node_mastery` 更新、跳過 `propagation`、`progress` 回傳 null | 作答有回饋（正確/錯誤）但不影響官方掌握度 |

**API 行為對比**：

```jsonc
// 一般題目（平台驗證過的考古題/AI 生成題）
POST /api/v1/practice/submit
→ { "is_correct": true, "progress": { "mastery": 0.75, "propagation": [...] } }

// 個人題庫題目（never_for_scoring=true）
POST /api/v1/practice/submit
→ { "is_correct": true, "progress": null }  // 隔離：不更新掌握度
```

**使用者能做什麼？**
- ✅ 用個人題庫做練習、追蹤答對率、產生錯題紀錄
- ✅ 透過「驗證」流程將確認品質的題目提升為共用題池
- ❌ 不能用個人題庫刷高掌握度分數、不能影響 B2B 機構的學員評估

**對投資人的意義**：這是 B2B 簽約的核心護城河——教育機構最怕「學生自己上傳簡單題刷分」汙染數據。TiTi 的雙層隔離機制讓機構端的學習分析保持純淨，同時不妨礙學生自由探索。競品要麼全開（汙染）、要麼全禁（缺乏自主性），TiTi 在「自主探索」與「數據純淨」之間找到精準平衡。

### 15. 學習鷹架 Layer A（Scaffolds） (Learning Scaffolds)

> **學術依據**：Vygotsky 最近發展區 (Zone of Proximal Development, ZPD) 主張，學習者在適度引導下能達到超越獨立能力的表現；Wood, Bruner & Ross (1976) 正式提出「鷹架 (Scaffolding)」概念；Chi, Bassok, Lewis, Reimann & Glaser (1989) 的自我解釋效應 (Self-Explanation Effect) 實驗證實，學習者用自己的話複述與反思所學，保留率比被動閱讀高 2 倍以上。

**問題**：AI 解析出來的結構化教材若只用「切片 + 問答」方式呈現，使用者仍是被動接收者；必須引入主動建構的機制，才能真正觸發深度學習。

**TiTi 實現 — 三類 Layer A 鷹架**：

| 類型 | 定義 | 觸發時機 | 使用者行動 |
|------|------|---------|-----------|
| **takeaway**（重點摘要） | AI 從段落萃取的 3-5 句核心結論 | 資源解析完成時 | 閱讀 + 標記「已理解 / 需複習」 |
| **elaborative**（延伸思考題） | 開放式問題，無標準答案 | 章節閱畢時 | 輸入 `user_response` 文字回答，系統存檔供 AI 教練後續引用 |
| **strategy**（學習策略提示） | 針對該段落的記憶/應用策略建議 | 使用者停留超過閾值時 | 閱讀 + 接受/忽略 |

**資料模型**：

```python
Scaffold(
    resource_id=UUID,
    scaffold_type="takeaway" | "elaborative" | "strategy",
    content="AI 生成的鷹架內容",
    user_response=Optional[str],  # 僅 elaborative 類型有值
    created_at=timestamp,
)
```

**與知識心智圖的整合**：
- `takeaway` 顯示在知識節點卡片側邊欄
- `elaborative` 觸發 AI 教練對話，使用者的 `user_response` 成為後續教練對話的個人化上下文
- `strategy` 依學習時段（衝刺/標準/精熟）動態調整建議內容

**延遲思考題設計**（elaborative 核心）：
- 問題**延遲揭示**：使用者閱讀完一段後才出現，避免預先看到答案影響閱讀
- **無標準答案**：刻意留白，目的是觸發自我解釋而非測驗
- **可選回答**：不強迫，但有回答的使用者會解鎖 AI 教練的「引用你說過的話」功能

**對投資人的意義**：這是 AI 教練從「回答問題」升級到「陪伴學習」的關鍵——鷹架資料不是一次性互動，而是累積使用者的思考痕跡，讓 AI 教練在未來對話中能說「上次你提到 X，現在這個概念正好延伸」。這種歷程記憶是 ULTRA 與 PRO_PLUS 方案的核心差異化，也是續訂率的重要驅動力。
