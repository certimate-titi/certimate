# CertiMate 資料處理協議 (DPA)

**Data Processing Agreement**
**生效日期**: 2026-04-04
**版本**: 1.0

---

## 1. 定義

- **資料控制者 (Controller)**: 使用 CertiMate ULTRA 方案之機構管理者（教師或教育機構）。
- **資料處理者 (Processor)**: CertiMate 平台營運方。
- **資料主體 (Data Subject)**: 透過 EDU 帳號使用平台之學生。
- **個人資料**: 姓名、Email、學習記錄、測驗成績、AI 對話歷史等可識別個人之資訊。

## 2. 處理目的與範圍

2.1 資料處理者僅基於以下目的處理個人資料：
- 提供 CertiMate 教育服務（測驗、AI 教練、學習分析）
- 產生學習統計報告供機構管理者查閱
- 系統維運與安全防護
- 法律義務之遵循

2.2 資料處理者不得將個人資料用於廣告投放、第三方行銷或其他非本協議約定之目的。

## 3. 資料控制者之義務

3.1 機構管理者須確保：
- 已取得學生（或其法定代理人）之明確同意
- 匯入之個人資料正確且為最小必要範圍
- 學生已被告知其資料將由 CertiMate 處理

3.2 機構管理者透過 CSV 匯入學生資料前，須先完成 DPA 電子簽署。未簽署 DPA 前，系統將拒絕 CSV 匯入功能。

## 4. 資料處理者之義務

4.1 資料處理者承諾：
- 僅依資料控制者之指示處理個人資料
- 採取適當技術與組織措施保護資料安全
- 不將個人資料移轉至中華民國境外（除非取得資料控制者書面同意）
- 於服務終止後 90 天內刪除或返還所有個人資料

4.2 安全措施包括但不限於：
- 傳輸加密 (TLS 1.3)
- 靜態資料加密 (AES-256)
- 存取控制與稽核日誌
- 定期安全評估

## 5. 次處理者 (Sub-processor)

5.1 資料處理者目前使用之次處理者：

| 次處理者 | 用途 | 資料中心位置 |
|----------|------|-------------|
| Google Cloud Platform | 基礎架構 | 台灣 (asia-east1) |
| Firebase Authentication | 身分驗證 | 美國 |
| Google Gemini API | AI 功能 | 美國 |
| Anthropic Claude API | AI 功能 | 美國 |

5.2 新增次處理者前，資料處理者將提前 30 天通知資料控制者。

## 6. 資料主體權利

6.1 資料主體享有以下權利：
- **查閱權**: 查閱個人資料之蒐集與處理情形
- **更正權**: 請求更正不正確之個人資料
- **刪除權**: 請求刪除個人資料
- **可攜權**: 請求以結構化格式匯出個人資料

6.2 資料主體行使權利之請求，應透過機構管理者或直接向 CertiMate 客服提出。

## 7. 資料外洩通知

7.1 發生個人資料外洩事件時，資料處理者應於知悉後 72 小時內通知資料控制者。

7.2 通知內容應包括：外洩性質、受影響之資料主體範圍、已採取之補救措施、建議之後續行動。

## 8. 協議期間與終止

8.1 本協議於資料控制者簽署時生效，於 ULTRA 方案終止時自動終止。

8.2 協議終止後，資料處理者應於 90 天內刪除所有 EDU 帳號之個人資料，並提供刪除證明。

## 9. 準據法

本協議適用中華民國個人資料保護法及相關法規，爭議由臺灣臺北地方法院管轄。
