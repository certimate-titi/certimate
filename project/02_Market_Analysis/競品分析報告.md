### ⚠️ 0-B. YouLearn（最高度警戒競品）

> **YouLearn 是目前與 CertiMate 功能重疊最高的直接競爭對手，需要最密切關注。**
> Y Combinator 投資、150,000+ MAU、2.2M+ 份學習素材上傳。

**定位：** 將任何學習素材（PDF、YouTube、音訊、圖片）轉化為互動式 AI 學習體驗。

**核心功能：**
- 支援 PDF（免費版 100 頁/10MB；Pro 版 2,000 頁/300MB）
- YouTube 影片、講座錄音、圖片、純文字輸入
- AI 自動生成：摘要筆記、互動測驗、閃卡、練習考卷、心智圖、時間軸、逐字稿、Podcast 音頻
- 與文件/影片的 AI 對話問答（含來源引用）
- 語音學習模式（Voice Mode）—— 免手操作，邊走邊學
- 閃卡可匯出 Anki 格式，與 Spaced Repetition 工具串接
- 學習進度追蹤

**定價：**

| 方案 | 月費（月繳）| 月費（年繳）| 主要限制 |
|------|-----------|-----------|---------|
| Free | $0 | $0 | 每日 3 次上傳、10 題測驗/日、2 次練習考/月 |
| Pro | $20 USD（≈NT$640）| $12 USD（≈NT$370）| 無限上傳、優先客服 |
| Max | $60 USD（≈NT$1,900）| $45 USD（≈NT$1,450）| 旗艦功能 |

> 學生折扣：.edu 信箱享 Pro 方案 8 折。首購 7 天退款保障。

**優勢：**
- 功能廣度高，素材 → 學習工具的轉化鏈完整
- Voice Mode 為市場少有的差異化功能
- Podcast 生成（類似 NotebookLM）吸引碎片化學習族群
- Anki 匯出讓習慣 Spaced Repetition 的用戶無縫銜接
- YC 背書，資金與成長資源充足
- 介面設計現代，UX 體驗佳

**劣勢（CertiMate 的機會點）：**

| 缺口 | 說明 |
|------|------|
| 無「備考導向」的閉環體驗 | 測驗功能較鬆散，缺乏計時器、題型配比、成績單的完整模擬考 UI |
| Spaced Repetition 非原生 | 僅靠 Anki 匯出間接實現，無原生的艾賓浩斯排程 + Google 行事曆推送 |
| 無 B2B 機構管理後台 | 補習班、企業培訓無法派卷、追蹤班級學習進度、分析全班弱點 |
| 無考試後的弱點閉環 | 缺乏「錯題 → 系統診斷弱點 → 針對弱點重新出題」的自動化機制 |
| 無每日任務 / 成就系統 | 缺乏 Streak、XP、徽章等遊戲化動機設計，長期黏著度較弱 |
| 定價偏高 | Pro 最低 NT$370/月，是 CertiMate PRO（NT$199）的 1.86 倍 |
| 無 Vision OCR 手寫辨識 | 對需要上傳手寫理工公式筆記的學生（如微積分、化學）支援未知 |

**功能對照逐項比較：**

| 功能維度 | YouLearn | CertiMate |
|---------|----------|-----------|
| PDF 上傳 | ✅ | ✅ |
| YouTube 連結轉化 | ✅ | ✅ |
| 手寫圖片 / Vision OCR | 🔶 圖片支援，但數學公式辨識未明確 | ✅ KaTeX 渲染 |
| AI 自動出題 | ✅ 測驗 + 閃卡 | ✅ 結構化模擬考 |
| 計時模擬考環境 | ❌ 無倒數計時 UI | ✅ |
| 成績單與弱點分析 | 🔶 基本進度 | ✅ 雷達圖 + 弱點章節 |
| 原生 Spaced Repetition | ❌ Anki 匯出 | ✅ 艾賓浩斯 + 行事曆推送 |
| AI 蘇格拉底錯題解析 | ✅ AI 問答 | ✅ 引導式錯題分析 |
| 知識心智圖 | ✅ | ✅ |
| 語音學習模式 | ✅ Voice Mode | ❌ |
| Podcast 生成 | ✅ | ❌ |
| 每日任務 / Streak / XP | ❌ | ✅ |
| B2B 機構後台 | ❌ | ✅ Ultra 版 |
| 班級派卷 / 弱點熱點圖 | ❌ | ✅ |
| 月費（最低付費版）| NT$370（年繳）| **NT$199** |

**CertiMate 差異化定位：**

YouLearn 是「**通用型 AI 學習助理**」，幫助學生吸收任何知識；
CertiMate 是「**備考導向 AI 教練**」，目標只有一個：**幫你通過考試**。

這個差異帶來截然不同的產品設計選擇：
- CertiMate 在測驗壓力感（計時、分數）、弱點特訓循環、排程複習上更極致
- YouLearn 在碎片化輸入（語音、Podcast）、多媒體輸出上更豐富

兩者爭奪的是同一群「有學習素材、想借助 AI 提升效率」的用戶。**CertiMate 的核心護城河在於定價（-46%）、備考閉環完整度、B2B 機構市場、以及行事曆深度整合這四個 YouLearn 明確沒有的維度。**

### 1. deeplearning.ai

**定位：** Andrew Ng 創辦的 AI 教育平台，提供深度學習、MLOps、LLM 應用等專業課程。

**核心功能：**
- 固定課程（影片 + Jupyter Notebook 練習）
- Coursera 合作，可獲得結業認證
- 部分課程提供測驗評量（非 AI 動態出題）

**定價：**
| 方案 | 費用 |
|------|------|
| 單堂課程（審計） | 免費（無憑證）|
| Coursera Plus | $49 USD/月（全課程存取）|
| 個別課程購買 | $49-$399 USD |

**優勢：**
- Andrew Ng 品牌權威性高、業界認可
- 課程品質精緻，深度學習領域無可比

**劣勢：**
- 純固定課程，無法上傳自有文件
- 無 AI 動態出題或客製化練習
- 專注 AI/ML 技術領域，不含通用證照備考（如 PMP、TOEIC、AWS 上層考試）

**CertiMate 差異化：** deeplearning.ai 解決的是「學新知識」，CertiMate 解決的是「通過任何考試」。目標使用者幾乎不重疊；部分學完 deeplearning.ai 課程的人，可用 CertiMate 備考 AWS ML 認證。

### 2. Brilliant

**定位：** 以互動問題解決為核心的 STEM 學習平台，主打「做中學」。

**核心功能：**
- 數學、物理、電腦科學、邏輯等互動課程
- 每題均有視覺化動畫引導思考
- 每日 5 分鐘學習習慣建立
- 課程由專家設計，非 AI 動態生成

**定價：**
| 方案 | 費用 |
|------|------|
| 免費版 | 每天限量幾題 |
| 個人月費 | $24.99 USD/月（≈NT$800）|
| 個人年費 | $149.99 USD/年（≈NT$400/月）|
| 企業方案 | 報價制 |

**優勢：**
- 極高品質的互動視覺化學習體驗
- 數學/邏輯訓練無出其右
- 學習習慣養成設計優秀

**劣勢：**
- 完全固定課程，**無法上傳自有素材**
- 不支援任何具體證照備考（AWS、PMP、TOEIC 等）
- 定價對台灣學生偏高（NT$800/月）
- 無 AI 家教解說、無錯題追蹤系統

**CertiMate 差異化：** Brilliant 是「學科基礎能力訓練」，CertiMate 是「考前衝刺工具」。定價方面 CertiMate PRO（NT$199）僅為 Brilliant 的四分之一。

**劣勢：**
- 純靜態文件，無互動性
- 無任何測驗或知識追蹤機制
- 僅涵蓋 Prompt Engineering 一個主題

**CertiMate 差異化：** 幾乎無交集；Learn Prompting 是參考文件，CertiMate 是備考訓練工具。

**定位：** 從使用者提供的 URL 或素材自動生成個人化課程的 AI 平台。

**核心功能：**
- 輸入網頁連結、文件，AI 自動生成課程單元
- 個人化學習路徑
- 目前仍處 Beta 階段

**定價：**
| 方案 | 費用 |
|------|------|
| Beta 版 | 免費（功能未完整）|
| 正式付費方案 | 尚未公開 |

**優勢：**
- 概念上與 CertiMate 最相近（素材 → AI 課程）
- 輸入源支援 URL

**劣勢：**
- 生成課程單元（閱讀為主），**非以「通過考試」為目標**
- 無計時測驗環境、無成績單
- 無間隔複習、無錯題分析
- 產品仍早期，穩定性與完整度不足
- 無 YouTube 轉考卷能力
- 無 B2B 機構管理功能

**CertiMate 差異化：** Grasp 的「課程」偏向閱讀消化，CertiMate 的「備考循環」強調主動回憶（Active Recall）+ 測驗壓力 + 即時 AI 糾錯，更直接對準「通過考試」的結果。

### 5. Go1

**定位：** 企業學習管理系統（LMS），提供超過 100,000 門策展課程的 B2B 平台。

**核心功能：**
- 企業員工培訓課程庫（法遵、安全、軟技能等）
- 管理者儀表板、學習進度追蹤
- SCORM/LTI 整合
- SSO 企業帳號整合

**定價：**
| 方案 | 費用 |
|------|------|
| 標準方案 | $15-30 USD/人/月（企業報價）|
| 大型企業 | 客製報價 |

**優勢：**
- 企業採購整合完善（SSO、HRIS）
- 課程數量龐大（法遵、職場技能）
- B2B 銷售經驗豐富

**劣勢：**
- 純策展內容，**完全不支援私有文件上傳出題**
- 無 AI 動態出題或 AI 家教
- 適合通用員工培訓，**不適合技術證照考試衝刺**
- 定價遠高於 CertiMate ULTRA

**CertiMate 差異化：** Go1 服務的是「通用員工合規培訓」，CertiMate ULTRA 服務的是「機構客製化技術備考訓練」。補習班、企業技術培訓部門需要的是「把自家教材轉成考卷派發」，這正是 CertiMate 的核心優勢，Go1 完全無法滿足。

## 四、市場定位總結

### 4.1 CertiMate 的競爭真空地帶

從上述分析可以清楚看出，目前市場上存在一個**明顯的功能空白**：

```
                   素材客製化 ←————→ 備考導向
                        ↑
         CertiMate 佔據此區域
                        |
    Grasp ——→ 有素材導入，但非備考
    Quizlet ——→ 有備考感，但需手動建卡
    NotebookLM ——→ 有素材解析，但無測驗環境
    deeplearning.ai ——→ 有備考課程，但不能客製化
```

**沒有任何現有競品能同時做到：**
1. ✅ 接受使用者自有素材（PDF + YouTube + 手寫圖片）
2. ✅ 全自動 AI 出題（無需人工整理）
3. ✅ 完整測驗環境（計時、成績、弱點分析）
4. ✅ AI 個人家教（蘇格拉底式錯題解析）
5. ✅ 艾賓浩斯間隔複習 + 行事曆整合
6. ✅ B2B 機構後台（派卷、班級分析）
7. ✅ NT$199/月 的殺手級定價

### 4.2 各競品與 CertiMate 的關係分類

| 關係類型 | 競品 | 說明 |
|---------|------|------|
| **潛在競爭**（最需要關注） | Grasp、Google NotebookLM、Quizlet | 功能方向有交集，但都有重大缺口 |
| **上下游互補** | MagicSchool AI、Graphy、Easygenerator | 服務教師/創作者，CertiMate 服務學習者 |
| **不同市場** | Edmentum、Researcher.Life | K-12 或學術，與成人備考無交集 |
| **不同功能維度** | deeplearning.ai、Brilliant、Learn Prompting | 固定課程，無客製化備考能力 |
| **企業 LMS** | Go1 | B2B 通用培訓，無 AI 出題能力 |

## 五、既有市場分析補充（延伸原有報告）

### 5.1 傳統題庫網站（如阿摩線上測驗）

- **優勢**：累積大量歷屆試題，社群討論度高。
- **劣勢**：題目多由網友分享，品質參差不齊；無針對新興證照（如 AI 應用、新版雲端證照）的即時更新；版面老舊；對**數學符號與圖表**支援極差。
- **CertiMate 突破點**：AI 即時解析官方最新白皮書出題，確保符合最新課綱。更支援 **YouTube 教學影片秒轉考卷**與**旗艦多模態視覺解析（Vision OCR）**，完美辨識手寫微積分筆記並以 KaTeX 排版，傳統題庫完全無法追趕。

### 5.2 學習輔助工具（Quizlet、Anki）

- **優勢**：隨身背誦方便，Spaced Repetition 演算法成熟。
- **劣勢**：需花大量時間手動建立字卡，格式單一，不擅長處理複雜理工公式。
- **CertiMate 突破點**：使用者只要上傳 PDF 或貼上 YouTube 連結，系統「自動」建立類似 Quizlet 的模擬考題，大幅降低門檻。**NT$199/月** 的全包訂閱遠超手動建卡的效率。

### 5.3 通用型 AI（ChatGPT、Claude）

- **優勢**：對話問答靈活，知識面廣。
- **劣勢**：容易幻覺，沒有系統化「測驗環境」與「學習進度追蹤」，無法自動彙整錯題。
- **CertiMate 突破點**：專為「考試情境」打造的 UI/UX，聚焦「測驗 → 檢討 → 觀念釐清」的閉環學習體驗。

### 5.4 Google NotebookLM

- **優勢**：強大文件錨定防幻覺、Citation 功能、AI 雙人對談 Podcast。
- **劣勢**：缺乏「標準化測驗環境」；無「錯題本」與數據化追蹤；偏向單向吸收，缺乏實戰壓迫感。
- **CertiMate 突破點**：NotebookLM 幫你「讀懂」，CertiMate 幫你「考過」。融合 Citation 功能，解答時指出考點出自講義哪一頁或 YouTube 哪一分鐘，做到「錯哪裡，就複習哪裡」。

## 七、對 CertiMate 產品策略的建議

1. **主打「自有素材 → 考過」的獨特敘事**：市場上沒有競品能做到「我的 PDF + YouTube → 幫我通過考試」，這是最強的差異化敘事，應在所有行銷素材中持續強化。

2. **對 Grasp 保持警覺**：目前仍是 Beta，但方向相近，若其推出測驗環境需立刻評估差距。

3. **把 Quizlet 和 NotebookLM 用戶當核心轉換對象**：這兩群用戶已有「自學輔助工具」的使用習慣，只需讓他們體驗「自動出題」的 Aha Moment，轉換成本低。

4. **B2B 方向與 Go1、Easygenerator 有明確差異**：主攻「補習班、企業技術認證培訓」的自有教材上傳場景，這是 Go1 完全空白的市場。

5. **與 MagicSchool AI 可考慮通路合作**：補習班老師用 MagicSchool AI 備課 → 學生用 CertiMate 備考，形成自然的分工互補，可嘗試聯名推廣。
