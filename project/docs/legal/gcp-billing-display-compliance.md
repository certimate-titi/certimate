## 1. 評估範圍

本備忘評估在 CertiMate 平台管理後台展示 GCP 完整帳單資料（Cloud Run、Cloud SQL、Firebase Hosting、Gemini API 等各服務月費）是否涉及商業機密、個資、第三方條款違反等法律風險。

## 2. 關鍵法律與合約檢視

### 2.1 GCP 服務條款（Google Cloud TOS）
- **Billing 資料擁有權**：根據 Google Cloud TOS §3.2，帳單資料屬於「Customer Data」，Customer 有完整控制權，可自由查詢、匯出、展示
- **BigQuery Billing Export 使用限制**：無特別限制，Google 官方鼓勵客戶匯出以進行成本分析
- **結論**：✅ **無違反 GCP TOS**

### 2.2 商業機密風險
GCP 帳單本身包含：
- 各服務使用量與金額（屬 CertiMate 內部成本結構）
- 服務名稱、region、SKU（屬技術架構資訊）

風險分析：
- 若被競爭對手取得，可反推 CertiMate 的技術架構、用戶規模、單位成本
- **結論**：⚠️ 屬**商業機密**，必須嚴格權限隔離至 Super Admin

### 2.3 個資法（台灣）
- GCP 帳單**不包含任何終端用戶個資**
- Billing 資料為聚合性技術指標，不涉及 PDPA
- **結論**：✅ **不涉及個資法**

### 2.4 第三方 AI 供應商條款
| 供應商 | 條款重點 | 風險 |
|--------|---------|------|
| Anthropic Commercial Terms | 用量資料屬 Customer，可自由使用 | ✅ 無 |
| Google AI (Gemini) | 同 GCP TOS | ✅ 無 |
| Voyage AI | 需檢視最新條款（截至 2026-04 未見特殊限制） | 🟡 建議確認 |

## 3. 必要控管措施

### 3.1 存取控制（必要 / 硬性）
- [x] **僅 Super Admin 可見**（一般 admin 零存取權）
- [x] **JWT 層級檢查**（後端 API 必須 `require_super_admin()`）
- [x] **前端路由防護**（一般 admin 訪問 `/admin/cost-monitor` 直接 redirect）
- [x] **導覽列條件渲染**（非 Super Admin 完全不渲染選單項）

### 3.2 稽核軌跡（必要）
根據本專案 Feature 12 平台管理後台稽核規範：
- [x] **存取稽核**：每次瀏覽成本監控頁面寫入 `admin_audit_log`（action: `COST_MONITOR_VIEWED`）
- [x] **變更稽核**：所有預算修改、手動解除停用操作記錄 actor、before/after、原因
- [x] **保留期限**：稽核日誌保留至少 **2 年**（建議 3 年，符合會計稽核標準）

### 3.3 資料外流防護（建議）
- [ ] 頁面禁用右鍵另存、截圖警告浮水印（可選，非硬性要求）
- [x] **匯出功能限制**：不提供 CSV / PDF 匯出按鈕（避免無稽核外流）
- [x] **截圖行為的契約層級約束**：透過員工保密協議（NDA）而非技術層級

### 3.4 Super Admin 身份限定
- **必要條件**：Super Admin 帳號僅限**簽署 NDA 的核心團隊成員**
- **禁止**：外部顧問、約聘人員、試用期員工
- **建議**：若需臨時給外部財務顧問查看，應建立「唯讀 Financial Viewer」角色（本版不做）

## 4. 若遇外部質疑的應對

### 4.1 使用者詢問
Q: 你們會用我的資料算成本嗎？
A: GCP 帳單是平台層級的技術成本資料，**不含任何用戶個資**，且僅核心管理員可見。

### 4.2 監管機構查核
- PDPA 查核：可提供「Billing 資料不含個資」的技術說明
- 會計稽核：稽核日誌保留 3 年，可完整追溯每筆預算變更
