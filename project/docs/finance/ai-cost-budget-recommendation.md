## 3. 月預算建議

計算邏輯：預估月成本 × 1.2（20% 緩衝）後四捨五入到 50 USD 單位。

### 3.1 Anthropic（主要用於 AI 教練、考題驗證）

- 使用模型：80% Haiku + 20% Sonnet（成本優化策略）
- 平均每次呼叫 token：input 2,000 + output 500
- 月成本估算：
  - Haiku 部分：160,000 × 0.8 × (2000×0.25 + 500×1.25) / 1,000,000 ≈ **$143**
  - Sonnet 部分：160,000 × 0.2 × (2000×3 + 500×15) / 1,000,000 ≈ **$432**
  - 合計：**$575**
- **建議月預算：$700**（含 20% 緩衝）

### 3.2 Gemini（主要用於出題、心智圖、embedding）

- 使用模型：出題 Flash、心智圖 Pro、embedding text-embedding-004
- 月成本估算：
  - 出題 Flash：160,000 × 0.5 × (3000×0.075 + 1000×0.30) / 1,000,000 ≈ **$42**
  - 心智圖 Pro：500 × (10000×1.25 + 3000×5) / 1,000,000 ≈ **$14**
  - Embedding：500 × 5000 × 0.025 / 1,000,000 ≈ **$0.06**（極小）
  - 合計：**$56**
- **建議月預算：$100**（含緩衝與成長空間）

### 3.3 Voyage（主要 embedding 供應商）

- 使用模型：voyage-3
- 月成本估算：
  - Embedding：500 × 5000 × 0.12 / 1,000,000 ≈ **$0.30**
  - 但考慮查詢時也需 embed query：160,000 × 50 × 0.12 / 1,000,000 ≈ **$0.96**
  - 合計：**$1.26**
- **但 Voyage 風險極高**（無官方上限），建議預算保守：
- **建議月預算：$50**（約 40 倍實際用量的安全護欄，若達 80% 強制切 Gemini）

### 3.4 GCP 總預算

- 非 AI 基礎設施：$210
- Gemini API（GCP 計費）：$56
- 其他浮動費用（egress、BQ 查詢、snapshots）：$50
- 小計：$316
- **建議月預算：$400**（含 25% 緩衝）

## 6. 風險情境分析

| 情境 | 影響 | 應對 |
|------|------|------|
| 爆量 3 倍（病毒行銷） | 超支 $2,500 | 自動降級機制啟動，暫停新出題 |
| Prompt injection 導致 infinite loop | Voyage 單日燒 $500+ | 配額鎖 + rate limit 攔截 |
| GCP Cloud Run scale-out 異常 | 單日 $100+ | GCP 預算告警（需 Super Admin 人工介入） |
| Anthropic 調漲定價 20% | 超支 $115 | 20% 緩衝可吸收 |

## 7. 調整建議

- **第一個月**：以上建議值運行，密集觀察實際用量
- **第二個月起**：依實際數據調整，若多項 scope 使用率 < 30%，調低預算節省心理負擔
- **季度檢視**：Super Admin 每季檢視是否需調整門檻比例（例如改為 40/70/90）
