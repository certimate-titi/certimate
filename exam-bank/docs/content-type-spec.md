# TiTi 內容類型分類規格書

> **版本**：v1.0 | 2026-04-03
> **負責角色**：⭐ 考題設計人員 + 產品經理
> **目標對齊**：O1-KR3（信度覆蓋率）、O2-KR1（用戶基礎）

---

## 一、概述

TiTi 將用戶上傳的文件分為兩個獨立維度：

```
維度 1：檔案格式（ResourceType） — 由副檔名決定
  pdf | markdown | txt | image | youtube

維度 2：內容類型（ContentType） — 由 Stage 0 LLM 偵測
  exam | regulation | textbook | summary | formula | syllabus | general
```

同一份 PDF 可以是 exam（考古題 PDF）或 regulation（法規 PDF），兩者處理方式完全不同。

---

## 二、7 種內容類型

### 1. exam — 考試試卷

| 項目 | 說明 |
|------|------|
| **定義** | 包含題號、選項、答案的考試題目 |
| **來源** | 考古題、模擬考、練習題、測驗卷 |
| **辨識特徵** | 有「( )」選項、題號序列、答案欄 |
| **處理策略** | 結構化提取（題幹 + 選項 + 答案 + Bloom 分類） |
| **產出物** | 結構化題目 JSON → 匯入 `question` 表 → 直接可練習 |
| **信度標示** | 🟢 考古題 / 🟡 用戶上傳題目 |

### 2. regulation — 法規規範

| 項目 | 說明 |
|------|------|
| **定義** | 法律條文、行政規則、主管機關規定 |
| **來源** | 金管會法規、證交法、期貨交易法、考試相關法令 |
| **辨識特徵** | 「第 N 條」、「依...規定」、法律用語 |
| **處理策略** | 條文結構化提取（條號 + 內容 + 關鍵詞） |
| **產出物** | 知識節點 → 匯入 `knowledge_node` 表 → AI 依法規出題 |
| **價值** | 金融證照考題 60%+ 來自法規，法規庫是出題品質的關鍵 |

### 3. textbook — 教材內容

| 項目 | 說明 |
|------|------|
| **定義** | 教科書章節、參考書、系統性知識講解 |
| **來源** | 教科書、參考書、線上課程講義 |
| **辨識特徵** | 章節結構、定義、範例、圖表說明 |
| **處理策略** | 概念結構化提取（章節 + 定義 + 概念關聯） |
| **產出物** | 知識心智圖 → 匯入 `knowledge_node` 表 → AI 依概念出題 |

### 4. summary — 重點整理

| 項目 | 說明 |
|------|------|
| **定義** | 筆記、講義、考前衝刺、條列式重點 |
| **來源** | 個人筆記、補習班講義、考前整理 |
| **辨識特徵** | 條列符號、關鍵字標記、口訣 |
| **處理策略** | 要點提取（關鍵詞 + 摘要 + 記憶法） |
| **產出物** | 閃卡集 → 匯入 `flashcard` 表 → 快速複習 |

### 5. formula — 公式表/計算

| 項目 | 說明 |
|------|------|
| **定義** | 數學公式、財務公式、統計公式集 |
| **來源** | 公式表、計算手冊、公式整理 |
| **辨識特徵** | 大量數學符號、等號、希臘字母 |
| **處理策略** | KaTeX 公式辨識 + 變數說明 |
| **產出物** | 公式卡 → 匯入 `knowledge_node`（標記 formula）→ 計算題生成 |

### 6. syllabus — 考試大綱

| 項目 | 說明 |
|------|------|
| **定義** | 官方考試範圍、簡章、考科主題與權重 |
| **來源** | 考選部/SFI/iPAS 官方簡章 |
| **辨識特徵** | 考科名稱、百分比權重、題數、時間 |
| **處理策略** | 主題提取（考科 + 主題 + 權重比例） |
| **產出物** | 學習計畫 → 設定 `study_plan` → 智慧規劃學習路徑 |

### 7. general — 一般文件

| 項目 | 說明 |
|------|------|
| **定義** | 無法歸類到以上任何一種的內容 |
| **來源** | 雜項文件 |
| **處理策略** | 基礎文字提取 + 結構化 |
| **產出物** | 純文字 Markdown → 用戶自行閱讀 |

## 四、Stage 0 偵測準確度目標

| 類型 | 目標準確率 | 容易混淆 |
|------|----------|---------|
| exam | ≥ 95% | summary（有些筆記含練習題） |
| regulation | ≥ 90% | textbook（教科書引用法規） |
| textbook | ≥ 85% | regulation, summary |
| summary | ≥ 85% | textbook |
| formula | ≥ 90% | textbook（含公式的教材） |
| syllabus | ≥ 95% | general |
| general | fallback | — |

**混淆處理原則**：寧可歸類到「更結構化」的類型。例如含題目的筆記 → exam；含法規的教材 → regulation。

## 五、DB Schema 擴充

```sql
-- 在 resource 表新增 content_type 欄位
ALTER TABLE resource ADD COLUMN content_type VARCHAR(20) DEFAULT 'general';

-- ContentType enum
-- exam, regulation, textbook, summary, formula, syllabus, general
```

DBML 更新：

```dbml
Enum content_type {
  exam        [note: '考試試卷']
  regulation  [note: '法規規範']
  textbook    [note: '教材內容']
  summary     [note: '重點整理']
  formula     [note: '公式表']
  syllabus    [note: '考試大綱']
  general     [note: '一般文件']
}
```
