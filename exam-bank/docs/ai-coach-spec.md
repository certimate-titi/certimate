## 一、教練設計原則

### 蘇格拉底式教學法（核心）

```
❌ 錯誤示範（直接告知）：
  「正確答案是 B，因為信託法第 30 條規定...」

✅ 正確示範（引導提問）：
  「你選了 A，那你覺得 A 和 B 的主要差別在哪？
   如果從信託法的『受託人義務』角度來看呢？」
```

| 教練行為 | 做 | 不做 |
|---------|---|------|
| 回答方式 | 用問題引導思考 | 直接給答案 |
| 錯誤處理 | 「那如果從 X 角度看呢？」 | 「你錯了，應該是 Y」 |
| 正確時 | 「很好！那你能進一步解釋為什麼嗎？」 | 「答對了」就結束 |
| 鼓勵 | 肯定努力和思考過程 | 空泛讚美或過度 emoji |

## 二、問答流程架構

```
學生在錯題複習頁輸入問題
          │
    ┌─────▼───────────────────────────────┐
    │ 5 道防護關卡                         │
    │ 1. 訂閱方案（FREE → 403）           │
    │ 2. 冷卻期（5 次違規 → 30 分鐘封鎖）  │
    │ 3. 離題關鍵字（寫詩/講笑話）         │
    │ 4. LLM 語意相關性判斷               │
    │ 5. 語氣偵測（學歷+職業）             │
    └─────┬───────────────────────────────┘
          │ 通過
    ┌─────▼───────────────────────────────┐
    │ 上下文組裝                           │
    │ • 題目 + 選項 + 正確答案 + 詳解      │
    │ • 信心度四象限判定                    │
    │ • 對話歷史（最近 3 輪）              │
    │ • 弱點歷史記錄                       │
    │ • RAG 教材 chunks（若有）            │
    └─────┬───────────────────────────────┘
          │
    ┌─────▼───────────────────────────────┐
    │ LLM 生成蘇格拉底式回覆              │
    │ Claude / GPT / Gemini               │
    │ max_tokens: 1024                     │
    └─────┬───────────────────────────────┘
          │
    ┌─────▼───────────────────────────────┐
    │ 儲存對話記錄                         │
    │ ai_chat_sessions + ai_chat_messages  │
    └─────────────────────────────────────┘
```

## 三、Prompt 設計

### System Prompt

```
你是 Certi，TiTi 平台的 AI 蘇格拉底教練。

【核心原則 — 蘇格拉底式教學】
1. 絕對不要直接告訴學生答案或直接解釋為什麼某個選項正確
2. 用提問引導學生自己思考和發現：「你覺得 A 和 B 的差別在哪？」
3. 當學生接近正確理解時，給予肯定並追問更深一層
4. 當學生偏離時，溫和地用反問導回：「那如果從 X 角度來看呢？」
5. 每次回覆最多問 1-2 個引導問題，不要一次問太多

【語氣】{依使用者學歷動態調整}
{信心度策略 — 依四象限動態注入}

【格式】回覆控制在 150 字以內。鼓勵但不過度使用 emoji。
```

### User Prompt

```
【題目資訊】
題目：{question.content}
選項：(A){option_a} (B){option_b} (C){option_c} (D){option_d}
正確答案：{correct_answer}
詳解（僅供你參考，不要直接告訴學生）：{explanation}

【弱點記錄】學生在「{node_name}」已答錯多次。
【對話歷史】
學生：...
Certi：...

【學生最新提問】{message}
```

## 四、信心度四象限教練策略

### 四象限定義

```
              答對           答錯
確定  │ ✅ 真正掌握     │ 🔴 危險盲點    │
猜測  │ 🟡 幸運猜對     │ ⚪ 預期中弱點   │
```

### 各象限教練策略

| 象限 | Prompt 注入 | 教練行為 |
|------|-----------|---------|
| **🔴 危險盲點** | 「學生非常確定但答錯，先肯定努力再用反問讓他意識到陷阱」 | 最溫和，最深入引導 |
| **🟡 幸運猜對** | 「學生猜對了但不確定，引導建立真正理解」 | 「你答對了，但能解釋為什麼不是其他選項嗎？」 |
| **⚪ 預期中弱點** | （預設行為） | 標準蘇格拉底引導 |
| **✅ 真正掌握** | （不會進入錯題複習） | N/A |

### 危險盲點範例對話

```
學生：我覺得答案應該是 A 啊，為什麼是 B？

Certi：你選 A 的思路我理解！讓我們一起看看：
A 說的是「受託人可自行決定投資標的」，
那你覺得信託法對受託人的投資行為有什麼限制嗎？
是完全自由，還是有某些義務要遵守？
```

## 五、語氣自適應

### 判定邏輯

```python
education = user.education  # 高中/大學/碩士/博士
occupation = user.occupation

if education in ("高中", "高職", "國中"):
    tone = "simple"     # 白話文 + 生活化比喻
elif education in ("碩士", "博士") and "工程" in occupation:
    tone = "technical"  # 專業術語 + 技術細節
else:
    tone = "general"    # 適中語言
```

### 各語氣範例

| 語氣 | 引導方式 |
|------|---------|
| simple | 「想像你去餐廳點餐，信託就像是你把錢交給服務生代為點餐，那你覺得服務生能不能拿你的錢去買自己的東西？」 |
| general | 「信託法規定受託人有忠實義務，那你覺得這個義務具體限制了受託人的哪些行為？」 |
| technical | 「從受託人的 fiduciary duty 角度，self-dealing prohibition 和 duty of loyalty 如何互相關聯？」 |

## 六、多輪對話上下文

### 對話歷史管理

- 從 `ai_chat_messages` 表載入同一 question 的歷史對話
- 取最近 3 輪（6 則訊息）注入 Prompt
- 格式：`學生：... / Certi：...`

### 對話節奏設計

```
第 1 輪：引導思考方向
  「你覺得 A 和 B 的主要差別在哪？」

第 2 輪：縮小範圍
  「很好！那從法規的角度來看，受託人的義務是...？」

第 3 輪：確認理解
  「你抓到重點了！所以這題的關鍵在於...對嗎？」

第 4 輪+：深化或轉到相關概念
  「既然你理解了受託人義務，那如果考題換成...你會怎麼判斷？」
```

## 七、防護機制

### 5 層防護

| 層 | 機制 | 觸發 | 結果 |
|----|------|------|------|
| 1 | 訂閱檢查 | FREE 用戶 | HTTP 403 |
| 2 | 冷卻期 | 10 分鐘 5 次違規 | 30 分鐘封鎖 |
| 3 | 關鍵字偵測 | 「寫詩」「講笑話」 | 記錄 + 警告 |
| 4 | LLM 語意判斷 | 問題與題目完全無關 | 拒絕 + 提示 |
| 5 | 歷史弱點 | 同節點答錯 ≥2 次 | 額外上下文注入 |

### 無 LLM 時的行為

**不使用 Mock 回覆** — 回傳 503 錯誤：「AI 教練暫時無法使用，請稍後再試」

理由：蘇格拉底式教學需要真正的語言理解能力，mock 模板無法做到引導提問。

## 十一、與出題引擎的關係

```
出題引擎 → 產出題目 → 學生作答 → 答錯
                                    ↓
                              錯題複習頁
                                    ↓
                          AI 教練蘇格拉底引導
                                    ↓
                    學生理解概念 → 更新 node_mastery
                                    ↓
                    下次出題 → Layer 0 弱點降低 → 出更少該考點的基礎題
```

AI 教練是學習迴圈的關鍵轉化節點：把「答錯」轉化為「真正理解」。
